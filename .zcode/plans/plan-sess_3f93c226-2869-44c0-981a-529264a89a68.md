## 3. 发布效果追踪（高）——闭环验证

### 设计思路
发布成功后，延迟触发一次 AI 监测，对比发布前后的品牌提及率变化。

### 后端
- **实体** `PublishJob` 加 `PreMentionRate float64` + `PostMentionRate float64`
- **迁移** `018_publish_job_mention_rates.sql`
- **PO/mapper** 同步加字段
- **用例** `account.go` `publishAuto` goroutine 成功后：
  1. 记录发布前提及率（从最近一次 MonitoringResult 取）
  2. 延迟 30 秒后触发监测（给 AI 引擎收录时间）
  3. 监测完成后记录发布后提及率
  4. 更新 PublishJob
- **依赖注入**：`PublishUseCase` 加 `monitorUC port.MonitorTrigger` 可选接口（避免 usecase 间直接依赖）
  ```go
  type MonitorTrigger interface {
      TriggerMonitor(ctx, tenantID, brandID string) (float64, error)
  }
  ```
  geo 包的 `MonitorUseCase` 实现此接口，main.go 装配时注入

### 前端
- **Publish.tsx** 发布记录表格：published 状态行显示"提及率：前 X% → 后 Y%"
- 趋势变化用颜色标识（上升绿色/下降红色）
