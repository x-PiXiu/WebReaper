# 07 - 获客智能体转型计划

> **状态**：已确认，开工中
> **日期**：2026-08-20
> **前置**：本计划取代此前的 GEO 导向信息架构（01-06 计划已完成并合入 main）

---

## 一、转型背景

| 维度 | 转型前 | 转型后 |
|---|---|---|
| 产品名 | 智擎AI | **获客智能体** |
| 核心叙事 | "让品牌被 AI 引用"（GEO） | **"帮你做视频→发出去→客人来找你"** |
| 主线重心 | 监测（体检）为核心动作 | **视频创作+分发**为核心动作 |
| 输入模型 | 关键词管理（商户选词） | **知识库上传**（商户传品牌文档，AI 自动提炼） |
| GEO 功能 | 前台主角 | 保留全部功能，降为"看效果"（最后一步） |
| 转型原因 | — | 实体商家对 GEO 接受度较低，效果不明显；视频获客更直观 |

---

## 二、已确认的四个决策（grilling 结论）

### D1 产品名 = 获客智能体
- 顶栏品牌 / 登录页大标题 / Admin / 浏览器标签，全端替换（智擎AI 不再露出）
- "GEO" 字面从商户端清零（~15 处评分标签/页头副标 → "AI 推荐度"）

### D2 四步主线 = 建档案 → 做视频 → 发出去 → 看效果
- 菜单重排：品牌档案 / 做视频（内容中心·默认视频Tab） / 发出去（分发中心） / 看效果（原AI体检）
- 内容中心默认 Tab 从"写文章"翻转为"做视频图片"
- 工作台引导卡 + hasVideo 判定接 `/generation/tasks`

### D3 知识库 = 品牌档案第 4 Tab
- **维度**：KnowledgeMaterial + BrandID/TenantID；分层检索（品牌私有→行业公共池兜底）
- **格式**（第一期）：纯文本粘贴 + .txt/.md 文件上传（PDF/Word 解析放二期）
- **页面**：品牌档案第 4 Tab，与资料/门店/竞品并列（输入之家）
- **联动**：内容生成时自动注入（服务端现有 material injection 逻辑，过滤维度从 Industry → BrandID）

### D4 写文章 = 三段式（关键词消失）
- **交互**：品牌（自动选好）→ "想写什么？"（可选输入框）→ [帮我写]
- **留空** = AI 从知识库+品牌资料全自动提炼主题；**填了** = 围绕这句话写
- **底部提示**："AI 将参考：品牌名 + 知识库 N 份素材"
- **服务端**：keywords 从必改可选；keywordDesc 替代源 = 一句话 or 品牌定位；RAG 检索词换源

### D5 AI 体检 → AI 效果（改名+微调，功能保留）

| 现有 | 改为 |
|---|---|
| AI 体检（菜单+页面） | AI 效果 |
| 问问 AI | 测一测 |
| 体检报告 | 效果报告 |
| 体检记录 | 效果记录 |
| 自动体检 | 自动追踪 |
| 健康分 | AI 推荐度 |
| 体检额度 | AI 查询额度 |

- 问题库子 Tab 删除（Keywords.tsx 从 RecordsTab 移除）
- 问问AI 去掉"从问题库选"下拉；出题不入库
- 服务端 keyword 记录保留（内部数据关联机制）

### D6 视频分发分两步
- **本轮**：A6 配额修复（DefaultPlans 补 "generation" key）+ 小红书视频 RPA 补全（.mp4 上传）
- **下一轮**：抖音/快手完整通道（扫码绑定 + Agent 驱动 RPA）

## 三、技术架构决策

### 知识库品牌化（A1/A2）

```
服务端改动：
  entity/knowledge_material.go
    + BrandID  string  // 品牌私有素材（空 = 行业公共池）
    + TenantID string  // 租户隔离
    IsValid() 放宽 SourceURL 必填（商户上传无 URL）

  adapter/repository/knowledge_material_repo.go
    ListByBrand(brandID) / Delete by brand+tenant
    SearchSimilar 加 brandID 过滤

  adapter/knowledge/retriever.go
    Retrieve(ctx, industry, brandID, query, num)
    分层：先查品牌私有 → 不足补行业公共池

  商户端路由（router_geo.go 新增）：
    POST /geo/brands/:id/knowledge/materials   — 上传（文本/txt/md）
    GET  /geo/brands/:id/knowledge/materials   — 列表
    DELETE /geo/brands/:id/knowledge/materials/:mid — 删除

  入库流程：文本 → embedder 向量化 → pgvector/Milvus → 素材表
  复用现有 pipeline.go 的清洗/指纹去重逻辑
```

### 内容生成 keywords 可选（A3/A4）

```
geo_handler.go:745
  Keywords []string `json:"keywords"`  // 去掉 binding:"required"

content.go:919
  删除 if len(in.Keywords) == 0 空校验

keywordDesc 替代源（content.go 内部）：
  if in.Topic != ""      → keywordDesc = in.Topic（用户一句话）
  else if brand.Positioning != "" → keywordDesc = brand.Positioning
  else                   → keywordDesc = brand.Name

ragQuery = 品牌名 + keywordDesc（不变，只是 keywordDesc 换了来源）

知识库注入（buildReferencePrompt）：
  过滤维度从 brand.Industry → brand.ID（分层检索品牌私有→行业公共）

GEO 评分锚点：
  scorer.Score(ctx, content, in.Keywords[0])
  → if len(in.Keywords) > 0 取第一个；否则取 brand.Name
```

### AI 效果重构（客户端）

```

Home.tsx：引导卡步骤名 + 判定逻辑
geoTerms.ts：术语映射更新
```

### 视频分发（本轮范围）
