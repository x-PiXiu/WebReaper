> 日期：2026-08-29
> 定位：**用户视角的操作流程文档**——每个业务阶段用户怎么操作、客户端怎么拆分傻瓜式

## 1. 口播全旅程总览

一个完整口播视频的用户旅程分五个阶段（阶段 0 是一次性的准备工作）：

```
┌─────────────────────────────────────────────────────────────────────────┐
│ 阶段0  数字分身准备（一次性）                                            │
│   上传形象照/视频 → 创建主体 → 自动生成10s形象视频 → 分身可用             │
└─────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────┐
│ 阶段1  台词来源（向导第①步，三选一）                                     │
│   ① 粘贴爆款链接提取文案（抖音/B站/长尾平台）                            │
│   ② 上传参考音/视频 → ASR 提取                                          │
│   ③ 手写/粘贴文案                                                       │
└─────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────┐
│ 阶段2  口播生成向导（傻瓜式分步）                                        │
│   选品牌人设 → 选出镜形态（数字分身/真人） → 选音色 → TTS+对口型 → 成片   │
└─────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────┐
│ 阶段3  B-Roll 插入（可选，成片后处理）                                   │
│   台词定位 → 指定句挂片段 → 合成 → 核对                                  │
└─────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────┐
│ 阶段4  发布分发                                                          │
│   选平台/账号 →（发布模式）→ 发布 → 作品库跟踪                           │
└─────────────────────────────────────────────────────────────────────────┘
```

用户可以随时停在任意阶段：成片不插入直接发布（跳过阶段3）、插入后不发布继续改、
发布后回作品库看数据。每阶段的产物都进作品库留档。

## 2. 阶段 0：数字分身准备（一次性）

### 2.1 操作流程

```
【分身管理页】
   ├─ 浏览官方主体（全部展示，即选即用，无需创建）─────────────→ 直接用于阶段2
   └─ 创建个人分身：
        上传形象照 1-3 张（或 1 个 ≤5s 形象视频，仅 q2-pro）
        → 填分身名称
        → [提交创建]
              ↓ 后端自动链式执行（用户只见进度）：
              ① POST /ent/v2/subjects        创建主体（秒级）
              ② 自动：主体参考生视频          生成 10s 不说话的形象视频
                 （reference2video + duration=10 + 无音频）
              ③ 形象视频 URL 回写分身记录
              ↓
        分身状态：创建中 → 形象视频生成中 → ✅ 可用
        （用户此时可预览形象视频：人物是否满意，不满意可删了重建）
```

### 2.2 API 拆段

| 步骤 | API | 说明 |
|---|---|---|
| 官方主体列表 | 服务端缓存代理（GET /subjects?ownership=system） | 前端读本地缓存端点，不直连 Vidu |
| 个人分身列表 | 本地主体列表端点（按租户） | 不查 Vidu——本地存 server_id |
| 创建分身 | `POST /generation/submit` type=subject | 同步建主体 + 后端自动链式建形象视频任务 |
| 形象视频进度 | `GET /generation/tasks/:id` 轮询 | 创建接口返回链式任务 id |

### 2.3 页面与显示内容

| 页面/子页面 | 显示内容 |
|---|---|
| **分身管理页**（新） | 两个分区：上「官方主体」网格（头像/名称/风格标签，分页或全量）；下「我的分身」列表（名称、形象视频缩略图、状态徽标：创建中/形象视频生成中/可用、删除按钮） |
| 分身预览弹窗 | 形象视频播放器（10s 循环播放）+「用此分身去创作」按钮（跳转向导并预选） |

## 3. 阶段 1：台词来源（向导第①步）

### 3.1 操作流程（三入口汇合）

```
【口播向导 · 第①步 选择素材来源】
   ┌──────────────────┬──────────────────┬──────────────────┐
   │  ① 粘贴分享链接    │  ② 上传参考音/视频 │  ③ 手写文案        │
   ├──────────────────┼──────────────────┼──────────────────┤
   │ 输入框粘贴口令全文  │ 拖拽/选择本地文件  │ 多行文本框         │
   │ [提取文案] 按钮    │ [提取文案] 按钮    │ 直接输入           │
   │      ↓            │      ↓            │      ↓            │
   │ 解析+下载+ASR     │ 上传+ASR          │ —                 │
   │ （异步轮询，       │ （异步轮询）       │                   │
   │  显示进度提示）    │                  │                   │
   └────────┬─────────┴────────┬─────────┴────────┬─────────┘
            └──────────────────┼──────────────────┘
                               ↓
              【文案确认/编辑区】逐句显示（一行一句）
              可编辑每句 / 整体重写（LLM 润色：清洗版 + 品牌改写版二选一）
                               ↓
                        [下一步] → 进入阶段2
```

### 3.2 API 拆段

| 入口 | API |
|---|---|
| 链接提取 | `POST /generation/transcript/extract/async` → 轮询 `GET .../tasks/:id` |
| 上传提取 | 同上（asset_url 形态） |
| 文案润色 | `POST /generation/transcript/rewrite`（一次调用出双版本） |

### 3.3 显示内容要点

- 提取过程**异步轮询**：按钮变加载态 + 阶段提示（解析链接→下载视频→提取文案），
  长视频不超时（后台跑，前端 3s 轮询）
- 提取完成：逐句列表（一行一句高亮显示——**为阶段3 插入点做心智铺垫**）
- 快手链接 → 即时友好提示"请下载后用上传方式"（提前拦截）

## 4. 阶段 2：口播生成向导（傻瓜式分步）

### 4.1 操作流程（步骤条设计）

```
【口播向导 · 步骤条】 ① 素材 ── ② 配置 ── ③ 生成中 ── ④ 完成
                                    （②配置页内容）
   ┌────────────────────────────────────────────────────┐
   │ 选择品牌/人设     （下拉：我的品牌列表）              │
   │ 出镜形态         ◉ 数字分身  ○ 真人出镜              │
   │   ├─ 分身模式：选择分身（打开分身选择器：官方区+个人区）│
   │   └─ 真人模式：上传出镜视频（提示音频时长匹配建议）    │
   │ 选择音色         （音色试听/克隆音色）                │
   │ [开始生成]                                            │
   └────────────────────────────────────────────────────┘
                               ↓
   【③ 生成中页：阶段进度条】（不可离开页面，可取消）
      ▸ 语音合成(TTS)        ── 轮询 tts 任务
      ▸ 对口型合成           ── 轮询 lipsync 任务
          （分身模式无需"口播画面"步骤——形象视频已在分身上）
      每阶段：完成✓ / 进行中(转圈) / 待开始(灰)
      失败时：该阶段显示 [重试] 按钮（断点续跑，不重做已完成阶段）
                               ↓
   【④ 完成页】成片播放器 + [发布] [插入画面] [重新生成]
```

### 4.2 API 拆段（统一生成提交的分段）

| 用户看到的阶段 | API type | 前端编排 |
|---|---|---|
| 语音合成 | `tts` | 前端顺序提交：tts 完成 → 取 audioUrl |
| 对口型合成 | `lipsync`（video_url=分身形象视频或真人视频） | tts 产物 + 视频 → lipsync |

> 说明：形象视频前置改造后，分身模式的"参考生视频（ref）"阶段从向导中**消失**——
> 每次成片都是两段（tts + lipsync），更快更省。真人模式同样两段。

### 4.3 傻瓜式设计要点

1. **每步只问一件事**：素材→配置→生成→完成，步骤条顶部常驻
2. **失败断点续跑**：任一阶段失败只重试该阶段（tts 成品保留复用）
3. **进度可见**：生成中页显示当前阶段 + 已耗时；任务状态轮询统一 3~5s
4. **草稿云同步**：向导任意步离开自动保存（现有 composeDraft），回来恢复

## 5. 阶段 3：B-Roll 插入（成片后处理）

### 5.1 操作流程

```
【作品详情页 · 成片播放器下方 = 台词列表区】
   顶部提示：「插入点按文案行对齐，一行一句效果最佳」
   每句一行： [00:07-00:09] 我们家的酸菜鱼是现杀的   [+ 插入画面]
      （时间戳首次点击时后端定位后显示；estimated 句显示"边界为估算"角标）
                               ↓ 用户点某句 [+插入画面]
   【片段选择弹窗】= 素材库选择器（视频/图片）或本地上传
                               ↓ 选中后
   该句显示： [🎬 已挂片段(缩略图)] [预览窗口首帧] [更换] [移除]
   （可继续给其他句挂片段；纯前端配置状态，不调 API）
                               ↓ 用户点 [合成成片]
   后端：校验（窗口不重叠等）→ 创建 compose 任务 → 进度条（排队中→合成中%）
                               ↓
   合成完成：作品库出现新成片（源片保留）→ 播放核对
   （片段窗口画面切换/口播音量全程不变/窗口外口型对齐）
   不满意 → 以新成片为源再调整（时间轴自动继承，无需重新定位）
```

### 5.2 API 拆段

| 动作 | API | 时机 |
|---|---|---|
| 首次定位 | `POST /generation/tasks/:id/timeline`（一次，纯本地秒级） | 用户首次点 [+插入画面] 时自动触发 |
| 读取时间轴 | `GET /generation/tasks/:id/timeline` | 打开作品详情时（已定位则显示时间戳） |
| 提交合成 | `POST /generation/submit` type=compose | 点 [合成成片] |
| 合成进度 | `GET /generation/tasks/:id`（现有轮询） | 合成中 |
| 窗口预览 | `GET /generation/tasks/:id/preview?sentence_index=N`（增强项） | 挂片段后显示窗口首帧 |

### 5.3 页面与显示内容

| 子页面/组件 | 显示内容 |
|---|---|
| 台词列表区（作品详情页内） | 逐句行：时间戳范围 + 句文本 + 插入状态（未插/+插入画面/已挂缩略图）；estimated 角标 |
| 片段选择弹窗 | 复用素材库选择器（视频/图片筛选）+ 上传 tab |
| 合成进度条 | 排队中（前面 N 个）/ 合成中（阶段显示）/ 完成 |
| 合成结果 | 新成片播放器 + 源片/新片切换 tab + [再调整]（链式入口） |

## 6. 阶段 4：发布分发

### 6.1 操作流程

```
【作品详情页 [发布] 按钮】→【发布配置弹窗/页】
   选择平台（多选）：抖音 / 快手 / B站 / 知乎（/ 微信 / YouTube 视账号）
   每平台：选账号（绑定的账号列表，含健康状态）→ 标题/标签/分区等参数预填
   （content_adapter 按平台自动适配：截断/清洗/合并——用户可微调）
                               ↓ [发布]
   半自动模式：逐平台生成预填发布页链接 → 用户手动完成（新窗口打开）
   全自动模式：RPA 自动发布（当前服务端处于 DRY_RUN 演练模式——
              按钮就绪验证全通过，正式启用需去掉环境变量重启）
                               ↓
   【发布结果】：每平台 成功(带作品链接) / 失败(可读原因+重试) / 处理中
                               ↓
   作品库：作品卡显示已发布平台徽标；发布后的互动数据（播放/点赞）定期回读
```

### 6.2 页面与显示内容

| 页面/子页面 | 显示内容 |
|---|---|
| 发布配置弹窗 | 平台多选卡片（含各平台已绑账号与健康状态）、参数预填区（按平台分组）、发布模式选择 |
| 发布结果页 | 平台×状态矩阵（成功/失败/处理中 + 错误原因 + [重试]） |
| 作品库（现有） | 作品卡：封面、标题、已发布平台徽标、B-Roll 标记（含插入片段的作品） |

## 7. 统一生成 API 拆段总表（口播全旅程）

| 用户阶段 | 用户动作 | API type / 端点 | 同步/异步 |
|---|---|---|---|
| 阶段0 | 创建分身 | `subject`（含链式形象视频） | 同步+链式异步 |
| 阶段1 | 链接/上传提取 | `transcript/extract/async` | 异步轮询 |
| 阶段1 | 文案润色 | `transcript/rewrite` | 同步 |
| 阶段2 | 语音合成 | `tts` | 异步轮询 |
| 阶段2 | 对口型 | `lipsync` | 异步轮询 |
| 阶段3 | 台词定位 | `tasks/:id/timeline` | 同步（秒级） |
| 阶段3 | 插入合成 | `compose` | 异步轮询 |
| 阶段4 | 发布 | `merchant/publish`（mode=semi/auto） | 半自动同步/全自动异步 |

**统一提交体系原则**：所有"创建任务"的动作都走 `POST /generation/submit`（type 路由），
所有等待都复用 `GET /generation/tasks/:id` 轮询——前端只有两套调用模式，新业务零学习成本。
