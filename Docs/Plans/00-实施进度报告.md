> 📅 更新：2026-08-11（第四轮）｜ 状态：核心闭环全部落地，剩余项为运营动作与数据积累
> 📎 详细计划：[01-本地生活GEO改造与优化完善计划.md](./01-本地生活GEO改造与优化完善计划.md)

## 一、一句话总结

**系统已从"通用品牌 GEO 引擎"完成本地生活化改造**：门店档案 → 位置服务 → 附近双榜 → 本地关键词/问法 → 归因闭环 → 商业闭环，六层全部打通。当前可服务实体餐饮老板的完整本地曝光链路。

## 二、实施明细（按轮次）

| 轮次 | 内容 | 关键交付 |
|---|---|---|
| **第一轮** | 本地化地基 | 门店档案域（迁移 028）+ 高德位置服务（GeoLocator/POISearcher + mock 降级）+ 附近同行双榜 + 内容 NAP 注入 + JSON-LD LocalBusiness + 发布地址行（迁移 029）+ 前端"附近同行"页 |
| **第二轮** | 归因闭环 | 引用来源追踪（迁移 030：Sources/SelfSourceCount）+ 归因卡片 + 诊断→优化闭环 + 行动建议规则引擎 + 趋势降噪 |
| **第三轮** | 商业闭环收口 | 配额语义修正（LLM 调用次数计量）+ 新场景计量（nearby/diagnose）+ 成本分析端点（收入 vs 成本双报表）+ 内容引用统计（P5-02 校准基础设施） |
| **第四轮（本轮）** | 本地化补全 + 收尾 | 本地意图关键词生成（城市/区注入）+ 本地监测问法（"望京附近有什么川菜馆"）+ admin 成本分析展示 + P4 实验清单 |

## 六、技术账本（本轮累计）

- 新增迁移：028（门店）、029（发布地址）、030（引用来源）
- 新增适配器：`adapter/geo`（高德地理编码 + POI 搜索 + mock 降级）
- 新增用例：StoreLocation / Nearby / Advice / Citation
- 新增端点：门店 CRUD×5、附近双榜、行动建议、引用统计、成本分析
- 新增配置：`AMAP_API_KEY`、`LLM_COST_PER_MToken`
- 测试：全量 `go test ./...` 通过；前端 `tsc` + `vite build` 通过；`go vet` 干净

## 七、运维提醒

- 高德 Key 免费额度（个人开发者日配额约 5000 次）：**商用需核实商业授权条款**
- `LLM_COST_PER_MToken` 按实际模型单价配置，成本报表才有参考意义
- 生产部署需配置 `PUBLIC_BASE_URL` 为公网域名，归因（self_source_count）依赖该域名匹配
