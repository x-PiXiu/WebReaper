## 五、整洁架构合规度基线

### 5.1 依赖规则（Dependency Rule）

```
handler → usecase → domain/entity     ✅
handler → usecase/port                ✅
adapter/repository → domain/entity    ✅
adapter/provider → usecase/port       ✅
domain/entity → (无外部依赖)           ✅
```

### 5.2 依赖倒置（DIP）执行度

| 领域 | 接口定义方 | 实现方 | 倒置质量 |
|------|-----------|--------|---------|
| 生成任务仓储 | `usecase/port` | `adapter/repository` | ⭐⭐⭐ |
| 生成服务商 | `usecase/port` | `adapter/provider` | ⭐⭐⭐ |
| 端点策略 | `usecase/port` | `adapter/viduendpoint` | ⭐⭐⭐ |
| 发布通道 | `usecase/port` | `adapter/publisher` | ⭐⭐⭐ |
| AI 生成器 | `usecase/port` | `adapter/ai` | ⭐⭐⭐ |
| 媒体存储 | `usecase/port` | `adapter/storage` | ⭐⭐⭐ |
| 缓存 | `usecase/port` | `adapter/cache` | ⭐⭐⭐ |
| 分布式锁 | `usecase/port` | `adapter/lock` | ⭐⭐⭐ |
| 支付网关 | `usecase/port` | `adapter/payment` | ⭐⭐⭐ |

### 5.3 开闭原则（OCP）实践

- 新增生成端点 = 新增 `EndpointAdapter` 实现 + 注册一行
- 新增发布平台 = 实现 `PublishChannel` 接口 + `channelRegistry.Register()` 一行
- 新增定时任务 = 实现 `port.ScheduledTask` + `taskScheduler.Register()` 一行
- 新增爬虫工具 = 实现 `port.CrawlerTool` + `toolRegistry.Register()` 一行

### 5.4 降级链完备性

| 场景 | 降级路径 |
|------|---------|
| Redis 连接失败 | → NoopLock / 内存 nonce / 无缓存 |
| DB 未配置 | → mock 仓储 |
| LLM 未配置 | → mock AI |
| Vidu 未配 Key | → MockProvider（前端全流程可演示） |
| ffmpeg 不可用 | → 降级路径（≤25MB 视频直传 ASR） |
| 高德未配 Key | → mock 降级（门店 pending，附近同行仅 AI 榜） |
