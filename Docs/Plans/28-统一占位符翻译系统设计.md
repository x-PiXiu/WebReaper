# 28 - 统一占位符翻译系统设计

> 日期：2026-08-31
> 定位：**架构设计文档**——统一处理生成任务中的提示词占位符引用（@素材/@主体/${变量}）
> 背景：Vidu 参考生视频支持 `@主体name` 引用已注册主体，未来其他厂商也可能有类似机制。
> 当前 `translateRefs` 只处理素材引用，未处理主体引用，且不支持厂商差异。

---

## 一、问题分析

### 1.1 当前 @引用 处理

```go
// prompt_translator.go:22-34
func translateRefs(subType string, cap entity.ModelCapability, params entity.GenerationParams, refs []entity.PromptRef) (entity.GenerationParams, error) {
    // ① prompt 中 @名称 → 纯名称（去除引用语法）
    if prompt, ok := params["prompt"].(string); ok && prompt != "" {
        for _, r := range refs {
            if r.Name != "" {
                prompt = strings.ReplaceAll(prompt, "@"+r.Name, r.Name)  // ❌ 直接替换为纯名称
            }
        }
        params["prompt"] = prompt
    }
    // ② 按类型聚合引用（image/audio/video）
    // ...
}
```

**问题**：
- `@名称` 被替换为纯名称，丢失了引用语义
- 没有处理 `@主体name` 引用
- 不同厂商的占位符语法不同，当前设计无法扩展

### 1.2 Vidu 的 @主体 引用

根据 Vidu 官方文档（`Docs/第三方/Vidu/创建视频任务/参考生视频.md`）：

```json
{
    "subjects": [
        {"name": "主体A", "server_id": "xxx"},
        {"name": "主体B", "server_id": "yyy"}
    ],
    "prompt": "@主体A 和 @主体B 在一起吃火锅"
}
```

**关键点**：
- `subjects[].name` 是引用标识
- prompt 中用 `@name` 引用主体
- Vidu 内部将 `@name` 替换为主体内容

### 1.3 链式形象视频 prompt 硬编码

```go
// avatar_chain.go:26
const defaultAvatarVideoPrompt = "形象展示：正面特写，微笑看向镜头，姿态自然大方，缓慢自然的肢体动作"
```

**问题**：
- 兜底值硬编码在代码中
- 用户无法自定义形象视频描述
- 应从 `system_settings` 读取默认值

## 二、设计方案

### 2.1 设计思路

```
┌─────────────────────────────────────────────────────────────────┐
│                    统一占位符翻译层                               │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  输入：prompt + refs + subjects                                 │
│    │                                                            │
│    ▼                                                            │
│  ① 解析占位符（@名称 / @主体name / ${variable}）                │
│    │                                                            │
│    ▼                                                            │
│  ② 按类型分类                                                   │
│    ├─ 素材引用（image/audio/video）→ 翻译为端点参数              │
│    ├─ 主体引用（subject）→ 翻译为 subjects 数组 + 保留 @name    │
│    └─ 变量引用（${var}）→ 替换为实际值                           │
│    │                                                            │
│    ▼                                                            │
│  ③ 输出：翻译后的 params（含 subjects + 清理后的 prompt）        │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 2.2 核心接口

```go
// PlaceholderType 占位符类型。
type PlaceholderType string

const (
    PlaceholderTypeMaterial PlaceholderType = "material" // @图片/@音频/@视频
    PlaceholderTypeSubject  PlaceholderType = "subject"  // @主体name
)

// Placeholder 占位符解析结果。
type Placeholder struct {
    Raw  string          // 原始文本（如 "@主体A"）
    Type PlaceholderType // 类型
    Name string          // 名称（如 "主体A"）
    Ref  *entity.PromptRef // 关联的素材引用（仅 material 类型）
}

// ProviderPlaceholderRule 厂商占位符规则。
type ProviderPlaceholderRule struct {
    KeepSubjectRef bool // 是否在 prompt 中保留 @name（Vidu=true）
}
```

### 2.3 翻译流程

```go
// Translate 翻译占位符。
func (t *PlaceholderTranslator) Translate(
    ctx context.Context,
    provider string,
    subType string,
    params entity.GenerationParams,
    refs []entity.PromptRef,
    tenantID string,
) (entity.GenerationParams, error) {
    prompt, _ := params["prompt"].(string)
    if prompt == "" {
        return params, nil
    }

    // ① 解析 @名称 占位符
    matches := placeholderRegexp.FindAllStringSubmatch(prompt, -1)

    // ② 分类：素材引用 vs 主体引用
    // 素材引用：在 refs 中有对应的 PromptRef
    // 主体引用：在 refs 中没有，可能是已注册的主体名称

    // ③ 处理素材引用
    if len(materialRefs) > 0 {
        params, _ = translateRefs(subType, cap, params, materialRefs)
    }

    // ④ 处理主体引用（按厂商规则）
    if len(subjectNames) > 0 {
        rule := t.providerRules[provider]
        if rule.KeepSubjectRef {
            // Vidu 模式：保留 @name，添加 subjects 数组
            params["subjects"] = buildSubjectsArray(subjects)
        } else {
            // 其他厂商模式：移除 @name
            prompt = removeSubjectPlaceholders(prompt, subjectNames)
            params["prompt"] = prompt
        }
    }

    return params, nil
}
```

### 2.4 厂商规则注册表

```go
// 默认规则
var defaultProviderRules = map[string]ProviderPlaceholderRule{
    "vidu":        {KeepSubjectRef: true},   // Vidu 需要 @name 引用
    "xiaomi-mimo": {KeepSubjectRef: false},  // MiMo 不需要
}

// 扩展新厂商
func (t *PlaceholderTranslator) RegisterRule(provider string, rule ProviderPlaceholderRule) {
    t.providerRules[provider] = rule
}
```
