## 1. 硬编码数据 × 服务端逻辑核查总表

对客户端全部硬编码业务数据逐项核查服务端现状（结论 = 当前仓库代码，非部署实例）：

| # | 前端位置 | 硬编码内容 | 服务端现状 | 处置 |
|---|---|---|---|---|
| 1 | AvatarModule `OFFICIAL_SHOWCASE` | 官方主体 5 张静态样例卡 | **无**：无 `/subjects` 列表路由，Vidu 适配器只有创建主体（`endpoints.go:401`），`GenerationProvider` 接口无 list subjects | 保留静态 + 区块标注「接入中」；待后端缓存代理端点（问题反馈 #1） |
| 2 | AssetLibrary `SYSTEM_SHOWCASE` | 系统素材 3 条静态示例 | **无**：MediaAsset 无 ownership/system 字段，`GET /media/assets` 仅 owner 过滤 | 保留静态；待后端系统素材概念（非口播优先） |
| 3 | AssetLibrary `QUOTA_LIMIT=200` | 素材额度上限 | **无**：`/billing/usage` 的 scene 集合无 media/素材场景（pro 的 200 是每月生成次数） | 保留展示；待后端素材配额端点 |
| 4 | wizardModel `CAPABILITY_FALLBACK` | 平台×形态能力兜底矩阵 | **已全量下发**：`ChannelConstraints` 含 title_max_runes/min_images/min_videos/require_tags/require_category/max_tags；`ChannelInfo.auto` + `auto_content_types` 在列 | **本次删除**——服务端为唯一事实源，未下发即「无约束」，不前端虚构 |
| 5 | wizardModel `BILIBILI_CATEGORIES` | B站 12 个分区 | **无**：渠道约束无分区枚举，B站适配器只声明约束值 | 保留前端（已注释标注），待服务端配置化 |
| 6 | copyTemplates `COPY_TEMPLATES` | 6 套文案模板正文 | **部分**：`/generation/templates` 是生成参数模板（DB 驱动、admin 建），非文案正文模板 | 保留（内容创作域，口播优先级之外） |
| 7 | generatePromptChips | 8 条提示词快填 | **无** | 保留（内容创作域） |
| 8 | LipSyncWizard `STAGES` | 按耗时轮播的提取阶段提示 | **无**：转写任务仅 `pending/done/error` 三态，无 stage/progress 字段 | 保留模拟（注释已标注）；待后端阶段字段 |
| 9 | LipSyncWizard `produceEta` | 写死的成片预计耗时 | **无** | 保留（经验值） |
| 10 | VoiceModule 推荐 = `slice(0,12)` | 音色推荐=本地截断 | **无推荐标记**：`generation_voices` 表仅 voice_id/language/name/sample_url 四列 | 保留；待后端加 recommend/featured 字段 |
| 11 | （无——本次新接） | 生成中取消 | **有**：`POST /generation/tasks/:id/cancel` 真实取消（上游尽力取消 + 本地置 cancelled） | **本次接入**向导生成中页取消按钮 |
| 12 | BrollDrawer `accept="video"` | 片段仅视频 | **服务端已支持图片**：compose 对图片 URL 按 `LoopImageToVideo` 转窗口时长视频（`compose.go:169-193`） | **本次放开**：片段选择器支持图片+视频（新增 `visual` 类型） |
| 13 | （无——本次新接） | compose 产物展示 | **部分**：任务视图带 sub_type/params 可推导血缘；但 `ListWorks.deliverableSubTypes` **不含 compose**，compose 成片不进服务端作品库 | **本次前端补齐**（从生成任务追加，按 id 去重）；建议服务端补 deliverableSubTypes + 顶层 parent_task_id |
| 14 | （预览缺位） | 分身形象视频预览 | **无**：subject 是同步端点，注册即 success；无链式形象视频任务，无形象视频 URL 回写（creations 仅 server_id） | 待后端链式形象视频（23 号 §2.1②）落地后补预览与「形象视频生成中」态 |
| 15 | （状态缺位） | 分身三态徽标 | **无中间态**：state 枚举无「主体已注册但形象视频生成中」 | 徽标维持 创建中/失败/可用；链式上线后加第三态 |

**结论**：15 项中 3 项服务端已具备（#4/#11/#12）——本次全部接通或删除兜底；
其余 12 项服务端无对应逻辑，前端保留静态/降级并已在代码注释与本表标注，避免误当真实数据。

## 2. 与 23 号文档的偏差 · 本次修复

### 2.1 已修复（本次提交）

| 偏差（23 号文档要求 → 此前实现） | 修复内容 |
|---|---|
| §2.1③ 创建表单缺「场景图+场景描述」 | CreateSubjectModal 补可选场景图上传（带"露脸/无分镜"警示）+ 场景描述输入；payload 以 `params.scene_image/scene_description` 先行提交（服务端接住即生效） |
| 「场景主体」概念与口播主流程无关（产品决策：首要是口播） | **整体删除**：CreateSubjectModal 的 Segmented、subjectTask 的 kind 字段、SubjectCard 场景标签、AvatarModule 场景徽标 |
| §2.3 分身管理页应为「上官方区+下我的区」两分区 | AvatarModule 由 Tab（全部/我的/推荐）重构为两分区；官方区静态样例+「接入中」标注；我的区保留搜索/批量删除 |
| §3.1 文案区应逐句（一行一句，句=插入点心智铺垫） | 新组件 `ScriptLinesEditor`：逐行编辑/增删句、粘贴多行自然拆句、句数统计；替换向导第①步 TextArea |
| §3.1 润色应显式可选+需求输入（此前提取后自动调用且无需求输入） | 提取结果原样逐句进编辑器不自动润色；「AI 润色」改 Popover 输入一句话需求（暂拼入 topic 字段，待服务端加独立参数） |
| §4.1 生成中页应可取消 | 接入 `POST /tasks/:id/cancel`：管线新增 `onTaskSubmit` 回调跟踪活动任务，取消后友好提示「已完成阶段产物保留，可断点重试」 |
| §5.1 片段选择应支持视频/图片（此前仅视频） | AssetPicker 新增 `visual` 类型（图+盘库+生成产物合并）；BrollDrawer 放开；提示文案同步 |
| §5.1 合成后应可「以新成片为源再调整」（此前只有提示文案） | BrollDrawer 合成完成后提供「对新成片继续插入」链式入口（时间轴服务端已自动继承）+「回到源片」视角切换 |
| §6.2/§8#7 作品卡应显示 B-Roll 标记 | MyWorks 按 compose 血缘显示两档徽标：compose 产物「B-Roll」、被插过画面的源片「已插画面」 |
| §8#7 作品库应含 compose 产物（服务端 ListWorks 暂不含） | 前端从生成任务追加 compose 成片到作品列表（标题取合成台词首句，按 id 去重，服务端补上后自动融合） |
| 发布能力兜底矩阵已过时（服务端全量下发） | 删除 `CAPABILITY_FALLBACK`；`effectiveConstraints`/`supportsAutoForm` 纯服务端驱动 |
| `CREATIVE_CDN.avatars` 死代码 | 删除 |
