## 二、详细改动

### 2.1 B-Roll 插入语义修复（29 号计划落地）

| 改动 | 文件 | 说明 |
|------|------|------|
| eof_action=pass | `mediaav/compose.go` | 短片段播完透出原片（不冻结最后一帧）——实测 4.5s 处从纯红变原片 |
| 长片段窗口扩展 | `mediaav/compose.go` | E = max(句末, S+片段时长)——8s 蓝片在句末后持续播放 |

| 向导五步式 | `LipSyncWizard.tsx` | ① 文案 → ② 出镜配音 → ③ B-Roll 配置 → ④ 生成 → ⑤ 发布 |
| 音频两模式 | `LipSyncWizard.tsx` | 文本配音（默认）/ 上传音频——移除独立 TTS 步骤 |

### 2.2 音色白牌化（用户确认 2026-09-01）

**核心决策**：用户端不再暴露任何上游 Vidu 内容，全部改为平台自建。

| 改动 | 说明 |
|------|------|
| `port.VoiceLibrary` 接口拆分 | ListForUser（scope=platform + 本租户 clone）vs ListForAdmin（全量含 vidu 参考源） |
| 083 迁移 | generation_voices 加 is_default 列 |
| applyDefaultVoice | 改读平台默认音色（不再硬编码 female-shaonv） |
| 管理后台三新端点 | POST /admin/voices/from-vidu（Vidu 克隆）/ GET /admin/voices/vidu-sources / PUT /admin/voices/:id/default |
| 前端 VoicePicker | 分组简化：★精选 > 🎤平台音色 > 我的克隆（无 Vidu 语言分组） |
| E2E 实测 | 用户端 4 条音色（1 默认 platform + 1 新克隆 + 2 clone），零 Vidu 暴露 |

### 2.3 管理后台重组（22 页 → 9 页）

```
新菜单结构（3 组 8 项）：
📊 运营管理
  /admin            → 平台总览（Dashboard + 健康卡片）
  /admin/tenants    → 商户与品牌（Users + Brands + Contents 三 Tab）
  /admin/assets     → 平台资产（Subjects + Voices 两 Tab）
  /admin/billing    → 计费管理
⚙️ 内容引擎
  /admin/engine     → 引擎配置（Agent + 模板 + 提示词 + 知识库 + 提交 五 Tab）
  /admin/chat       → AI 对话（Admin Tools 快捷操作）
🔧 系统配置
  /admin/system     → 系统设置（Settings + Integrations + TaskMonitor 三 Tab）
  /admin/crawler    → 爬虫管理（账号 + 配置 + 任务 + 灵感 四 Tab）
```

- 5 个新复合页 lazy import 原子页面
- 19 条旧路由 Navigate 重定向（零断链）
- 原子页面统一加 `embedded` prop（嵌入时去外壳）
