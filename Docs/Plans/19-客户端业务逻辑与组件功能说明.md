## 一、全局架构

### 1.1 数据流

```
用户操作 → React 组件 → API 调用（Axios） → 服务端
                ↑                                    ↓
          状态更新 ← Zustand Store ← React Query ← JSON 响应
```

### 1.2 状态管理

| Store | 持久化 | 用途 |
|---|---|---|
| `useAuthStore` | localStorage | JWT token、用户名、角色、租户 ID |
| `useBrandStore` | localStorage | 当前选中品牌 ID |
| `useComposeDraft` | localStorage | 创作流程全部中间状态（文案/音频/视频/封面） |
| `useThemeStore` | localStorage | 深色/浅色主题 |

### 1.3 API 层

所有 API 调用通过 `api/client.ts` 的 Axios 实例：
- 自动注入 `Authorization: Bearer <token>`
- 响应自动解包 `{code, msg, data}` 信封
- 401 自动跳转登录
- 402 配额超限弹窗
- 错误自动 toast 提示

### 2.1 统一生成（Generation）

#### 业务逻辑

用户通过「傻瓜式」界面提交生成任务，系统自动选择端点和模型：

```
用户输入：文本 + 素材（可选）+ 高级参数（可选）
  ↓
前端：submitUnified(payload)
  ↓
后端：EndpointSelector 自动选择端点 → 选模型 → 提交 Vidu
  ↓
前端：轮询任务状态 → 展示结果
```

#### 组件需求

**`GenerationSubmitter` 组件**：

| 功能 | 说明 | API |
|---|---|---|
| 文本输入 | 多行文本框，支持 @引用 语法 | — |
| 素材选择 | `AssetPicker` 组件，支持图片/音频/视频 | `GET /media/assets` |
| 模型选择 | 下拉框（可选，默认自动） | `GET /generation/types` |
| 音色选择 | `VoicePicker` 组件（TTS 时显示） | `GET /generation/voices` |
| 高级参数 | 折叠面板：seed/style/duration/resolution/aspect_ratio | — |
| 提交按钮 | 调用 `submitUnified` | `POST /generation/submit` |
| 任务状态 | 实时轮询，显示进度 | `GET /generation/tasks/:id` |
| 结果展示 | 视频播放器 / 图片预览 / 音频播放器 | — |

**前端校验**：
```typescript
function validateGenerationInput(payload: UnifiedSubmitPayload): string[] {
  const errors: string[] = [];
  if (!payload.text || payload.text.trim() === '') {
    errors.push('请输入文本描述');
  }
  if (payload.text && payload.text.length > 5000) {
    errors.push('文本不能超过 5000 字符');
  }
  return errors;
}
```

**上传校验**：
```typescript
const UPLOAD_RULES = {
  image: { maxSize: 20 * 1024 * 1024, formats: ['.png', '.jpg', '.jpeg', '.webp'] },
  audio: { maxSize: 20 * 1024 * 1024, formats: ['.mp3', '.m4a', '.wav'] },
  video: { maxSize: 200 * 1024 * 1024, formats: ['.mp4', '.webm', '.mov'] },
};

function validateUpload(file: File): string | null {
  const ext = '.' + file.name.split('.').pop()?.toLowerCase();
  const type = getMediaType(ext);
  const rules = UPLOAD_RULES[type];
  if (!rules) return `不支持的文件格式: ${ext}`;
  if (file.size > rules.maxSize) return `文件超过 ${rules.maxSize / 1024 / 1024}MB 上限`;
  return null;
}
```

```typescript
async function startQRLogin(platform: string) {
  // 1. 启动扫码
  const { session_id, qr_image } = await businessApi.startQRLogin({ platform });

  // 2. 显示二维码
  showQRModal({ qrImage: qr_image, sessionId: session_id });

  // 3. 轮询扫码状态
  const result = await pollQRStatus(session_id);
  if (result.status === 'success') {
    message.success('绑定成功');
    refreshAccounts();
  } else if (result.status === 'expired') {
    message.warning('二维码已过期，请重新扫码');
  }
}

async function pollQRStatus(sessionId: string) {
  for (let i = 0; i < 60; i++) { // 最多 2 分钟
    const result = await businessApi.pollQRLogin(sessionId);
    if (result.status !== 'waiting') return result;
    await sleep(2000);
  }
  return { status: 'expired' };
}
```

**发布确认流程**：
```typescript
async function handlePublish(publishData) {
  // 1. 校验
  const errors = validatePublishInput(publishData);

    showError(errors.join('\n'));
    return;
  }

  // 2. 提交
  const result = await businessApi.publishContent(publishData);

  // 3. 轮询状态
  if (result.mode === 'auto') {
    await pollPublishStatus(result.id);
  } else {
    // link 降级：显示手动发布弹窗

}
```

## 六、错误处理规范

### 6.1 API 错误

```typescript
// 统一错误处理（Axios 拦截器已实现）
// 业务代码中按需补充
function handleApiError(error: ApiError) {
  switch (error.code) {
    case 40000: // 参数校验
      message.error(error.msg);
      break;
    case 40100: // 未授权
      authStore.clearAuth();
      navigate('/login');
      break;
    case 40201: // 配额超限
      showQuotaUpgradeModal();
      break;
    case 400: // 生成失败
      message.error(friendlyGenerationError(error.msg));
      break;
    default:
      message.error(error.msg || '操作失败');
  }
}
```
