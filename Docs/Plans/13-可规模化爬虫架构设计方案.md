# 13 - 可规模化爬虫架构设计方案

> 日期：2026-08-24 | 状态：待开发 | 优先级：P1
> 参考：MediaCrawler 项目架构分析

## 一、MediaCrawler 设计思想提炼

### 1.1 核心设计哲学

MediaCrawler 的成功不在于它写了多少平台爬虫，而在于它的**架构让新增平台的成本极低**。提炼出 6 个核心设计思想：

| # | 设计思想 | MediaCrawler 实现 | WebReaper 借鉴 |
|---|----------|-------------------|----------------|
| 1 | **抽象工厂 + 策略模式** | `AbstractCrawler` → 7 个平台实现 | `CrawlerPlatform` 接口 → 多平台 |
| 2 | **接口归内层，实现在外层** | `base/` 定义接口，`media_platform/` 实现 | `usecase/port` 定义接口，`adapter/` 实现 |
| 3 | **配置驱动行为** | `base_config.py` + 平台 config | DB 驱动的 `crawler_configs` 表 |
| 4 | **反爬是一等公民** | CDP/stealth/签名/代理/限速 五层防护 | CDP + 限速 + Cookie 管理 |
| 5 | **存储可插拔** | 8 种存储后端，Factory 选择 | 统一 `InspirationRepository` |
| 6 | **渐进式降级** | API 失败 → 浏览器降级 → 通用搜索兜底 | 同样的降级链路 |

### 1.2 MediaCrawler 的爬虫编写模式

每个平台爬虫由 5 个文件组成（统一模式）：

```
media_platform/douyin/
├── core.py      ← 主爬虫（编排整个流程）
├── client.py    ← API 客户端（HTTP 请求 + 签名）
├── login.py     ← 登录策略（二维码/手机/Cookie）
├── field.py     ← 枚举常量（搜索频道、排序、时间过滤）
└── help.py      ← 工具函数（URL 解析、签名辅助）
```

**关键洞察**：`core.py` 是编排者，`client.py` 是执行者。core 不关心 HTTP 细节，client 不关心业务流程。这种分离让每个平台的"怎么搜"和"搜什么"解耦。

### 1.3 WebReaper 的优势

WebReaper 已经有了 MediaCrawler 的核心骨架：

| MediaCrawler | WebReaper 现有 | 差距 |
|---|---|---|
| `AbstractCrawler` | `port.SocialSearcher` | ✅ 接口已定义 |
| `media_platform/douyin/` | `adapter/douyinweb/` | ✅ 抖音已实现 |
| `base_config.py` | `config/base_config.py` | ⚠️ 缺少爬虫动态配置 |
| CDP 模式 | chromedp | ⚠️ 需升级为 CDP 连接真实浏览器 |
| 7 个平台 | 1 个平台（抖音） | ⚠️ 需加快手、B站 |
| Admin 控制 | 无 | ❌ 需新建 |

### 2.2 核心接口设计

#### `port.CrawlerPlatform` — 平台爬虫接口

```go
// CrawlerPlatform 社交媒体平台爬虫接口。
//
// 设计（策略模式）：每个平台实现此接口，用例层通过平台名动态选择。
// 新增平台 = 新增 adapter 实现 + 注册一行，用例零改动。
type CrawlerPlatform interface {
    // Platform 返回平台标识（"douyin"/"kuaishou"/"bilibili"）。
    Platform() string

    // Search 关键词搜索热门视频。
    Search(ctx context.Context, opts SearchOptions) ([]CrawledVideo, error)

    // GetDetail 获取单个视频详情（含完整互动数据）。
    GetDetail(ctx context.Context, videoID string) (*CrawledVideo, error)

    // RefreshMetrics 批量刷新视频的实时指标（播放量/点赞/评论等）。
    RefreshMetrics(ctx context.Context, videoIDs []string) ([]MetricsUpdate, error)

    // IsAlive 检测平台连接是否正常（Cookie 有效性）。
    IsAlive(ctx context.Context) bool

    // GetCapabilities 返回平台支持的能力（搜索/详情/评论/刷新）。
    GetCapabilities() PlatformCapabilities
}

// SearchOptions 搜索选项。
type SearchOptions struct {
    Keyword     string // 搜索关键词
    Limit       int    // 结果数量限制
    SortBy      string // 排序：popular/latest
    PublishTime string // 时间过滤：day/week/month/all
    Offset      int    // 分页偏移
}

// CrawledVideo 爬取到的视频数据（平台无关）。
type CrawledVideo struct {
    Platform       string    // 平台标识
    VideoID        string    // 平台视频 ID
    Title          string    // 标题
    Description    string    // 描述/文案
    CoverURL       string    // 封面 URL
    VideoURL       string    // 视频链接
    Author         string    // 作者名称
    AuthorAvatar   string    // 作者头像
    Duration       int       // 时长（秒）
    PublishTime    time.Time // 发布时间
    PlayCount      int64     // 播放量
    DiggCount      int64     // 点赞数
    CommentCount   int64     // 评论数
    ShareCount     int64     // 分享数
    CollectCount   int64     // 收藏数
    Topics         []string  // 话题标签
    MusicName      string    // 背景音乐
    MusicAuthor    string    // 音乐作者
}

// MetricsUpdate 指标更新（用于实时刷新）。
type MetricsUpdate struct {
    VideoID      string
    PlayCount    int64
    DiggCount    int64
    CommentCount int64
    ShareCount   int64
    CollectCount int64
}

// PlatformCapabilities 平台能力声明。
type PlatformCapabilities struct {
    SupportSearch    bool // 支持关键词搜索
    SupportDetail    bool // 支持视频详情
    SupportComments  bool // 支持评论获取
    SupportRefresh   bool // 支持指标刷新
    SupportCreator   bool // 支持创作者主页
    MaxSearchLimit   int  // 单次搜索最大结果数
    RateLimitPerMin  int  // 每分钟请求限制
}
```

#### `port.CrawlerManager` — 爬虫管理器接口

```go
// CrawlerManager 爬虫管理器（管理后台动态控制）。
type CrawlerManager interface {
    // GetPlatform 获取平台爬虫实例。
    GetPlatform(ctx context.Context, platform string) (CrawlerPlatform, error)

    // ListPlatforms 列出所有已注册的平台。
    ListPlatforms(ctx context.Context) []PlatformInfo

    // GetConfig 获取平台爬虫配置。
    GetConfig(ctx context.Context, platform string) (*CrawlerConfig, error)

    // UpdateConfig 更新平台爬虫配置（热生效）。
    UpdateConfig(ctx context.Context, platform string, config CrawlerConfig) error

    // GetTaskStatus 获取采集任务状态。
    GetTaskStatus(ctx context.Context, taskID string) (*TaskStatus, error)

    // TriggerCrawl 手动触发采集。
    TriggerCrawl(ctx context.Context, brandID string, force bool) (string, error)
}

// CrawlerConfig 爬虫配置（DB 驱动，管理后台可改）。
type CrawlerConfig struct {
    Platform         string   `json:"platform"`
    Enabled          bool     `json:"enabled"`
    SearchKeywords   []string `json:"search_keywords"`   // 基础搜索关键词
    ExtraKeywords    []string `json:"extra_keywords"`    // 额外关键词（管理后台配置）
    CrawlInterval    int      `json:"crawl_interval"`    // 采集间隔（小时）
    MaxResults       int      `json:"max_results"`       // 单次最大结果数
    SortBy           string   `json:"sort_by"`           // 默认排序
    PublishTime      string   `json:"publish_time"`      // 默认时间过滤
    EnableComments   bool     `json:"enable_comments"`   // 是否采集评论
    EnableRefresh    bool     `json:"enable_refresh"`    // 是否刷新旧数据
    RefreshInterval  int      `json:"refresh_interval"`  // 刷新间隔（小时）
    CookieAccountID  string   `json:"cookie_account_id"` // 使用的 Cookie 账号
    RateLimitPerMin  int      `json:"rate_limit_per_min"` // 每分钟请求限制
    ProxyEnabled     bool     `json:"proxy_enabled"`     // 是否启用代理
    MaxRetryCount    int      `json:"max_retry_count"`   // 最大重试次数
}
```

### 2.4 CDP 浏览器管理器

```go
// CDPBrowserManager Chrome DevTools Protocol 浏览器管理器。
//
// 设计动机（参考 MediaCrawler 的 CDP 模式）：
//   - 连接用户已运行的 Chrome 浏览器（端口 9222），使用真实指纹
//   - 或启动新的 Chrome 实例（带 --remote-debugging-port）
//   - 管理多个平台的 Cookie 注入/提取
//   - 复用浏览器上下文，避免每次搜索都开新浏览器
type CDPBrowserManager struct {
    debugPort  int
    mu         sync.Mutex
    contexts   map[string]*rod.Browser // platform → browser instance
    cookies    map[string][]*http.Cookie // platform → cookies
}

// Connect 连接到已运行的 Chrome 实例。
func (m *CDPBrowserManager) Connect(ctx context.Context, platform string) (*rod.Browser, error)

// Launch 启动新的 Chrome 实例。
func (m *CDPBrowserManager) Launch(ctx context.Context, platform string) (*rod.Browser, error)

// InjectCookies 向浏览器注入 Cookie。
func (m *CDPBrowserManager) InjectCookies(ctx context.Context, platform string, cookies []*http.Cookie) error

// ExtractCookies 从浏览器提取当前 Cookie。
func (m *CDPBrowserManager) ExtractCookies(ctx context.Context, platform string) ([]*http.Cookie, error)

// Close 关闭浏览器连接。
func (m *CDPBrowserManager) Close(platform string)
```

## 四、平台爬虫实现策略

### 4.1 抖音（复用现有 douyinweb）

| 现有组件 | 复用方式 |
|----------|----------|
| `douyinweb.Searcher.SearchHotVideos` | 核心搜索逻辑直接复用 |
| `douyinweb.Searcher.withSearchPage` | CDP 页面管理复用 |
| `douyinweb.Searcher.xhrSyncJS` | XHR 同步请求复用 |
| `douyinweb.Searcher.pickCookie` | Cookie 选择逻辑复用 |

**升级点**：
- 封装为 `CrawlerPlatform` 接口
- 新增 `RefreshMetrics` 方法（批量刷新视频指标）
- 新增 `GetCapabilities` 声明
- 去掉 LLM curate 依赖

### 4.2 快手（新增）

快手使用 GraphQL API，参考 MediaCrawler 的 `media_platform/kuaishou/`：

```
搜索流程：
1. CDP 打开 kuaishou.com/search/video?keyword=xxx
2. 注入 Cookie
3. 拦截 GraphQL 请求：visionSearchPhoto
4. 解析响应 → []CrawledVideo
```

关键 API：
- 搜索：`/graphql` → `visionSearchPhoto` mutation
- 详情：`/graphql` → `photoDetail` query
- 参数：`keyword`, `pcursor`（分页）, `page`（结果页码）

### 4.3 B站（新增）

B站 API 相对开放，参考 MediaCrawler 的 `media_platform/bilibili/`：

```
搜索流程：
1. 直接 HTTP 请求（B站 API 反爬较松）
2. GET https://api.bilibili.com/x/web-interface/search/type
3. 参数：keyword, search_type=video, order=click, page=1
4. 解析响应 → []CrawledVideo
```

关键 API：
- 搜索：`/x/web-interface/search/type` (search_type=video)
- 详情：`/x/web-interface/view?bvid=xxx`
- 无需浏览器自动化，纯 HTTP 即可

### 4.4 平台能力矩阵

## 五、管理后台动态控制设计

### 5.1 配置热生效机制

```
管理后台修改配置
  → API 保存到 crawler_configs 表
  → CrawlerManager.UpdateConfig() 被调用
  → 内存中的 CrawlerConfig 热更新
  → 下次定时任务执行时使用新配置
  → 无需重启服务
```

### 5.2 任务监控

```
定时任务执行
  → 创建 crawler_task_logs 记录（status=running）
  → 执行采集逻辑
  → 更新记录（status=success/failed, videos_found, duration_ms）
  → 管理后台可实时查看
```

### 5.3 Cookie 管理

```
管理后台 → Cookie 管理页面
├── 查看所有平台的 Cookie 状态
├── Cookie 过期提醒
├── 一键刷新 Cookie（打开浏览器重新登录）
└── Cookie 账号选择（多账号轮换）
```

## 七、风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| CDP 连接不稳定 | 爬虫失败 | 自动重连 + 浏览器健康检查 |

| 数据量增长 | 存储压力 | 30 天自动清理 + 按品牌分页 |
