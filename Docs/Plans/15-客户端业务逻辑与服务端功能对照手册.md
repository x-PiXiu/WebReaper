## 一、客户端页面全景与业务逻辑

### 1.1 页面路由清单

| 路由 | 页面 | 核心业务 |
|------|------|---------|
| `/m/home` | Home | 四步引导（找对标→写稿→成片→发布）、热力地图占位 |
| `/m/compose` | ComposeHub | 创作中心：video（拍口播）/ graphic（发图文）双轨 |
| `/m/compose/lipsync` | LipSyncWizard | 口播向导五步（傻瓜式主路径） |
| `/m/compose/quick` | QuickGenerate | 快速生成两步（选模板→传素材+一句话） |
| `/m/creation` | Creation | 高级生成（13 种端点模式卡片） |
| `/m/inspire` | InspirationPlaza | 灵感广场（爬虫爆款+本地转存播放+复刻） |
| `/m/distribution` | Distribution | 分发中心三 Tab（账号池/发布向导/发布记录） |
| `/m/works` | MyWorks | 作品库（三源聚合） |
| `/m/brands` | Brands | 品牌管理（含发布配置/发布历史/灵感 Tab） |
| `/m/assets` | AssetLibrary | 素材库（上传+数字分身创建） |

### 1.2 核心业务流程（当前实际状态）

**流程 A：口播视频生成（傻瓜式主路径）**

```
① 文案来源（粘贴抖音/B站链接提取 | 上传音视频 | 手写）
    → POST /generation/transcript/extract（服务端：下载→ffmpeg剥轨→ASR→按句分行）
    → POST /generation/transcript/rewrite（清洗版+改写版双产出）
② 确认文案（双版本切换+编辑，逐行一句显示）
③ 出镜方式（real 真人出镜上传视频 | avatar 数字分身选已注册主体）
④ 音色（VoicePicker，可不选=后端默认）
⑤ 成片（runLipSyncPipeline 三阶段自动：TTS→数字人/对口型→轮询取产物）
```

**流程 B：发布（五步向导）**

```
① 平台与形态（默认发视频；能力接口驱动过滤；账号卡片带配额）
② 标题正文（最严约束字数红线）
③ 素材（视频≤200MB上传 / 素材库 / AI成片）
④ 平台参数（B站分区标签必填、定时、模式）
⑤ 适配预览+完备性检查 → 提交（半自动链接/全自动RPA）
```

## 三、优化实现方案（按优先级）

### P0：对口型时长配平器（小改动，现有链路直接受益）

**方案**：`useLipSyncPipeline` TTS 完成后：
1. ffprobe 音频时长 T（服务端生成任务产物已带 URL，用 Go 侧 ffprobe）
2. 出镜视频 ffprobe 时长 V
3. `V < T` → ffmpeg `-stream_loop -1 -t T` 循环补足；`V > T` → `-t T` 截断
4. 配平后的视频 URL 传给 lip_sync

**实现位置**：`internal/usecase/generation/useLipSyncPipeline 对应服务端` = 新增 `mediaav.FFmpegTool.LoopVideo(ctx, path, targetDur)` 方法 + `useLipSyncPipeline.ts` 前端管线在 TTS 完成后调预备端点（或全部收在服务端统一提交内：selector 的 lip_sync 分支前置配平——**推荐后者**，客户端零改动）。

**服务端改动点**：
- `mediaav/ffmpeg.go`：加 `ProbeDuration` + `AdaptVideoDuration`（循环/截断）
- `endpoint_selector.go` buildLipSyncParams：video_url 是本站 URL 时先配平

### P1：长文案分段成片编排器（核心基建）

**方案**：向导第⑤步文案 >45 字时：
1. 按句分行结果（raw_text_lines 已有）按每段 ≤45 字聚组
2. 逐组提交 img2video/digital_human（≤16s/段）
3. 全部完成后 ffmpeg concat 拼接 + 转场（可选 crossfade）
4. 用户看到一个成片 + 进度"生成中（3/8 段）"

**实现位置**：
- 新文件 `internal/usecase/generation/segment_orchestrator.go`（编排器）
- `mediaav/ffmpeg.go` 加 `ConcatVideos(ctx, paths, out)`
- 前端 `PublishWizard` 无关——在 `useLipSyncPipeline` 第⑤步前挂编排

### P2：数字分身复用（subjects 一致性生成）

**方案**：向导第③步选分身（有 server_id）→ 提交 reference2video 携带 `subjects: [{server_id}]` → Vidu 以注册主体的形象/服装一致性生成
**实现位置**：
- `endpoint_selector.go` buildReference2VideoParams 加 subjects 参数读取
- `useLipSyncPipeline.ts` subjectServerId 传入 materials/params
- 主体 server_id 存储检索：资产 MetaJSON（AssetLibrary 创建时已存任务产物，需回填 MetaJSON）

### P3：音乐/音效生成（text2audio）

**方案**：接入 Vidu `/ent/v2/audio/text2audio`（音乐）端点 adapter + selector 分支 `type=music`
**实现位置**：
- `endpoints_media.go` 新增 text2audioAdapter
- `endpoint_selector.go` selectByType 加 music 分支
- 前端 Creation.tsx 卡片解禁

### P4：trending-replicate（爆款视频复刻）

**方案**：灵感广场"复刻"第二模式——爆款视频 URL（已本地转存更稳）+ 用户主体 → Vidu 复刻同款节奏
**实现位置**：
- `endpoints_media.go` 或新文件 replicateAdapter
- 灵感广场前端加"复刻风格"按钮
