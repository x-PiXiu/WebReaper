# 08 - 傻瓜式口播视频向导与生成域收敛计划

> **状态**：已确认（三轮 grilling 共识 + 08-23 补充 D7-D9），待开工
> **日期**：2026-08-22（初版）/ 2026-08-23（补充第三方集成中心与运营可观测）
> **前置**：03-Vidu全量接入统一生成架构（已合入，本计划在其上收敛）；会话内已完成的链路修复见附录 A

---

## 一、背景与定位

03 计划完成了 Vidu 全量接入（12 端点统一任务协议），但暴露两个问题：

1. **功能过宽**：12 个生成模式对目标用户（实体商家）认知负担过重，与"傻瓜式"定位冲突
2. **核心场景缺失**：用户真实旅程是"拍视频→写文案→配语音→对口型成片"，以及"建数字分身→分身出视频"，现有 UI 没有承载这条流水线

本计划将生成域收敛为**傻瓜式口播视频工具**，以一站式向导承载主场景。

---

## 二、已确认决策（grilling 结论）

### D1 功能收敛：保留 5 端点，关闭 8 模式

| 保留 | 说明 |
|---|---|
| subject（主体创建） | 人物分身 + 场景主体（见 D6） |
| reference2video（参考生视频） | 分身出画面，模型自动切换（见 D3） |
| **lip-sync（对口型）** | **后端需新实现**（OpenAPI 见 Docs/第三方/Vidu/创建其他任务/对口型.md） |
| tts（语音合成） | 向导"先试听再对口型"步骤 |
| voice_clone（声音克隆） | "我的音色"数据源 |

关闭（管理后台 generation modes 开关一键关闭，前端隐藏+提交拒绝，**代码保留可逆**）：文生视频、图生视频、首尾帧、智能多帧、数字人口播（digital_human 端点）、图片生成、文生音频、音效。

"数字人"一词歧义消除：只保留主体创建，砍照片直出口播的 digital_human 端点。

### D2 一站式向导（内容合成一级入口「拍同款口播视频」）

```
① 文案来源
   ├─ 粘贴抖音/快手分享链 / 灵感广场爆款点「提取文案」
   │    → 解析真实地址 → 下载 → ffprobe 探测
   │        ├─ 有软字幕轨 → ffmpeg 抽字幕（免费·100%精确）
   │        └─ 无 → ffmpeg 抽音轨(16k 单声道 mp3，5min≈2-3MB) → 云 ASR
   └─ 无参考 → 手写 + AI 润色
② 文案确认（LLM 一次调用双产出）
   ├─ 清洗版：加标点分段/去语气词口癖/修同音错字（=「用原文」按钮，保留原话风格）
   ├─ 改写版：借原文结构（钩子→卖点→行动号召）+ 品牌知识库内容替换
   │          + 时长控制（默认填入编辑框，可继续编辑）
   └─ 实时估算语音时长（≈4字/秒）
③ 出镜方式（先文案后出镜——内容优先）
   ├─ A 真人出镜：上传不说话视频（与语音时长对比黄条提示，不阻断）
   └─ B 数字分身：人物主体（必须）+ 场景主体（可选）
      + 一句话意图 → AI 代写完整 Vidu prompt（自动 @分身 @场景，可改）
④ 音色：官方 302 音色（可试听）/ 我的克隆音色 / 去克隆
⑤ 成片
   ├─ TTS 试听 → 真人路径：直接对口型（视频+音频）
   │            分身路径：参考生（生成分身画面）→ 对口型
   └─ 预存资产库（复用 24h 转存）+ 页内预览下载 + 发布（复用已有发布体系）
```

关键结构决策：
- **双视频槽独立**：参考视频（别人的爆款，只提取说话内容，用完即弃）与出镜视频（用户自己拍的不说话视频，成片画面）是两个槽位
- **出镜视频与数字人是并列的两种画面来源**（真人对口型不用数字人；分身是"参考生生画面→对口型加说话"两段式），不是依赖关系

### D3 参考生视频模型自动切换

Vidu 约束：视频主体只有 viduq2-pro 支持，q3 不支持。系统内部按主体类型自动选：图片主体→viduq3（效果最好）、视频主体→viduq2-pro。用户全程不感知模型存在。

### D4 视频文案提取管线

1. **来源**：灵感广场爆款（直接点「提取文案」，升级现有"一键复刻"）+ 用户粘贴抖音/快手分享链接（复用已有抖音适配器做分享链→视频地址解析）
2. **下载**：解析后下载入库（复用媒体存储）
3. **ffmpeg 探测/抽轨**（Docker 镜像加装 ffmpeg）：
   - 有软字幕轨 → 抽字幕直接得文本（零成本零误差；抖音/快手几乎全是硬字幕走不通此路，B 站等有软字幕来源可白嫖）
   - 无 → 抽音轨（16kHz 单声道 mp3）再送 ASR——绕开 ASR 接口 25MB 上限（5 分钟 1080p 视频常 20-50MB，音频仅 2-3MB）
   - 检测不到 ffmpeg 时降级：视频 ≤25MB 整文件直传 ASR，超出明确报错提示安装
4. **ASR → 文案**：见 D2 第②步三态转化（ASR 原文不可直接用：无标点/语气词/同音错字）

### D5 ASR 服务商动态可切换（本轮新增；D7 能力路由的第一个实例）

- **默认**：硅基流动 SenseVoiceSmall——免费、完全 OpenAI 兼容 `/v1/audio/transcriptions`、mp3/wav/m4a/flac/ogg、≤50MB/≤1h、中文识别强（阿里系开源模型）
- **可换**：OpenAI Whisper（$0.006/min，25MB 上限）/ Groq whisper-large-v3-turbo / 智谱 GLM-ASR（¥0.06/min，OpenAI SDK 风格但返回为 chat.completion 结构，需适配开关）/ 阿里云百炼 Paraformer 等
- **管理方式**：asr 能力多厂商条目 + active 标记（D7 统一集成模型），运行时切换即时生效不重启

### D6 主体库升级与灵感广场

- 资产库"数字人"tab 升级为**主体库**：人物分身 + 场景主体两类（同一创建弹窗加类型选择；场景主体 = 2-3 张场景照片建成可复用主体，生成时 `[@分身] 在 [@场景]`——Vidu 原生支持多主体组合）
- 主体卡片「去生成」直达向导并预填
- 灵感广场"一键复刻"升级为真「提取文案」入口

### D7 第三方集成中心——能力路由模型（2026-08-23 定稿，升级版）

**现状问题**：第三方管理散落 4 处（`/admin/providers`、`/admin/generation-specs`、`/admin/agent-configs`、待增 ASR），且全部**以厂商为中心**——但系统真正需要的是**能力**（视频生成/ASR/LLM/搜索/支付），厂商只是供货商。ASR 动态切换（D5）本质已是能力路由问题，应泛化而非特例。

**统一数据模型（后端）**：
- 集成条目 = `{厂商, 所供能力[], 凭据(加密), enabled, 业务设置 JSON, active 标记}`
- 能力枚举：`generation / asr / llm / search / payment`；每个能力多条目 + 单 active
- D5 的 ASR 切换为此模型的第一个实例；将来加可灵/即梦（视频备胎）、DeepSeek（LLM 备胎）零模型改动
- 存量迁移：provider_configs / llm_configs 逻辑视图归一（表可保留，加聚合层）

**列表页 `/admin/integrations` 双视图**：
- 按厂商（默认）：卡片 = 图标/所供能力标签/状态灯/关键指标（Vidu 显示积分）
- **按能力**：一行一能力，当前生效厂商 + 备选链 + 健康灯——暴露"ASR 挂了且无备选"类系统性风险

**插件式厂商详情页 `/admin/integrations/{vendor}`**：
- 框架统一（概览/健康/凭据/审计），业务区块由厂商注册：Vidu 注册「生成模式开关（8 关闭项 reopen）/ 模型能力矩阵（合并 GenerationSpecs）/ 首选模型（D3 自动切换可配：图片主体 viduq3 / 视频主体 viduq2-pro）/ 音色库（只读+版本标记）/ 回调健康 / 用量曲线」；ASR 注册「多服务商路由」；LLM 注册「条目管理」；Tavily/ZPAY 迁移现有表单
- 新增第三方 = 注册卡片 + 区块，页面框架零改动（EndpointAdapter 注册表模式的 UI 镜像）

**统一健康检查**：provider 端口增 `HealthCheck()`（Vidu=积分+最近任务成功率；ASR=最近调用成功率；LLM=probe）；状态灯语义 = "配置了且最近调用正常/异常"，联动 D8 预警。

**密钥安全与审计**：
- API Key 从明文改为 AES-GCM 加密存储（主密钥 env 注入），掩码展示保留
- 配置审计表：谁/何时/改了哪个厂商的什么，支持回滚上一版（防误改 Key/误关厂商无从追查）

**商户端透出**：向导依赖的能力（ASR 等）未配置/异常时，入口处直接提示"管理员未启用"，不等人提交报 500。

**路由迁移**：`/admin/providers`、`/admin/generation-specs` → 301 至 `/admin/integrations`，菜单收敛一项「第三方集成」。

**刻意不做**：自动故障转移（健康感知自动切换备胎）——先手动切换 + 可视健康，等真有多厂商备胎且故障频发再自动化。

### D8 运营可观测（2026-08-23 补充）

- **积分预警**：Vidu 余额低于阈值（默认 50，厂商详情页可改）时站内通知管理员（复用通知系统；轮询任务里顺带检查，不新增调度）
- **用量看板**：厂商详情页按天 credits 消耗曲线 + 按端点分布（usages 表已有数据，scene=generation）
- **回调健康**：callback_url 已配置但 24h 无回调到达 → 详情页黄条提示（检查防火墙/证书/前缀）

### D9 向导健壮性细节（2026-08-23 补充）

- **任务链状态机**：分身路径两段式（参考生→对口型）第二段失败时，重试只跑第二段（复用第一段产物衔接），向导内展示链路进度
- **草稿持久化**：向导各步骤写入 composeDraft（已有 store 模式），中途离开不丢
- **肖像权确认**：真人对口型首次提交勾选"视频为本人在内的肖像权可用"（Vidu 文档硬性要求"视频内容免涉肖像权"），租户级一次确认
- **发布衔接**：成片页「发布」在未绑定平台账号时引导去账号绑定（复用已有体系）

## 三B、风险与对策（2026-08-23 pre-mortem，实施时必须落地）

**安全（新增攻击面）**：
- R1 分享链解析 SSRF：仅 http/https；DNS 解析后 IP 黑名单（私网/环回/链路本地段）；大小上限+超时；禁重定向至内网
- R2 声音克隆滥用：克隆提交勾选"音频为本人或已获授权"（租户级一次），管理后台可审计全租户克隆记录

**成本（单位经济学）**：
- R3 每条向导视频成本账：ASR(≈0)+LLM 改写+TTS+对口型(分身路径+参考生) ≈4-5 次付费调用——上线前算清"每条≈X 积分≈¥Y"，商户套餐/配额按此标定，防卖得越多亏得越多
- R4 链路费用黑洞：向导级幂等（防重复点击重复扣费）；开始前整链预估配额预检；中断保留已产出（试听音频不浪费）与状态

**数据与存储**：
- R5 参考视频生命周期：提取完文案即删原始视频（只留文本/音轨产物），防磁盘被 5GB 级临时文件吃爆
- R6 大文件上传：出镜视频动辄数百 MB，单次 POST 会撞 nginx/gin 限制——分片上传或明确上限与前端提示

**链路状态**：
- R7 向导会话实体：聚合各步任务 ID + 步骤游标 + 产物引用（现 generation_tasks 是单端点粒度，刷新即断链）；D9 草稿持久化与分段重试挂在此实体下

**运营监控**：
- R8 新外部依赖静默失效：抖音分享链解析成功率 / ffmpeg 可用性 / ASR 失败率进 D8 健康面板，低于阈值告警

**合规**：
- R9 数据流向告知：用户音频发第三方 ASR、克隆音色存 Vidu——用户协议一句话 + 管理后台数据流向说明

**历史兼容**：8 个关闭模式的历史任务在任务列表/画布保持可读（只是不能新提交）；管理后台 reopen 后模式与历史无缝衔接。

## 三（续）、实施顺序（建议）

1. **后端地基**：lip-sync 端点适配器（音频驱动+文本驱动+ref_photo_url+callback）→ 8 模式开关关闭（seed 默认值 + 管理后台操作）→ reference2video 模型自动切换逻辑
2. **提取管线**：分享链解析下载 → ffmpeg 探测/抽轨（含降级）→ ASR 适配器（OpenAI 兼容 + 动态配置）→ LLM 清洗/改写双产出接口
3. **向导前端**：五步向导组件（步骤状态、时长估算、双视频槽、出镜方式分叉、任务链状态机、TTS 试听、成片预览/下载/发布）
4. **入口与库**：内容合成一级入口 → 主体库升级（场景主体）→ 灵感广场「提取文案」
5. **集成中心（D7 能力路由）**：统一集成数据模型 + 存量聚合 → `/admin/integrations` 双视图列表 + 插件式厂商详情（Vidu 聚合 Key/模式/矩阵/首选模型/音色/回调健康/用量）→ 旧路由 301 → HealthCheck + 积分预警 + 密钥加密与审计 → 商户端能力可用性提示

---

## 四、技术边界与部署要求

1. **对口型画面视频必须公网可达**（5GB 级无法 base64 内联）——本地开发需内网穿透；分身/主体流程（图/≤5s 视频）已自动内联不受限
2. **ffmpeg**：Docker 镜像 `apt install ffmpeg`；本地 Windows 需安装（winget），缺失时走降级路径
3. **ASR Key**：管理后台配置（推荐硅基流动，免费）
4. 抖音/快手分享链解析受平台接口稳定性影响，失败时明确报错并引导改用直接上传
5. 所有 Vidu 调用受积分余额约束（管理后台厂商配置页可实时查余额）
