# 数字人

`POST https://api.vidu.cn/ent/v2/digital-human`

### 请求头

| 参数名称 | 类型 | 参数描述 |
| --- | --- | --- |
| Content-Type | application/json | 数据交换格式 |
| Authorization | Token `{your api key}` | 将 `{your api key}` 替换为您的 token |

### 请求体

| 参数名称 | 类型 | 必填 | 参数描述 |
| --- | --- | --- | --- |
| model | String | 是 | 模型名称，默认用turbo<br>可选值：`viduq2-turbo` 、`viduq2-pro` |
| image | String | 是 | 数字人图像<br>模型将以此参数中传入的图片为首帧画面来生成数字人视频。<br>注1：支持传入图片 Base64 编码或图片URL（确保可访问）；<br>注2：只支持输入 1 张图；<br>注3：图片支持 png、jpeg、jpg、webp格式；<br>注4：图片比例需要小于 1:4 或者 4:1 ；<br>注5：图片大小不超过 50 MB；<br>注6：请注意，http请求的post body不超过**20MB**，且编码必须包含适当的内容类型字符串，例如：<br>`data:image/png;base64,{base64_encode}` |
| prompt | String | 可选 | 文本提示词<br>用于生成视频的文本描述，字符长度不能超过 2000 个字符。<br>视频提示词，用来控制数字人的视频内容。 |
| audio_url | String | 可选 | 对口型音频<br>与text仅生效一个，如果同时有值则audio_url生效 |
| text | String | 可选 | 对口型文本<br>与audio_url仅生效一个，如果同时有值则audio_url生效 |
| voice_id | String | 可选 | 音色ID<br>仅在使用text时生效，可选音色列表如下：[音色列表](https://shengshu.feishu.cn/sheets/EgFvs6DShhiEBStmjzccr5gonOg) |
| resolution | String | 可选 | 视频分辨率<br>默认为720p，可选项为：540p、720p、1080p |
| payload | String | 可选 | 透传参数<br>不做任何处理，仅数据传输<br>注：最多 1048576个字符 |
| callback_url | String | 可选 | Callback 协议<br>需要您在创建任务时主动设置 callback_url，请求方法为 POST，当视频生成任务有状态变化时，Vidu 将向此地址发送包含任务最新状态的回调请求。回调请求内容结构与查询任务API的返回体一致<br>回调返回的"status"包括以下状态：<br>- processing 任务处理中<br>- success 任务完成（如发送失败，回调三次）<br>- failed 任务失败（如发送失败，回调三次）<br>Vidu采用回调签名算法进行认证，详情见：[回调签名算法](https://platform.vidu.cn/docs/callback-signature) |

```
curl -X POST -H "Authorization: Token {your_api_key}" -H "Content-Type: application/json" -d '
{
    "model": "viduq2-turbo",
    "image": "your_image_url",
    "prompt": "",
    "audio_url": "your_audio_url",
    "resolution": "1080p",
    "payload": ""
}' https://api.vidu.cn/ent/v2/digital-human
```

### 响应体

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| task_id | String | Vidu生成的任务ID |
| state | String | 可选值：<br>`created` 创建成功<br>`queueing` 任务排队中<br>`processing` 任务处理中<br>`success` 任务成功<br>`failed` 任务失败 |
| image | String | 本次调用的图像参数 |
| prompt | String | 本次调用的提示词参数 |
| audio_url | String | 本次调用使用的音频url |
| text | String | 本次调用使用的文本 |
| voice_id | String | 本次调用使用的音色id，仅使用text时生效 |
| resolution | String | 本次调用的分辨率参数 |
| payload | String | 本次调用时传入的透传参数 |
| credits | Int | 本次调用使用的积分数 |
| created_at | String | 任务创建时间 |
