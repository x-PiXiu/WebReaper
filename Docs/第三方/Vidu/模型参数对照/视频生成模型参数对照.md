# Vidu 视频生成模型参数对照

> 基于 Vidu 官方 API 文档整理，覆盖 7 个视频生成端点、13 个模型。
> 更新日期：2026-07-24

---

## 1. 全量模型清单

| 模型 ID | 系列 | 定位 | 出现的端点 |
|---------|------|------|-----------|
| viduq3-pro | Q3 | 旗舰，效果最佳，音画同出 | text2video, img2video, reference2video, start-end2video |
| viduq3-turbo | Q3 | 性价比，生成更快，音画同出 | text2video, img2video, reference2video, start-end2video |
| viduq3-pro-fast | Q3 | 高性价比，仅图生视频 | img2video |
| viduq3-mix | Q3 | 均衡性最强，智能切镜 | reference2video（非主体） |
| viduq3 | Q3 | reference2video 专用名（= viduq3-pro） | reference2video（主体调用） |
| viduq2-pro | Q2 | 效果好，支持视频主体参考 | img2video, reference2video, start-end2video, multiframe |
| viduq2-turbo | Q2 | 生成快 | img2video, start-end2video, multiframe |
| viduq2-pro-fast | Q2 | 价格触底，速度提升 2-3x | img2video, start-end2video |
| viduq2 | Q2 | 文生视频专用 | text2video, reference2video |
| viduq1 | Q1 | 画面清晰，运镜稳定 | text2video, img2video, reference2video, start-end2video |
| viduq1-classic | Q1 | 转场运镜更丰富 | img2video, start-end2video |
| vidu2.0 | 2.0 | 生成速度快 | img2video, reference2video, start-end2video |

> 注：`viduq3` 是 reference2video 主体调用时的模型名，等价于 `viduq3-pro`。

## 5. 跨端点通用参数

以下参数在所有视频端点中通用：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| model | String | 是 | 模型名称（template/template-story 除外） |
| seed | Int | 否 | 随机种子，0 或不传为随机 |
| payload | String | 否 | 透传参数，≤1048576 字符 |
| off_peak | Bool | 否 | 错峰模式，48 小时内完成 |
| watermark | Bool | 否 | 是否添加水印 |
| wm_position | Int | 否 | 水印位置 1-4 |
| wm_url | String | 否 | 自定义水印图片 URL |
| meta_data | String | 否 | JSON 元数据标识 |
| callback_url | String | 否 | 回调 URL（POST） |
