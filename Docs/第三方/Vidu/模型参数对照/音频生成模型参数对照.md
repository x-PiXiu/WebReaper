# Vidu 音频生成模型参数对照

> 基于 Vidu 官方 API 文档整理，覆盖 4 个音频端点、1 个模型 + 2 个无模型服务接口。
> 更新日期：2026-07-24

---

## 1. 全量端点清单

| 端点 | API 路径 | model 参数 | 接口类型 | 定位 |
|------|----------|-----------|---------|------|
| 文生音频 | `/ent/v2/text2audio` | `audio1.0` | 异步 | 提示词 → 音效/BGM |
| 可控文生音效 | `/ent/v2/timing2audio` | `audio1.0` | 异步 | 时间轴 → 多段时序音效 |
| 语音合成 | `/ent/v2/audio-tts` | 无 | **同步** | 文本 → 朗读音频 |
| 声音复刻 | `/ent/v2/audio-clone` | 无 | **同步** | 音频 → 复刻音色 + 试听 |

> 注：`audio1.0` 是唯一有 model 参数的音频模型。TTS 和声音复刻不接受 model 参数，由平台内部路由。

---

## 2. 端点 × 模型可用性矩阵

| 端点 | audio1.0 |
|------|:--------:|
| text2audio | ✅ |
| timing2audio | ✅ |
| audio-tts | — （无 model 参数） |
| audio-clone | — （无 model 参数） |

## 3. 核心参数对比（按端点）

### 3.1 text2audio（文生音频）

适用于通过输入提示词，生成一段音频（支持生成音效和背景音乐 BGM）。

| 参数 | audio1.0 |
|------|----------|
| model | 必填，`audio1.0` |
| prompt | 必填，≤1500 字符 |
| duration | 可选，默认 10，范围 2～10 秒 |
| seed | 可选，0 或不传为随机 |
| callback_url | 可选，POST 回调 |

### 3.2 timing2audio（可控文生音效）

支持通过时间轴灵活控制多个事件音效的触发时长。**不支持输出背景音乐 BGM。**

| 参数 | audio1.0 |
|------|----------|
| model | 必填，`audio1.0` |
| duration | 可选，默认 10，范围 2～10 秒 |
| timing_prompts | 必填，Array[Object]，结构见下方 |
| seed | 可选，0 或不传为随机 |
| callback_url | 可选，POST 回调 |

**timing_prompts 结构：**

| 字段 | 类型 | 说明 |
|------|------|------|
| from | Float | 开始时间（秒），必须在 [0, duration] 区间内 |
| to | Float | 结束时间（秒），必须在 [0, duration] 区间内 |
| prompt | String | 音效描述，≤1500 字符 |

> 支持多个事件重叠。from < to。

### 3.3 audio-tts（语音合成）

输入文本生成对应的朗读音频，可控制语速、音量、情绪。**同步接口，不需要回调。**

| 参数 | 说明 |
|------|------|
| text | 必填，待合成文本，≤10000 字符。支持 `<#x#>` 停顿标记（x 为秒数，范围 [0.01, 99.99]） |
| voice_setting_voice_id | 必填，音色 ID |
| voice_setting_speed | 可选，默认 1.0，范围 [0.5, 2] |
| voice_setting_volume | 可选，默认 0（正常），范围 0-10 |
| voice_setting_pitch | 可选，默认 0（原音色），范围 [-12, 12] |
| voice_setting_emotion | 可选，情绪控制：happy / sad / angry / fearful / disgusted / surprised / calm |
| pronunciation_dict_tone | 可选，多音字发音定义，格式：`["燕少飞/(yan4)(shao3)(fei1)"]` |
| payload | 可选，透传参数，≤1048576 字符 |

**同步响应：**

| 字段 | 类型 | 说明 |
|------|------|------|
| task_id | String | 任务 ID |
| state | String | 状态：queueing / success / failed |
| file_url | String | 音频文件 URL |
| credits | Int | 消耗积分 |
| payload | String | 透传参数 |
| created_at | String | 创建时间 |

### 3.4 audio-clone（声音复刻）

复刻真人音色，并使用该音色朗读指定文本。**同步接口，不需要回调。**

| 参数 | 说明 |
|------|------|
| audio_url | 必填，原音频 URL。格式：mp3/m4a/wav，时长 10 秒～5 分钟，≤20MB |
| voice_id | 必填，自定义音色 ID。长度 [8,256]，首字符必须为英文字母，允许数字/字母/横线/下划线 |
| text | 必填，试听文本，≤1000 字符。复刻后用该音色朗读此文本并返回试听音频 |
| prompt_audio_url | 可选，示例音频（≤8 秒，≤20MB），有助于增强音色相似度 |
| prompt_text | 可选，示例音频对应的文本内容 |
| payload | 可选，透传参数，≤1048576 字符 |

**同步响应：**

| 字段 | 类型 | 说明 |
|------|------|------|
| task_id | String | 任务 ID |
| state | String | 状态：queueing / success / failed |
| voice_id | String | 用户自定义的 voice_id（失败时不返回） |
| demo_audio | String | 试听音频 URL（未传 text 时为空） |
| payload | String | 透传参数 |
| created_at | String | 创建时间 |

**重要限制：** 复刻的音色为临时音色，7 天（168 小时）内未在 TTS 接口中调用将自动删除，积分不退还。试听不算使用。

## 4. text2audio vs timing2audio 对比

| 维度 | text2audio | timing2audio |
|------|-----------|-------------|
| 用途 | 单段音效/BGM | 多段时序音效 |
| prompt | 必填，顶层 String | 无顶层 prompt，嵌套在 timing_prompts[] 内 |
| timing_prompts | 不支持 | 必填 |
| BGM 支持 | ✅ | ❌ |
| 多事件重叠 | — | ✅ |
| 请求体结构 | 扁平 | 结构化（数组嵌套） |

> 这两个端点共享同一个模型 `audio1.0`，但请求体结构完全不同。平台通过三级 Schema 架构（§10.16）处理参数差异。

---

## 5. 同步 vs 异步接口对比

| 维度 | 异步（text2audio / timing2audio） | 同步（TTS / 声音复刻） |
|------|----------------------------------|----------------------|
| 返回方式 | 返回 task_id → 轮询/回调 | 直接返回完整结果 |
| 结果获取 | `GET /tasks?task_ids={id}` | 响应体中直接包含 file_url / demo_audio |
| 超时 | 分钟级（音效生成较慢） | 秒级（TTS 快速合成） |
| 回调支持 | ✅ | ❌（不需要） |

---

## 6. voice_id 音色来源

| 来源 | 说明 |
|------|------|
| 平台预置音色 | Vidu 提供的官方音色列表 |
| 声音复刻创建 | 通过 `/audio-clone` 接口创建的临时音色（7 天有效） |

> TTS 和声音复刻都通过 `voice_id` 关联音色。声音复刻创建的音色需在 7 天内通过 TTS 调用才能保留。
