# Vidu 图片生成模型参数对照

> 基于 Vidu 官方 API 文档整理，覆盖 1 个图片生成端点、2 个模型。
> 更新日期：2026-07-24

---

## 1. 全量模型清单

| 模型 ID | 系列 | 定位 | 能力 |
|---------|------|------|------|
| viduq2 | Q2 | 文生图 + 参考生图 + 图片编辑，支持 2K/4K | images 可传 0～7 张（0 张时走文生图） |
| viduq1 | Q1 | 仅参考生图，固定 1080p | images 必须传 1～7 张 |

> 注：图片模型的 `model_id` 与视频模型同名（`viduq2`、`viduq1`），但 `model_type` 为 `IMAGE`，`api_model_name` 分别为 `viduq2` 和 `viduq1`。数据库中通过 `model_id` 区分，图片模型注册为 `viduq2-image` 和 `viduq1-image`。

---

## 2. 端点 × 模型可用性矩阵

| 端点 | API 路径 | viduq2 | viduq1 |
|------|----------|:------:|:------:|
| reference2image | `/ent/v2/reference2image` | ✅ | ✅ |

> 图片生成仅有 1 个端点 `reference2image`，两个模型共用同一端点。

---

## 3. 核心参数对比

### 3.1 reference2image（参考生图 / 文生图）

| 参数 | viduq2 | viduq1 |
|------|--------|--------|
| model | 必填，`viduq2` | 必填，`viduq1` |
| images | 可选，0～7 张 | 必填，1～7 张 |
| prompt | 必填，≤2000 字符 | 必填，≤2000 字符 |
| aspect_ratio | 默认 `16:9`，可选：`16:9`、`9:16`、`1:1`、`3:4`、`4:3`、`21:9`、`2:3`、`3:2`、`auto` | 默认 `16:9`，可选：`16:9`、`9:16`、`1:1`、`3:4`、`4:3` |
| resolution | 默认 `1080p`，可选：`1080p`、`2K`、`4K` | 默认 `1080p`，仅 `1080p` |
| seed | 可选，0 或不传为随机 | 可选，0 或不传为随机 |
| payload | 可选，≤1048576 字符 | 可选，≤1048576 字符 |
| callback_url | 可选，POST 回调 | 可选，POST 回调 |

**关键差异说明：**

| 差异点 | viduq2 | viduq1 |
|--------|--------|--------|
| 文生图 | ✅ images 为空时走文生图 | ❌ 不支持，images 必填 |
| 参考生图 | ✅ 1～7 张参考图 | ✅ 1～7 张参考图 |
| 图片编辑 | ✅ 支持 | ❌ 不支持 |
| 最大比例种类 | 9 种（含 auto） | 5 种 |
| 超宽比例 | ✅ 支持 21:9 | ❌ 不支持 |
| 自动比例 | ✅ `auto`（与首张输入图同比例） | ❌ 不支持 |
| 最高分辨率 | 4K | 1080p |

## 4. 模型能力总结

### viduq2（Q2 图片模型）

| 能力 | 支持情况 |
|------|---------|
| 文生图（无 images） | ✅ |
| 参考生图（有 images） | ✅ 0～7 张 |
| 图片编辑 | ✅ |
| 最高分辨率 | 4K |
| 比例 | 16:9, 9:16, 1:1, 3:4, 4:3, 21:9, 2:3, 3:2, auto |
| 回调支持 | ✅ |

### viduq1（Q1 图片模型）

| 能力 | 支持情况 |
|------|---------|
| 文生图（无 images） | ❌ 不支持 |
| 参考生图（有 images） | ✅ 1～7 张 |
| 图片编辑 | ❌ |
| 最高分辨率 | 1080p |
| 比例 | 16:9, 9:16, 1:1, 3:4, 4:3 |
| 回调支持 | ✅ |

---

## 5. 通用参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| model | String | 是 | 模型名称（`viduq2` 或 `viduq1`） |
| prompt | String | 是 | 文本提示词，≤2000 字符 |
| images | Array[String] | 视模型 | 参考图片 URL 或 Base64 编码 |
| seed | Int | 否 | 随机种子，0 或不传为随机 |
| aspect_ratio | String | 否 | 画面比例 |
| resolution | String | 否 | 分辨率 |
| payload | String | 否 | 透传参数，≤1048576 字符 |
| callback_url | String | 否 | 回调 URL（POST） |

---

## 6. 图片输入约束

两个模型共用以下图片输入约束：

| 约束 | 值 |
|------|-----|
| 格式 | png、jpeg、jpg、webp |
| 最小像素 | 128×128 |
| 比例限制 | 宽高比需在 1:4 到 4:1 之间 |
| 单张大小 | ≤50MB |
| 编码方式 | URL 或 `data:image/png;base64,{base64_encode}` |
| POST body 限制 | ≤20MB |

---

## 7. 任务响应结构

图片生成的响应结构与视频生成一致（统一走 `/tasks` 查询）：

| 字段 | 类型 | 说明 |
|------|------|------|
| task_id | String | 任务 ID |
| state | String | 状态：created / queueing / processing / success / failed |
| model | String | 本次调用的模型 |
| prompt | String | 本次调用的提示词 |
| images | Array[String] | 本次调用的参考图 |
| seed | Int | 随机种子 |
| aspect_ratio | String | 画面比例 |
| resolution | String | 分辨率 |
| credits | Int | 消耗积分 |
| created_at | String | 创建时间 |
