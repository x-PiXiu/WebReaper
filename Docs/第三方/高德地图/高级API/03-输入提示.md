# 高德 Web 服务 API —— 输入提示

> 来源：高德开放平台官方文档（最后更新时间：2026-02-02）
> 服务地址：`https://restapi.amap.com`（HTTP/HTTPS，GET 请求）
> 归档位置：`Docs/第三方/高德地图/高级API/`

---

## 1. 产品介绍

输入提示是一类简单的 HTTP 接口，根据用户输入的关键词返回**建议列表**。

**典型场景**：高德客户端输入"仙林"后出现相关地点提示——本项目对应**门店地址表单"边输入边联想"**（老板输几个字即出现可选地址，免手输完整地址）。

**使用流程（三步）**：申请 Web 服务 Key → 拼接 URL（Key 必填）→ 解析返回 JSON/XML。

---

## 2. 服务地址与请求方式

```
https://restapi.amap.com/v3/assistant/inputtips?parameters
请求方式：GET
```

---

## 3. 请求参数

| 参数名 | 含义 | 规则说明 | 是否必填 | 缺省值 |
|---|---|---|---|---|
| `key` | 请求服务权限标识 | 高德官网申请的 Web 服务 Key | 必填 | 无 |
| `keywords` | 查询关键词 | 用户输入的关键词 | **必填** | 无 |
| `type` | POI 分类 | 支持多个分类，`\|` 分隔；可选：分类名称 / **分类代码**（强烈建议用分类代码，否则可能结果不符预期） | 可选 | 无 |
| `location` | 坐标 | 格式 `X,Y`（经度,纬度），**不可含空格**；**建议使用**——在此坐标附近优先返回结果；**仅在请求参数 city 不为空时生效** | 可选 | 无 |
| `city` | 搜索城市 | citycode / adcode（**不支持县级市**）；优先返回该城市数据（不一定仅限该市，需配 citylimit） | 可选 | 全国 |
| `citylimit` | 仅返回指定城市 | `true`/`false` | 可选 | false |
| `datatype` | 返回数据类型 | 多类型 `\|` 分隔：`all`（全部）/ `poi`（POI）/ `bus`（公交站点）/ `busline`（公交线路） | 可选 | all |
| `sig` / `output` / `callback` | 签名 / 格式 / 回调 | output=JSON/XML；callback 仅 output=JSON 时有效 | 可选 | — |

---

## 4. 返回参数

| 参数名 | 含义 | 规则说明 |
|---|---|---|
| `status` | 返回状态 | 1=成功 / 0=失败 |
| `info` | 状态信息 | 失败时返回错误原因 |
| `count` | 返回结果总数目 | — |
| `tips[]` | 建议提示列表 | 见下 |

`tips[]` 子字段：

| 字段 | 含义 | 说明 |
|---|---|---|
| `id` | 返回数据 ID | **POI 类型 → POI ID**；bus → bus id；busline → busline id（⚠️ busline 类型此字段可能为空） |
| `name` | tip 名称 | 如"望京西园" |
| `district` | 所属区域 | 省+市+区（直辖市为"市+区"） |
| `adcode` | 区域编码 | 六位区县编码 |
| `location` | tip 中心点坐标 | **busline 类型时不返回** |
| `address` | 详细地址 | — |

---

## 5. 服务示例

```
https://restapi.amap.com/v3/assistant/inputtips?output=xml&city=010&keywords=招商银行&key=<用户的key>
```

---

## 6. 关键注意事项

1. **type 建议用分类代码**（如 `050000` 餐饮）：用名称可能得到不符预期的结果。
2. **location 仅在 city 非空时生效**——"附近优先"需要城市限定配合。
3. **city 不支持县级市**（与地理编码的 city 参数规则一致）。
4. **`id` 可直接联动 ID 查询**：返回的 POI ID 喂给 `v3/place/detail` 或 **`v5/place/detail`（批量 10 个）** 拿完整详情（官方明确"建议同输入提示 API 配合使用"）。
5. 配额：调用量限制见控制台"配额管理"（政策会调整）。

## 7. 项目对接建议

| 用途 | 拼接要点 | 落点设想 |
|---|---|---|
| **门店建档地址联想**（P1 主场景） | `keywords=用户输入&city=门店adcode&datatype=poi` | 前端地址表单输入触发 → 建议列表（name/address）→ 选中即填地址（免手输）；返回的 `location` 与 `adcode` 可一并回填门店 |
| **附近优先联想** | 加 `location=门店经纬度`（city 非空时生效） | 老板输入"川菜馆"→ 联想附近门店 → 快速定位竞品 POI ID |
| **ID 联动** | 选中 tip 的 `id` → `v5/place/detail` | 联想 → 详情（评分/人均/营业时间）一步到位 |
| 城市兜底 | `citylimit=true` | 输入命中多地时严格限定本市 |

> 对接骨架：`adapter/geo/amap.go` 新增 `InputTips(ctx, keywords, city, location)`——复用现有 HTTP 骨架；响应 `tips[]` 映射为轻量结构（Name/Address/District/Adcode/Location/POIID），mock 降级返回空列表（未配置 Key 时表单退化为纯手输，行为不变）。
