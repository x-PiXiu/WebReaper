# 高德 Web 服务 API —— 搜索 POI 2.0（v5）

> 来源：高德开放平台官方文档（最后更新时间：2026-07-15）
> 服务地址：`https://restapi.amap.com`（HTTP/HTTPS，GET 请求，**仅支持 JSON 输出**）
> 归档位置：`Docs/第三方/高德地图/高级API/`
> 关联：v3 版见同目录 `01-搜索POI.md`；本项目当前对接的是 **v3 周边搜索**

---

## 1. 产品概述

地点搜索服务 2.0 是新一代 Web API，提供四种场景的地点搜索能力：

| 机制 | 接口 |
|---|---|
| **关键字搜索** | `v5/place/text`（支持结构化地址，如"北京市朝阳区望京阜荣街10号"；也支持 POI 名称，如"首开广场"） |
| **周边搜索** | `v5/place/around`（圆心 + 半径） |
| **多边形区域搜索** | `v5/place/polygon`（首尾连接的几何点组成多边形） |
| **ID 搜索** | `v5/place/detail`（建议结合输入提示接口使用） |

**限制**：搜索不支持返回全量数据，同参数翻页最多 **200 条**。

---

## 2. ⭐ v5 vs v3 核心差异（本项目选型参考）

| 维度 | v3（搜索 POI） | **v5（搜索 POI 2.0）** |
|---|---|---|
| 返回字段控制 | `extensions=base/all`（all 一次全返回，流量大） | **`show_fields` 精确筛选字段组**（children/business/indoor/navi/photos，按需取，响应小） |
| 区域限定参数 | `city` + `citylimit` | `region` + `city_limit`（city_limit=true 时**仅召回 region 内数据**） |
| 分页参数 | `offset` / `page` | `page_size`（1-25）/ `page_num` |
| 营业时间 | 无 | **`business.opentime_today` / `opentime_week`**（今日/每周营业时间） |
| 关键词长度 | 未注明 | 文本总长 **≤80 字符** |
| ID 查询 | 最多 **1 个** id | 最多 **10 个** id（`\|` 分隔，批量） |
| 输出格式 | JSON/XML | **仅 JSON** |
| 返回结构 | 含 `suggestion`（城市建议） | 无 suggestion；`count` = 单次实际返回 poi 个数；多 `infocode`（10000=正确） |
| 排序 | `sortrule=distance/weight` | 同（仅传 keywords 时距离排序不生效） |

**结论**：v5 的 `show_fields` 精确控制 + 营业时间 + ID 批量查询，对项目"地图榜补全门店卡（评分/人均/商圈/特色菜/营业时间）"比 v3 `extensions=all` **更省流量、信息更全**——**新对接推荐直接用 v5**。

## 3. 关键字搜索（`v5/place/text`）

```
https://restapi.amap.com/v5/place/text?parameters
请求方式：GET
```

### 请求参数

| 参数名 | 含义 | 规则 | 必填 | 默认 |
|---|---|---|---|---|
| `key` | 高德 Key | Web 服务 Key | 必填 | 无 |
| `keywords` | 地点关键字 | 只支持一个关键字，**文本总长 ≤80 字符** | keywords/types 二选一 | 无 |
| `types` | 指定地点类型 | 与 POI typecode 同类；多个用 `\|` 分隔；按高德综合权重排序 | keywords/types 二选一 | 无 |
| `region` | 搜索区划 | citycode / adcode / cityname（中文，仅城市级，如"北京市"）；增加区域内召回权重 | 可选 | 全国 |
| `city_limit` | 指定城市召回限制 | `true` 时**仅召回 region 对应区域内数据** | 可选 | false |
| `langCode` | 返回语言 | zh/en（多语言为高级服务） | 可选 | zh |
| `show_fields` | 返回字段控制 | 指定可选字段组（见 § 6），逗号分隔；**未设置只返回基础字段** | 可选 | 空 |
| `page_size` / `page_num` | 分页 | 1-25 / 页码 | 可选 | 10 / 1 |
| `sig` / `output` / `callback` | 签名 / 格式 / 回调 | output 仅 json | 可选 | — |

### 服务示例

```
https://restapi.amap.com/v5/place/text?keywords=北京大学&types=141201&region=北京市&key=<用户的key>
```

## 4. 周边搜索（`v5/place/around`）

```
https://restapi.amap.com/v5/place/around?parameters
请求方式：GET
```

### 请求参数（与关键字搜索共用的不再重复）

| 参数名 | 含义 | 规则 | 必填 | 默认 |
|---|---|---|---|---|
| `key` | 高德 Key | — | 必填 | 无 |
| `keywords` | 地点关键字 | ≤80 字符 | 可选 | 无 |
| `types` | 地点类型 | 多个 `\|` 分隔 | 可选 | 无 |
| `location` | 中心点坐标 | 经度,纬度（经度在前），小数 ≤6 位，**不支持多个点** | **必填** | 无 |
| `radius` | 搜索半径 | 0~50000，**>50000 按默认值**，单位米 | 可选 | 5000 |
| `sortrule` | 排序规则 | `distance`/`weight`；**仅传 keywords 时距离排序不生效** | 可选 | distance |
| `region` / `city_limit` | 区划限定 | 同关键字搜索 | 可选 | 全国 |
| `show_fields` / `page_size` / `page_num` | 字段/分页 | 同上 | 可选 | — |

**空条件默认**：keywords 和 types 均为空时，默认 types = `050000`（餐饮服务）+ `070000`（生活服务）+ `120000`（商务住宅）。

### 服务示例

```
https://restapi.amap.com/v5/place/around?location=116.473168,39.993015&radius=10000&types=011100&key=<用户的key>
```

## 5. 多边形区域搜索（`v5/place/polygon`）与 ID 搜索（`v5/place/detail`）

### 5.1 多边形搜索

```
https://restapi.amap.com/v5/place/polygon?parameters
```

| 参数 | 规则 | 必填 |
|---|---|---|
| `polygon` | 多个坐标对，`\|` 分隔；**矩形可传左上右下两顶点，其他情况首尾坐标需相同** | 必填 |
| `keywords` / `types` | 同前（空条件默认 types=120000 商务住宅 + 150000 交通设施服务） | 可选 |
| `show_fields` / `page_size` / `page_num` / `langCode` | 同前 | 可选 |

示例：
```
https://restapi.amap.com/v5/place/polygon?polygon=116.460988,40.006919|116.48231,40.007381|116.47516,39.99713|116.472596,39.985227|116.45669,39.984989|116.460988,40.006919&keywords=肯德基&types=050301&key=<用户的key>
```

### 5.2 ID 搜索（升级点：批量）

```
https://restapi.amap.com/v5/place/detail?parameters
```

| 参数 | 规则 | 必填 |
|---|---|---|
| `id` | **最多 10 个 id，`\|` 分隔**（v3 仅 1 个） | 必填 |
| `show_fields` / `langCode` / `sig` | 同前 | 可选 |

示例：
```
https://restapi.amap.com/v5/place/detail?id=B000A7BM4H|B0FFKEPXS2&key=<用户的key>
```

## 6. 返回结果（字段结构）

### 6.1 顶层

| 字段 | 说明 |
|---|---|
| `status` | 成功返回 `1`，失败返回 `0` |
| `info` | "ok" 或错误原因 |
| `infocode` | 状态码，**10000 = 正确** |
| `count` | 单次请求实际返回 poi 个数 |
| `pois[]` | POI 集合 |

### 6.2 基础字段（默认返回，无需 show_fields）

`name` / `id` / `parent`（父 POI ID，可能为空）/ `distance`（米，**仅周边搜索有值**）/ `location` / `type` / `typecode` / `pname` / `cityname` / `adname`（区县）/ `address` / `pcode` / `adcode` / `citycode`

### 6.3 可选字段组（需通过 `show_fields` 设置，逗号分隔）

| show_fields 组 | 字段 | 说明 |
|---|---|---|
| `children` | 子 POI 信息 | id/name/location/address/subtype/typecode/sname |
| `business` | **商业信息** | `business_area`（所属商圈）/ `opentime_today`（今日营业时间，如"08:30-17:30"）/ `opentime_week`（每周营业时间描述）/ `tel`（电话）/ `tag`（特色内容，**仅美食 POI**，如"烤鱼,麻辣香锅"）/ `rating`（评分，**仅餐饮/酒店/景点/影院**）/ `cost`（人均消费，同上）/ `parking_type` / `alias` / `keytag` / `rectag` |
| `indoor` | 室内信息 | `indoor_map`（1=有室内数据）/ `cpid` / `floor`（如 8）/ `truefloor`（如 F8） |
| `navi` | 导航信息 | `navi_poiid`（导航引导点，大型面状 POI 的出入口）/ `entr_location`（入口经纬度）/ `exit_location` / `gridcode` |
| `photos` | 图片信息 | `title` / `url`（下载链接） |

> ⚠️ **字段类型提示**：部分返回值存在时为字符串、不存在时为数组——解析需兜底。
> ⚠️ ID 搜索额外返回基础字段 `atag`（类目，如"985大学/粤菜"）。

## 7. 项目对接建议（v5 迁移评估）

### 7.1 现状

`AmapPOISearcher`（`adapter/geo/amap.go`）对接 **v3 `place/around`**，`extensions=base` —— 评分（biz_ext.rating）按官方文档需要 extensions=all 才能返回，当前 base 模式**大概率拿不到评分**。

### 7.2 两条升级路径对比

| 路径 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| A. v3 + extensions=all | 现有实现改参数 | 改动最小（解析结构不变） | all 返回全部字段，响应大；无营业时间 |
| **B. 迁移 v5 + show_fields=business,navi** | 新适配器（URL/解析均变） | **响应最小**（只要 business/navi）；**含营业时间**（opentime_today——门店档案补全）；ID 批量 10 个 | 适配器重写 + v5 参数名不同 |

### 7.3 建议（B 路径）

1. `adapter/geo/amap.go` 新增 `AmapV5POISearcher`（或升级现有）：周边搜索 `v5/place/around?location=..&radius=..&keywords=..&show_fields=business,navi`
2. `port.POIStore` 扩展字段：`Rating` / `Cost` / `BusinessArea` / `OpenTimeToday` / `Tag` / `Tel` / `EntrLocation`（地图榜门店卡一次拿全）
3. 门店档案同步：`opentime_today` 可回填 `geo_store_locations.hours`（建档时用户没填营业时间的兜底）
4. ⛔ **无需单独接 `place/detail`**：评分/人均/营业时间/商圈/特色菜在**搜索返回里已有**（第 2 点的 show_fields 已覆盖）——ID 批量查询仅当需要搜索不返回的补充字段（如 `atag` 类目）时才考虑（注意官网目录未单列 detail 接口，JS 的 `poiOnAMAP` 是跳转落地页而非数据接口，见 `01-搜索POI.md` § 5）
5. mock 降级策略沿用（未配置 Key 返回 `port.ErrGeoNotConfigured`）

> ⚠️ 迁移前用真实 Key 验证一次 v5 返回结构（v5 仍属较新接口，字段以线上实测为准）；v3 实现保留作为降级开关（config 可选 `AMAP_API_VERSION=v3|v5`）。
