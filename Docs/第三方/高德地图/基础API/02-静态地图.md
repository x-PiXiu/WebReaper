# 高德 Web 服务 API —— 静态地图

> 来源：高德开放平台官方文档（最后更新时间：2026-02-02）
> 服务地址：`https://restapi.amap.com`（HTTP/HTTPS，GET 请求）
> 归档位置：`Docs/第三方/高德地图/基础API/`

---

## 1. 产品介绍

静态地图服务通过返回一张**地图图片**响应 HTTP 请求，使用户能够将高德地图以图片形式嵌入网页中。可指定地图位置、图片大小，并添加覆盖物：

- **标签**（labels）：文字标签
- **标注**（markers）：图钉标注
- **折线/多边形**（paths）：路径与区域绘制
- **调用高清图**（scale=2）

> ⚠️ 使用静态地图需遵守高德开放平台《自定义地图服务协议》。

**适用场景（本项目视角）**：
| 场景 | 用途 |
|---|---|
| 公开文章页嵌门店位置图 | 文章"地址信息块"旁放门店地图缩略图——本地信号 + 用户转化路径（P2 已列入扩展清单） |
| 附近同行页地图 | 每个地图榜门店配缩略图，或品牌门店全景图 |
| 分享/外链卡片 | 生成带地图的图片用于平台发布 |

**使用流程（三步）**：申请 Web 服务 Key → 拼接 URL（Key 必填）→ 接收图片响应（二进制图片，非 JSON）。

> 输入参数和输出数据编码统一为 UTF-8。

---

## 2. 服务地址与请求方式

```
https://restapi.amap.com/v3/staticmap?parameters
请求方式：GET
```

---

## 3. 请求参数

| 参数名 | 含义 | 规则说明 | 是否必填 | 默认值 |
|---|---|---|---|---|
| `key` | 用户唯一标识 | 高德官网申请的 Web 服务 API Key | 必填 | 无 |
| `location` | 地图中心点 | 经度,纬度，逗号分隔，小数不超过 6 位 | **部分条件必填** | 无 |
| `zoom` | 地图缩放级别 | **[1,17]** | 必填 | 无 |
| `size` | 地图大小 | 图片宽*高，**最大 1024*1024** | 可选 | 400*400 |
| `scale` | 普通/高清 | `1`=普通图；`2`=高清图（宽高和 zoom 都翻倍；zoom 为最大值时不再改变） | 可选 | 1 |
| `markers` | 标注 | 见 § 4，**最大 10 个** | 可选 | 无 |
| `labels` | 标签 | 见 § 5，**最大 10 个** | 可选 | 无 |
| `paths` | 折线/多边形 | 见 § 6，**最大 4 个** | 可选 | 无 |
| `traffic` | 交通路况标识 | `0`=不展现；`1`=展现实时路况 | 可选 | 0 |
| `sig` | 数字签名 | 数字签名认证用户必填 | 可选 | 无 |

**中心点/缩放级别自动计算规则**（有覆盖物时）：
- 请求**无 `location`** → 地图区域以所有标注/标签/折线的**几何中心**为中心点
- 请求**无 `zoom`** → 地图区域以包含所有覆盖物为准，系统自动计算 zoom

## 4. markers（标注）

### 4.1 格式

```
markers=markersStyle1:location1;location2..|markersStyle2:location3;location4..|markersStyleN:locationN;locationM..
```

- `location`：经纬度，点之间用 `;` 分隔
- `markersStyle`：可使用系统样式或自定义图片

### 4.2 系统样式（size, color, label）

| 参数名 | 说明 | 默认值 |
|---|---|---|
| `size` | 可选值：`small` / `mid` / `large` | small |
| `color` | 取值范围 [0x000000, 0xffffff] | 0xFC6054 |
| `label` | `[0-9]`、`[A-Z]`、`[单个中文字]`；**size 为 small 时图片不展现标注名** | 无 |

常用颜色参考：0x000000 黑 / 0x008000 绿 / 0x800080 紫 / 0xFFFF00 黄 / 0x0000FF 蓝 / 0x808080 灰 / 0xffa500 橙 / 0xFF0000 红 / 0xFFFFFF 白

### 4.3 示例

```
# 系统样式（mid 大小、红色、标注名 A）
https://restapi.amap.com/v3/staticmap?markers=mid,0xFF0000,A:116.37359,39.92437;116.47359,39.92437&key=您的key

# 自定义图片（仅支持 PNG）
https://restapi.amap.com/v3/staticmap?markers=-1,https://a.amap.com/jsapi_demos/static/demo-center/icons/poi-marker-default.png,0:116.37359,39.92437&key=您的key
```

## 5. labels（标签）

### 5.1 格式

```
labels=labelsStyle1:location1;location2..|labelsStyle2:location3;location4..|labelsStyleN:locationN;locationM..
```

`labelsStyle`：content, font, bold, fontSize, fontColor, background（逗号分隔，有默认值的可为空）

### 5.2 参数说明

| 参数名 | 说明 | 默认值 |
|---|---|---|
| `content` | 标签内容，**字符最大数目 15** | 无 |
| `font` | `0`微软雅黑 / `1`宋体 / `2`Times New Roman / `3`Helvetica | 0 |
| `bold` | `0`非粗体 / `1`粗体 | 0 |
| `fontSize` | 字体大小，**[1,72]** | 10 |
| `fontColor` | 字体颜色 [0x000000, 0xffffff] | 0xFFFFFF |
| `background` | 背景色 [0x000000, 0xffffff] | 0x5288d8 |

### 5.3 示例

```
https://restapi.amap.com/v3/staticmap?location=116.48482,39.94858&zoom=10&size=400*400&labels=朝阳公园,2,0,16,0xFFFFFF,0x008000:116.48482,39.94858&key=您的key
```

## 6. paths（折线 / 多边形）

### 6.1 格式

```
paths=pathsStyle1:location1;location2..|pathsStyle2:location3;location4..|pathsStyleN:locationN;locationM..
```

`pathsStyle`：weight, color, transparency, fillcolor, fillTransparency

### 6.2 参数说明

| 参数名 | 说明 | 默认值 |
|---|---|---|
| `weight` | 线条粗细，**[2,15]** | 5 |
| `color` | 折线颜色 [0x000000, 0xffffff] | 0x0000FF |
| `transparency` | 透明度 [0,1]，小数最多 2 位；0=完全透明，1=完全不透明 | 1 |
| `fillcolor` | 多边形填充颜色，**此值不为空时折线封闭成多边形**（取值规则同 color） | 无 |
| `fillTransparency` | 填充面透明度 [0,1] | 0.5 |

### 6.3 示例

```
# 折线（含多边形填充：fillcolor 非空 → 封闭成多边形）
https://restapi.amap.com/v3/staticmap?zoom=15&size=500*500&paths=10,0x0000ff,1,,:116.31604,39.96491;116.320816,39.966606;116.321785,39.966827;116.32361,39.966957&key=您的key
```

## 7. 关键注意事项

1. **返回的是图片二进制**，不是 JSON/XML——与地理编码/周边搜索的解析方式完全不同（直接作为 `<img src>` 或响应体透传）。
2. **有覆盖物时可省 location/zoom**：自动以覆盖物几何中心为地图中心、自动算 zoom——做"多点标注"（如品牌多门店全景图）时很省事。
3. **大小限制**：size 最大 1024*1024；markers 最多 10 个；labels 最多 10 个；paths 最多 4 个。
4. **高清图**：scale=2 时宽高与 zoom 双倍（zoom 达最大值 17 时不再变）。
5. **合规**：须遵守《自定义地图服务协议》；图片通常需要服务端代理或直接以 URL 引用（注意防盗链/缓存）。
6. **配额**：调用量限制见控制台"配额管理"（政策会调整）。

## 8. 项目对接建议

| 用途 | 拼接要点 | 落点设想 |
|---|---|---|
| 公开文章页门店图 | `location=门店经纬度&zoom=15&size=400*300&markers=mid,,:lng,lat` + 门店名 label | `public_handler.go` 文章页模板地址块旁加 `<img>`；URL 由门店经纬度拼装（已落库） |
| 附近同行全景图 | 省略 location/zoom，传多门店 markers（≤10） | `NearbyUseCase` 返回的 MapRanking 经纬度直接拼 markers |
| 导航卡片 | markers + labels（门店名，fontSize 16） | 分发/文章页"一键导航"配图 |

> 对接骨架：`adapter/geo` 新增 `StaticMap` 适配器（纯 URL 拼装，无 HTTP 解析——直接返回图片 URL 或代理下载），mock 降级返回占位图；门店 `HasGeo()` 为 true 即可用。
