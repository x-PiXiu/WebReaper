# 混剪业务详细分析

> 最后更新：2026-08-31
> 定位：B-Roll 画面插入合成业务的服务端实现细节分析

---

## 一、业务概述

混剪业务（B-Roll 合成）提供**在口播视频的指定句子处插入画面片段**的能力。

**核心价值**：
- 提升口播视频视觉丰富度（纯口播→口播+产品画面/场景画面）
- 精准对齐（按台词时间轴定位，每句话对应一个画面）
- 本地合成（ffmpeg，不依赖外部 API）
- 支持图片/视频片段
- 单阶段操作（29号计划：配置+生成+插入一体化）

## 四、服务端实现细节

### 4.1 台词时间轴定位（LocateTimeline）

**入口**：`POST /api/v1/generation/tasks/:id/timeline`

**处理流程**：

```go
// videocompose/timeline.go - LocateTimeline() [line 79]
func (uc *UseCase) LocateTimeline(ctx context.Context, tenantID, taskID string, 
    force bool, linesOverride []port.TimelineLineOverride) ([]TimelineLine, string, error) {
    
    // ① 文字修正模式（只改各行text，时间窗不动）
    if len(linesOverride) > 0 {
        meta.Lines[o.Index].Text = o.Text
        return meta.Lines, meta.ScriptSource, nil
    }

    // ② 缓存命中（非force）
    if meta, ok := parseTimeline(task.TimelineJSON); ok && !force {
        return meta.Lines, meta.ScriptSource, nil
    }

    // ③ 下载成片（SSRF防护）
    mediaPath, cleanup, _ := uc.safeDownloadTaskMedia(ctx, task)
    defer cleanup()

    // ④ 静音检测（三级阈值）
    segs, _ := uc.av.DetectSpeechSegments(ctx, mediaPath)

    // ⑤ 台词配对
    script := taskScript(task)
    if script != "" {
        // A/B路径：台词行与语音段配对
        lines := splitLines(script)
        meta = alignSegments(segs, lines)
    } else {
        // C路径：ASR全文→按段时长比例切行
        audioPath, _ := uc.av.ExtractAudio(ctx, mediaPath)
        text, _ := uc.transcriber.Transcribe(ctx, audioPath, "audio/mpeg", 0)
        meta = splitBySegments(segs, text)
    }

    // ⑥ 保存时间轴
    uc.saveTimeline(ctx, task, meta)
    return meta.Lines, meta.ScriptSource, nil
}
```

**三种配对模式**：

| 模式 | 条件 | 算法 | 精度 |
|------|------|------|------|
| direct | 段数M == 句数N | 一一对应 | 高 |
| estimated (合并) | M > N | 按字符比例合并相邻段 | 中 |
| estimated (拆分) | M < N | 按字符比例拆分段 | 中 |

**台词来源**：
- **A路径**：用户手写文案（params.script）→ splitLines 切行
- **B路径**：链接提取文案（params.script）→ splitLines 切行
- **C路径**：上传音频（无 script）→ ASR 识别 → splitBySegments 切行

**边界语义**：

```go
// timeline.go - applyBoundarySemantics()
// 起点 = 上一静音段中点（首行 start-150ms clamp≥0）
// 终点 = 本句语音结束（不动）
```

### 4.2 B-Roll 合成（SubmitCompose）

**入口**：`POST /api/v1/generation/submit` (sub_type=compose)

**前置条件**：源成片必须已定位时间轴（timeline_json 非空）

**处理流程**：

```go
// videocompose/compose.go - SubmitCompose() [line 33]
func (uc *UseCase) SubmitCompose(ctx context.Context, in port.ComposeInput) (port.ComposeResult, error) {
    // ① 校验：ffmpeg 可用
    if uc.av == nil || !uc.av.Available() {
        return error("ffmpeg 不可用")
    }

    // ② 校验：源任务存在且有时间轴
    src, _ := uc.tasks.FindByID(ctx, in.TenantID, in.SourceTaskID)
    meta, ok := parseTimeline(src.TimelineJSON)
    if !ok {
        return error("源成片尚未定位台词时间轴")
    }

    // ③ 校验：句号有效 + 窗口互不重叠
    for _, s := range in.Segments {
        if s.SentenceIndex < 0 || s.SentenceIndex >= len(meta.Lines) {
            return error("句号越界")
        }
    }
    // 重叠检测...

    // ④ 创建 compose 任务
    task := entity.GenerationTask{
        ID:       "comp-" + nano,
        SubType:  "compose",
        Model:    "local-ffmpeg",
        Provider: "local",
        State:    entity.TaskStateQueueing,
    }
    uc.tasks.Save(ctx, task)

    // ⑤ 后台执行
    go uc.execute(task.ID, in.TenantID, mainURL, resolvedSegs)

    return port.ComposeResult{TaskID: task.ID, State: task.State}, nil
}
```

### 4.3 后台执行（execute）

```go
// videocompose/compose.go - execute() [line 122]
func (uc *UseCase) execute(taskID, tenantID, mainURL string, segs []resolvedSeg) {
    ctx, cancel := context.WithTimeout(context.Background(), 10*time.Minute)
    defer cancel()

    // ① 并发闸门（2并发，ctx取消即让位）
    select {
    case composeSem <- struct{}{}:
        defer func() { <-composeSem }()
    case <-ctx.Done():
        setState(entity.TaskStateCancelled, "排队中超时/取消")
        return
    }
    setState(entity.TaskStateProcessing, "")

    // ② 安全下载全部媒体（SSRF校验 + 500MB上限）
    mainPath, cleanupMain, _ := safeDownloadMedia(ctx, mainURL)
    defer cleanupMain()

    segPaths := make([]string, len(segs))
    for i, s := range segs {
        p, cleanup, _ := safeDownloadMedia(ctx, s.url)
        defer cleanup()
        segPaths[i] = p
    }

    // ③ 片段预检（视频流校验 + 图片预转视频）
    specs := make([]port.InsertSegmentSpec, len(segs))
    for i, r := range segs {
        hasVideo, _ := uc.av.ProbeHasVideoStream(ctx, segPath)
        if !hasVideo {
            setState(TaskStateFailed, "纯音频不支持插入")
            return
        }
        // 图片 → 循环视频（时长=窗口时长）
        if isImagePath(segPath) {
            dur := float64(r.spec.EndMs-r.spec.StartMs) / 1000
            uc.av.LoopImageToVideo(ctx, segPath, dur, loopPath)
            segPath = loopPath
        }
        specs[i] = port.InsertSegmentSpec{
            StartMs:   r.spec.StartMs,
            EndMs:     r.spec.EndMs,
            MediaPath: segPath,
        }
    }

    // ④ ffmpeg 合成
    outPath := mainPath + ".broll.mp4"
    uc.av.ComposeInsertSegments(ctx, mainPath, specs, outPath)

    // ⑤ 产物上传到存储
    outURL, _ := uc.uploadCreation(ctx, tenantID, outPath)

    // ⑥ 更新任务状态
    task.State = entity.TaskStateSuccess
    task.CreationsJSON = marshal([]map[string]any{{"url": outURL}})
    uc.tasks.Save(ctx, task)
}
```

**关键设计**：
- **并发闸门**：最多 2 个 ffmpeg 进程同时运行，避免 CPU 过载
- **SSRF 防护**：下载前校验 URL（禁止内网地址）
- **图片预转**：图片自动转为循环视频（时长=窗口时长）
- **超时控制**：单次合成上限 10 分钟

## 五、ffmpeg 合成细节

### 5.1 滤镜链（29号改进）

```go
// adapter/mediaav/compose.go - ComposeInsertSegments()
// 滤镜逻辑（29号改进：移除 tpad + shortest）：
// 1. 每个片段缩放到主视频分辨率（scale + crop）
// 2. overlay 时间窗控制（enable='between(t,S,E)'）
// 3. 音频直拷（不重编码）

// 改进前（定格+截断）：
// [i:v]scale=W:H,...,tpad=stop_mode=clone:stop_duration=3600[si]
// [prev][si]overlay=0:0:enable='between(t,S,E)':shortest=1[next]

// 改进后（自然播放）：
// [i:v]scale=W:H,...[si]
// [prev][si]overlay=0:0:enable='between(t,S,E)'[next]
```

### 5.2 插入逻辑改进（29号计划）

**核心理念**：时间窗是**起始标记**（片段从这里开始播放），不是**严格边界**。

| 极端情况 | 改进前 | 改进后 | 实现 |
|----------|--------|--------|------|
| 片段比时间窗长 | `shortest=1` 截断 | 不截断，播完整个片段 | 移除 shortest |
| 片段比时间窗短 | `tpad=clone` 定格 | 播完后显示原片 | 移除 tpad |
| 图片片段 | 循环视频 | 静态显示到时间窗结束 | LoopImageToVideo 时长=时间窗 |
| 时间窗重叠 | 校验报错拒绝 | 后续片段优先 | 移除重叠检测 |
| 同句重复插入 | 校验报错拒绝 | 保持拒绝 | 保留重复检测 |

### 5.3 输入输出

```
输入：
  - 主视频：口播成片（lip_sync/reference2video 产物）
  - 片段1：图片或视频（第3句开始播放）
  - 片段2：图片或视频（第5句开始播放）

输出：
  - 合成视频：主视频 + 片段从指定句开始播放
  - 片段播完后，原片自然显示（不定格、不截断）
```
