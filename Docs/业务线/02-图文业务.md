# 图文业务详细分析

> 最后更新：2026-08-31
> 定位：图文内容业务的服务端实现细节分析

---

## 一、业务概述

图文业务是 WebReaper 的内容创作核心之一，提供**AI 生成图文内容**的能力，主要服务于 GEO 优化（AI 搜索引擎品牌曝光）和多平台发布。

**核心价值**：
- 批量生产高质量图文内容（小红书笔记/知乎文章/公众号文章）
- SEO 优化（针对 AI 搜索引擎的内容结构优化）
- 规则评分（权威性/专业性/结构/唯一性/时效性）
- 多平台适配（标题长度/标签/Emoji密度）

## 四、GEO 内容优化（核心）

### 4.1 内容生成流程

```
用户输入：品牌ID + 关键词 + 内容类型
    │
    ▼
① ContentUseCase.Generate()
    │  读取品牌信息（名称/定位/卖点/竞品）
    │  读取关键词（搜索意图）
    │  构建 prompt（品牌上下文 + 关键词 + 内容类型）
    │
    ▼
② AIGenerator.Generate()
    │  调用 LLM 生成初稿
    │  RAG 增强：知识库检索相关素材注入 prompt
    │
    ▼
③ RuleScorer.Score()
    │  规则评分（5个维度）：
    │  - 权威性 (authority)
    │  - 专业性 (specificity)
    │  - 结构 (structure)
    │  - 唯一性 (uniqueness)
    │  - 时效性 (recency)
    │
    ▼
④ 写入 geo_optimized_contents 表
    │  status = "draft"
    │  score_total = 5个维度加权平均
    │
    ▼
⑤ 用户编辑 → 确认 → 发布
```

### 4.2 服务端实现

```go
// geo/content.go - Generate()
func (uc *ContentUseCase) Generate(ctx context.Context, tenantID, brandID, keywordID string, contentType string) (entity.OptimizedContent, error) {
    // ① 读取品牌信息
    brand, _ := uc.brandRepo.FindByID(ctx, tenantID, brandID)

    // ② 读取关键词
    keyword, _ := uc.keywordRepo.FindByID(ctx, keywordID)

    // ③ RAG 增强：检索知识库素材
    var knowledgeContext string
    if uc.knowledgeRetriever != nil {
        materials, _ := uc.knowledgeRetriever.Retrieve(ctx, brand.Name+" "+keyword.Term, 5)
        knowledgeContext = formatMaterials(materials)
    }

    // ④ 构建 prompt
    prompt := buildContentPrompt(brand, keyword, contentType, knowledgeContext)

    // ⑤ LLM 生成
    generated, _ := uc.aiGenerator.Generate(ctx, prompt)

    // ⑥ 规则评分
    score := uc.ruleScorer.Score(generated)

    // ⑦ 写入数据库
    content := entity.OptimizedContent{
        ID:            "oc-" + nano,
        TenantID:      tenantID,
        BrandID:       brandID,
        KeywordID:     keywordID,
        OptimizedText: generated,
        ScoreTotal:    score.Total,
        Authority:     score.Authority,
        Specificity:   score.Specificity,
        Structure:     score.Structure,
        Uniqueness:    score.Uniqueness,
        Recency:       score.Recency,
        Status:        "draft",
    }
    uc.contentRepo.Save(ctx, content)
    return content, nil
}
```

### 4.3 规则评分系统

```go
// geo/rule_scorer.go
type RuleScorer struct{}

func (s *RuleScorer) Score(text string) ScoreResult {
    return ScoreResult{
        Authority:   s.scoreAuthority(text),    // 权威性：引用数据/专家观点
        Specificity: s.scoreSpecificity(text),  // 专业性：行业术语/细节
        Structure:   s.scoreStructure(text),    // 结构：标题/段落/列表
        Uniqueness:  s.scoreUniqueness(text),   // 唯一性：差异化内容
        Recency:     s.scoreRecency(text),      // 时效性：时间引用
        Total:       weighted,                  // 加权平均
    }
}
```

**评分维度**：
| 维度 | 权重 | 检测规则 |
|------|------|----------|
| 权威性 | 25% | 引用数据、专家观点、来源链接 |
| 专业性 | 25% | 行业术语、具体数字、细节描述 |
| 结构 | 20% | 标题层级、段落分明、列表使用 |
| 唯一性 | 15% | 差异化观点、独特卖点 |
| 时效性 | 15% | 时间引用、最新数据 |

### 5.2 请求参数

```go
// endpoint_selector.go - buildText2ImageParams()
func (s *EndpointSelectorImpl) buildText2ImageParams(req entity.UnifiedGenerationRequest, stats MaterialStats) entity.GenerationParams {
    params := entity.GenerationParams{
        "prompt": req.Text,
    }
    // 参考图写入 images
    if len(stats.Images) > 0 {
        urls := make([]string, 0, len(stats.Images))
        for _, img := range stats.Images {
            urls = append(urls, img.SourceURL)
        }
        params["images"] = urls
    }
    return params
}
```

## 七、数据库表结构

### 7.1 geo_optimized_contents（GEO 优化内容表）

```sql
CREATE TABLE geo_optimized_contents (
    id VARCHAR(64) PRIMARY KEY,
    tenant_id VARCHAR(64) NOT NULL,
    brand_id VARCHAR(64) NOT NULL,
    keyword_id VARCHAR(64),
    title VARCHAR(256),
    original_text LONGTEXT,      -- 原始文本（优化前）
    optimized_text LONGTEXT,     -- 优化后文本
    version INT DEFAULT 1,       -- 版本号
    score_total DECIMAL(5,2),    -- 总分
    authority DECIMAL(5,2),      -- 权威性
    specificity DECIMAL(5,2),    -- 专业性
    structure DECIMAL(5,2),      -- 结构
    uniqueness DECIMAL(5,2),     -- 唯一性
    recency DECIMAL(5,2),        -- 时效性
    status VARCHAR(32) DEFAULT 'draft',  -- draft/published
    index_status VARCHAR(16),    -- 收录状态
    indexed_at DATETIME,         -- 收录时间
    created_at DATETIME(3)
);
```

### 7.2 generation_tasks（生成任务表）

```sql
-- 文生图/文生视频任务
CREATE TABLE generation_tasks (
    id VARCHAR(64) PRIMARY KEY,
    tenant_id VARCHAR(64) NOT NULL,
    type VARCHAR(32),           -- video/image
    sub_type VARCHAR(64),       -- text2image/text2video
    model VARCHAR(64),          -- viduq1/viduq3
    state VARCHAR(16),          -- created/queueing/processing/success/failed
    params_json TEXT,            -- 提交参数
    creations_json TEXT,         -- 产物信息
    credits INT,                 -- 消耗积分
    created_at DATETIME(3),
    finished_at DATETIME(3)
);
```
