## 三、核心架构特性

### 3.1 统一占位符翻译系统（28号计划）

```
客户端请求
    │  prompt="@主播 在 @背景图 前讲解"
    │  refs=[{name:"背景图", url:"...", kind:"image"}]
    ▼
PlaceholderTranslator.Translate()
    ├─ 素材引用（@背景图）→ translateRefs → images[]
    └─ 主体引用（@主播）→ ProviderPlaceholderRule
        ├─ Vidu: 保留 @name + subjects 数组
        └─ 其他厂商: 移除 @name，纯文本
    ▼
EndpointAdapter.BuildRequest()
    │  组装最终请求体
    ▼
Provider.Submit()
```

**厂商规则注册表**：
| 厂商 | KeepSubjectRef | 说明 |
|------|---------------|------|
| vidu | true | 保留 @name，添加 subjects 数组 |
| xiaomi-mimo | false | 移除 @name，纯文本 |

### 3.2 资产物化机制

```
任务终态 success
    │
    ├─ sub_type=subject → upsert subject_assets
    ├─ sub_type=voice_clone → upsert generation_voices(scope=clone)
    └─ sub_type=reference2video (avatar_video=true) → 回填 avatar_video_url
```

### 3.3 双通道异步

```
生成任务提交
    │
    ├─ 同步端点（subject/tts-mimo）→ 直接返回结果
    └─ 异步端点（video/image/audio）→ 进入双通道
        ├─ 回调通道（秒级推送）：Vidu 主动 POST
        └─ 轮询通道（20s 兜底）：定时扫描未终态
```

## 四、数据一致性问题（已发现）

### 4.1 已确认问题

| # | 严重度 | 问题 | 影响 | 状态 |
|---|--------|------|------|------|
| 1 | 🔴 高 | 3条成功 voice_clone 无对应音色记录 | 用户看不到克隆音色 | ⚠️ 需回填 |
| 2 | 🟡 中 | 1条 subject_asset 的 avatar_video_url 为空（有成功形象视频） | 分身无形象视频预览 | ⚠️ 需回填 |
| 3 | 🟡 中 | 14条发布任务 content_type 为空 | 前端展示异常 | ⚠️ 需修复 |
| 4 | 🟡 中 | 1656条 usages scene 为空 | 配额统计不准 | ℹ️ admin操作 |

### 4.2 回填脚本

```sql
-- 回填1：voice_clone 成功任务物化到 generation_voices
INSERT INTO generation_voices (voice_id, language, name, sample_url, scope, tenant_id, source_task_id, status)
SELECT
    JSON_UNQUOTE(JSON_EXTRACT(t.params_json, '$.voice_id')),
    '克隆音色',
    CONCAT('克隆-', LEFT(JSON_UNQUOTE(JSON_EXTRACT(t.params_json, '$.voice_id')), 8)),
    COALESCE(JSON_UNQUOTE(JSON_EXTRACT(t.creations_json, '$[0].url')), ''),
    'clone',
    t.tenant_id,
    t.id,
    'active'
FROM generation_tasks t
WHERE t.sub_type = 'voice_clone' AND t.state = 'success'
AND JSON_UNQUOTE(JSON_EXTRACT(t.params_json, '$.voice_id')) NOT IN (
    SELECT voice_id FROM generation_voices WHERE scope = 'clone'
)
ON DUPLICATE KEY UPDATE updated_at = NOW();

-- 回填2：有成功形象视频但 avatar_video_url 为空的 assets
UPDATE subject_assets sa
SET avatar_video_url = (
    SELECT JSON_UNQUOTE(JSON_EXTRACT(t.creations_json, '$[0].stored_url'))
    FROM generation_tasks t
    WHERE t.sub_type = 'reference2video' AND t.state = 'success'
    AND t.params_json LIKE CONCAT('%', sa.server_id, '%')
    AND t.params_json LIKE '%avatar_video%'
    LIMIT 1
),
updated_at = NOW()
WHERE sa.avatar_video_url = ''
AND sa.server_id IN (
    SELECT DISTINCT JSON_UNQUOTE(JSON_EXTRACT(t.params_json, '$.subjects[0].server_id'))
    FROM generation_tasks t
    WHERE t.sub_type = 'reference2video' AND t.state = 'success'
    AND t.params_json LIKE '%avatar_video%'
);

-- 回填3：content_type 为空的发布任务
UPDATE geo_publish_jobs SET content_type = 'article' WHERE content_type = '' OR content_type IS NULL;
```
