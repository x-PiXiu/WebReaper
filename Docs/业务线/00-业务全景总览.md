## 三、业务协同关系

```
灵感采集 ──→ 图文业务 ──→ 多平台发布 ──→ 数据分析
    ↓              ↓              ↓
素材管理 ──→ 口播业务 ──→ 多平台发布
    ↓              ↓              ↓
分身管理 ──→ 混剪业务 ──→ 多平台发布
    ↓              ↓
音色管理 ──→ 音频业务 ──→ 口播业务

GEO优化 ←── 多平台发布 ──→ 收录优化
    ↓
智能体对话 ──→ 调用所有业务工具
    ↓
知识库 ──→ RAG增强图文业务
```

## 五、API 端点分布

| 域 | 主要端点 | 说明 |
|----|----------|------|
| 内容创作 | POST /generation/submit | 统一生成提交 |
| 分发获客 | GET /geo/*, POST /geo/publish | GEO监测+发布 |
| 资源管理 | GET /subjects, GET /generation/voices | 主体+音色查询 |
| 智能服务 | POST /chat, GET /knowledge/* | 对话+知识库 |
| 计费 | GET /billing/*, POST /billing/orders | 套餐+订单 |
