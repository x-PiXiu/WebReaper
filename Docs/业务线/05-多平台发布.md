# 多平台发布详细分析

> 最后更新：2026-08-31
> 定位：多平台内容分发业务的服务端实现细节分析

---

## 一、业务概述

多平台发布把口播/图文/文章作品一键分发到 7 个平台（知乎/小红书/抖音/快手/B站/视频号/YouTube），
提供**半自动**（生成预填发布链接，用户手动完成）与**全自动**（RPA 浏览器代发）两种模式，
配套账号绑定/健康巡检/配额限流/定时发布/发布后互动数据回读。

**能力诚实化原则（Plan-14）**：全自动只在**真机验证过**的 平台×形态 放行，其余诚实降级半自动——
当前放行：知乎{文章}、小红书{图片}（`account.go:530-533` verifiedAutoForms）。

## 二、用户旅程

```
【账号池】绑定账号（扫码 QRLogin / 抖音官方 OAuth）→ 健康巡检（10min 周期）
      OAuth 双时钟续期：access 到期前 48h 刷新；refresh 窗口关前 7 天续期
      （抖音 15天/30天续5次 → 最长 195 天）
          ↓
【发布向导·五步】① 平台与形态（健康账号多选卡）
      ② 标题与正文（服务端 adapt-preview 预览各平台截断/清洗）
      ③ 素材（AssetPicker 复用） ④ 平台参数（B站分区/标签/全自动/自动选号/定时）
      ⑤ 预览确认（多平台适配预览 + 配额拦截 + 完备性检查）
          ↓
【发布执行】半自动：生成预填链接新窗口打开 → 用户手动发 → 标记已发布（此刻才记配额）
      全自动：账号池取号（最久未用优先）→ 通道轴 [api→]rpa→link 降级
      → RPA 上传/填表/点发布 → 成功取作品链接
      定时：scheduled_at 到期由定时任务（5min 扫描）执行
          ↓
【发布后】互动数据回读（24h 批量+单条手动刷新）→ 提及率前后对比（GEO 效果追踪）
      → 复测（手动/自动 6h）→ 发布记录 Tab 统计
```

## 三、发布通道（7 平台）

| 平台 | 支持形态 | 关键约束 | 全自动 | 半自动 URL |
|------|---------|---------|--------|-----------|
| 知乎 | article | 标题≤100 | ✅ 已验证 | zhuanlan.zhihu.com/write（正文不预填 CSRF） |
| 小红书 | image/video/article/audio | 标题≤20、图片≥1 | 图片✅ | creator.xiaohongshu.com/publish |
| 抖音 | video | 标题≤55、视频≥1 | 实现/未放行 | creator.douyin.com/creator-micro |
| 快手 | video | 标题≤80、视频≥1 | stub | cp.kuaishou.com/article/publish/video |
| B站 | video | 标题≤80、必填标签+分区≤10 | 实现/未放行 | member.bilibili.com/platform/upload |
| 视频号 | video+image | 标题≤40（RPA 层仅留汉字截16字） | 实现/未放行 | channels.weixin.qq.com/platform/media |
| YouTube | video | 标题≤100、隐私性 public/unlisted/private | cookie 手动导入 | studio.youtube.com（cookie 双域种值） |

**RPA 技术要点**：抖音四级降级上传+网络响应拦截取 aweme_id；B站标签 JS 设值+CDP 回车防中文双插入、
发布按钮 iframe/micro-app 全文档穿透；健康预检=导航后 URL 回落登录页即标过期。
**DRY_RUN 演练**：`PUBLISH_DRY_RUN=true` 走完上传+填表+截图但**绝不点发布**（真机校准选择器用）。

## 四、服务端实现细节

### 4.1 发布主流程（PublishUseCase.Publish，account.go:612-711）

```
mode 默认 semi-auto → registry.Get(platform) → validateCapability（服务端强校验
  标题/素材数/标签/分区）→ checkPublishLimit（品牌 RateLimit.MaxPerDay 限流）
→ 内容预处理：剥思考标签 + Markdown 转纯文 + 知乎追加公开站链接 + 门店地址注入
→ 标题空/<4字 → ExtractTitle(正文)
→ job 落库（pj-{nano}，pending）
→ 定时：ScheduledAt 未来 → 直接返回，定时任务执行（半自动到期回 pending 供确认）
→ 全自动 publishAuto / 半自动生成 ExternalURL
```

**通道轴降级**（:757-795）：OAuth 账号前置 api 通道，默认候选 `[rpa, link]`；凭证预检失败短路下一通道。
**降级只发生在启动前**——执行中失败不自动换通道重发（防重复发布事故）。

### 4.2 全自动执行（:714-871）

未指定账号 → 账号池 Acquire（active + 最久未用优先）；running 落库 → 后台 goroutine（5min 超时）
`PublishAuto` → published/failed → Release 回池 → `trackPublishEffect`（发布前后提及率）。
成功记 `publish_usage_stats`（配额依据）。僵尸清扫：启动时 ReapStaleJobs(30min)。

### 4.3 内容适配（content_adapter.go）

DefaultPlatformConfigs 按平台声明 标题/描述/标签上限 + Emoji 密度 + CTA 策略；
`Adapt`：截断加省略号/换行限制/Emoji 移除/标签提取合并/随机 CTA。
预览端点 `POST /merchant/publish/adapt-preview`（前端失败时 localAdaptPreview 兜底）。

### 4.4 账号体系

- 实体：CookieEncrypted（AES-GCM）/Health(active|expired|banned，banned 不可恢复)/AuthType(cookie|oauth)
- 绑定：扫码（知乎四方式）+ 抖音 OAuth（同 open_id 重新授权=续期）
- 巡检：AccountHealthTask 10min；OAuth 双时钟续期
- 账号池 + 品牌绑定（BrandAccountSelector 绑定优先回退全局）+ 人设隔离（persona_isolator）

### 4.5 定时与自动闭环

- ScheduledPublishTask 5min：ListScheduledDue → ExecuteScheduledJob → 站内通知
- AutoPublishTask 5min：生成→发布闭环（开关 auto_publish_enabled，仅 video/image，半自动）
- AutoMonitorAfterPublishTask 10min / AutoRecheckTask 6h（GEO 效果）

### 4.6 发布后数据回读

单条 RefreshJobMetrics（published + 可解析视频 ID 才可回读）→ socialSearch.GetVideoDetail
→ video_metrics 时间序列；批量 RunMetricsReadback 每日（500 条、2s 间隔防风控）；
聚合 AnalyticsSummary（指标卡+14 天趋势+作品列表）。
**半自动限制**：手动发布无作品链接 → 无法回读（前端显示"链接未追踪"）。
