# 音频业务详细分析

> 最后更新：2026-08-31
> 定位：TTS 语音合成 + 声音克隆业务的服务端实现细节分析

---

## 一、业务概述

音频业务提供**文本转语音（TTS）与音色克隆**能力，是口播/图文/工具台配音的底层供给。

**双厂商通道**（CapabilityResolver 按能力路由，兜底 defaultProvider）：

| 厂商 | TTS | 克隆 | 语义 | 音色 |
|------|-----|------|------|------|
| Vidu | `/ent/v2/audio-tts`（异步任务） | `/ent/v2/audio-clone`（同步即终态） | 统一任务（submit/poll） | 302 条官方音色表 |
| 小米 MiMo | `mimo-v2.5-tts`（chat 协议同步） | `mimo-v2.5-tts-voiceclone`（同步，样本 base64） | 同步返回 base64 音频 | 9 个预置音色（Vidu 音色 ID 一律降级 mimo_default） |

**口播主路径已不经独立 TTS**（01 号：文本驱动 lip_sync/reference2video 端内合成语音）——
独立 TTS 现存于：生成弹窗（配音）、合成轨道配音步骤、工具台高级表单、素材库。

## 二、用户旅程

### 2.1 配音生成（TTS）

```
选/输入文本 → 选音色（VoicePicker：平台精选置顶 > 推荐标记 > 按语言分组 > 我的克隆）
  → 可调 speed(0.5-2)/volume(0-10)/pitch(-12~12)/emotion(7 种)
  → 提交（type='audio'，无 materials）
  → Vidu 异步任务轮询 / MiMo 同步即得
  → 产物音频：试听 + 自动写入素材库（24h URL → stored_url 永久化）
```

### 2.2 声音克隆

```
上传参考人声（mp3/m4a/wav，10 秒-5 分钟）→ 填音色 ID（留空自动 vc-<ts>，
规则：字母开头、8-256 位 [a-zA-Z0-9_-]）→ 填试听文案（≤1000 字）
  → 提交（type='voice'，materials=[音频素材 ID]，params.voice_id）
  → 同步即终态：creations[0] = demo_audio 试听 URL
  → 物化：generation_voices 写入 scope=clone 行（音色库"我的"Tab 即显）
  → ⚠️ 7 天内需在语音合成中调用一次转永久（Vidu 侧规则，仅前端提示）
```

### 2.3 官方音色管理（管理后台，建设中）

```
运营上传样本音频 + 介绍文本 → SynthesizeClone 合成试听 → voice_id=platform-<ts>
  → generation_voices 写入 scope=platform 行 → 用户端 VoicePicker"平台精选"置顶
```

## 三、涉及的生成端点

| 端点 | sub_type / type | 用途 | 输入 | 输出 |
|------|-----------------|------|------|------|
| 语音合成 | `tts`（type='audio'） | 文本→音频 | text + voice_setting_* | 音频 URL |
| 声音克隆 | `voice_clone`（type='voice'） | 样本→专属音色 | audio_url + voice_id + 试听文本 | demo_audio |
| 文本转音频² | `text2audio` | 短音频（2-10s，≤1500 字） | text | 音频 |
| 音效² | `sound_effect` | 事件音效 | timing_prompts | 音频 |

> ²：`ClosedDefaultModes` 默认关闭（registry.go:83-89），管理后台可开。

## 四、服务端实现细节

### 4.1 Vidu TTS（endpoints_media.go:138-197）

- 参数：`text`（≤10000，支持 `<#x#>` 停顿标记——`convertPauseMarkers` 标点自动转换）、
  `voice_setting_voice_id`（必填）、`voice_setting_speed/volume/pitch/emotion`
- 异步任务语义：提交 → queueing → 轮询推进；成功产物 `file_url` → 转存

### 4.2 小米 MiMo 通道（ttsmimo/）

三份实现，实际装配 `MiMoAsGenerationProvider`（包装为 GenerationProvider，name="xiaomi-mimo"）：
- TTS：`mimo-v2.5-tts`，chat 协议 `messages=[{role:assistant,content:text}]`，
  `audio{format:mp3, voice}`；同步返回 `choices[0].message.audio.data`（base64）
- 克隆：`mimo-v2.5-tts-voiceclone`，`audio.voice = 样本 DataURL`；**不返回 voice_id——
  每次合成需重传样本**（与 Vidu 的注册制 voice_id 模型不同）
- 音色映射 `mimoVoiceID`：MiMo 9 音色直传；**Vidu 302 个音色 ID 一律降级 `mimo_default`**
- `QueryCredits=999999`（MiMo 免费额度）
- Key 解析顺序：`MIMO_API_KEY` → resolver("tts") → resolver("voice-clone")（main.go:941-957）

### 4.3 端点选择与默认音色（endpoint_selector.go）

- 自动路由：`AudioCount>0 && Image==0 && Video==0` → tts（:261-266）；
  显式 `type='audio'`→tts、`type='voice'`→voice_clone（:304-311）
- `buildTTSParams`：text + 显式音色；`applyDefaultVoice`（:589-604）：未选音色时读
  系统设置 `gen_default_voice_id`（回落 `female-shaonv`）——tts 写 `voice_setting_voice_id`、
  lip_sync 写 `voice_id`
- tts/voice_clone/text2audio 不注入 resolution/aspect_ratio（:562-577）
- `buildVoiceCloneParams`（:335-354）：`params.voice_id` 优先，否则自动 `vc-<UnixNano>`

### 4.4 Vidu 声音克隆（endpoints_media.go:199-250）

- 校验：`audio_url` 必填（mp3/m4a/wav，10s-5min）；`voice_id` 8-256 位字母开头
  `[a-zA-Z0-9_-]`；试听 `text` ≤1000
- **同步即终态**：创建响应携带 `demo_audio` → `applySubmitResult`（generation.go:807-835）
  直接置 success + 触发 24h URL 转存

### 4.5 音色物化（26 号计划）

```
voice_clone 任务 state=success
  → maybeMaterializeAsset（generation.go:432-449）
  → materializeVoiceClone（:558-601）：
      voiceID = params.voice_id
      sampleURL = creations[0].stored_url || url || demo_audio
      → Upsert generation_voices{Scope:'clone', TenantID, SourceTaskID, Status:'active'}
```

失败/取消不物化（资产列表天然干净）。

### 4.6 计费

- 配额闸门：与视频共用 `generation` 场景（quotaGate.Check，generation.go:669-671）
- 积分：`resolveCredits` 优先 `generation_specs.cost_credits`（当前全 0——用服务商返回值）
- 套餐：free 10 次/月、中间档 200/月、team 不限（billing/seed.go）

## 五、数据库表结构

### generation_voices（音色资产表，082 迁移后）

```sql
CREATE TABLE generation_voices (
    voice_id VARCHAR(128) PRIMARY KEY,
    language VARCHAR(64),          -- 分组（中文 (普通话)/英文…/克隆音色/平台精选）
    name VARCHAR(128),
    sample_url VARCHAR(512),       -- 试听音频
    recommend TINYINT(1) DEFAULT 0, -- 精选标记（077 迁移，8 条口播精选）
    scope VARCHAR(16) DEFAULT 'vidu',  -- vidu(官方表 seed)/platform(官方复刻)/clone(用户克隆)
    tenant_id VARCHAR(64) DEFAULT '',   -- clone 行归属；官方行空
    source_task_id VARCHAR(64),
    status VARCHAR(16) DEFAULT 'active'
);
```

- seed：302 条 Vidu 官方音色（表空时写入，viduendpoint/voices.go）
- 查询：`GET /api/v1/generation/voices?language=&q=`（仅两过滤参数，无分页，Limit 1000）
