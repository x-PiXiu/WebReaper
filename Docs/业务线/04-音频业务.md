# 音频业务详细分析

> 最后更新：2026-09-01（逐项核对服务端代码后修订）
> 定位：TTS 语音合成 + 声音克隆业务的服务端实现细节分析

---

## 一、业务概述

音频业务提供**文本转语音（TTS）与音色克隆**能力，是口播/图文/工具台配音的底层供给。

**双厂商通道**（CapabilityResolver 按能力路由，兜底 defaultProvider）：

| 厂商 | TTS | 克隆 | 语义 | 音色 |
|------|-----|------|------|------|
| Vidu | `/ent/v2/audio-tts`（**同步即终态**） | `/ent/v2/audio-clone`（**同步即终态**） | 创建响应携带 `file_url`/`demo_audio` → `SubmitResult.State=success` 直接落终态；响应无 state（queueing/空）才降级轮询 | 302 条上游音色（scope=vidu，**仅管理端可见**——白牌化） |
| 小米 MiMo | `mimo-v2.5-tts`（chat 协议同步） | `mimo-v2.5-tts-voiceclone`（同步，样本 base64） | 同步返回 base64 音频（`SubmitResult.State=success`，tts_as_provider.go:85） | 9 个预置音色（Vidu 音色 ID 一律降级 mimo_default） |

**白牌化（2026-09-01 用户确认）**：用户端音色只显示 `scope=platform`（管理后台创建）
和 `scope=clone AND tenant_id=本租户` 的克隆音色；`scope=vidu` 上游 302 条仅管理端可见
——作为克隆参考源（"从 Vidu 音色克隆平台音色"），不暴露给用户。

**口播主路径已不经独立 TTS**（01 号：文本驱动 lip_sync/reference2video 端内合成语音）——
独立 TTS 现存于：生成弹窗（配音）、合成轨道配音步骤、工具台高级表单、素材库。

## 二、用户旅程

### 2.1 配音生成（TTS）

```
选/输入文本 → 选音色（VoicePicker 分组：★精选推荐 > 🎤平台音色 > 我的克隆音色）
  → 可调 speed(0.5-2)/volume(0-10)/pitch(-12~12)/emotion(7 种)
  → 提交（type='audio'，无 materials）
  → Vidu/MiMo 均同步即得（创建响应携带产物；Vidu 响应无 state 时降级轮询）
  → 产物音频：试听 + 自动写入素材库（24h URL → stored_url 永久化）
```

### 2.2 声音克隆

```
上传参考人声（mp3/m4a/wav，10 秒-5 分钟，≤20MB）→ 填音色 ID（留空自动 vc-<ts>，
规则：字母开头、8-256 位 [a-zA-Z0-9_-]）→ 填试听文案（必填 ≤1000 字）
  → 提交（type='voice'，materials=[音频素材 ID]，params.voice_id）
  → 同步即终态：creations[0] = demo_audio 试听 URL（ID 固定 "demo_audio"）
  → 物化：generation_voices 写入 scope=clone 行（音色库"我的"Tab 即显）
  → ⚠️ 7 天内需在语音合成中调用一次转永久（Vidu 侧规则，仅前端提示）
```

### 2.3 官方音色管理（管理后台，已建成）

**创建方式一：上传/URL 样本克隆**
```
运营上传样本音频（multipart）或给 audio_url（JSON）+ 介绍文本
  → SynthesizeClone（MiMo）合成试听 → voice_id=platform-<ts>
  → generation_voices 写入 scope=platform 行 → 用户端 VoicePicker"🎤平台音色"分组
```

**创建方式二：从 Vidu 音色克隆（白牌化主路径，POST /admin/voices/from-vidu）**
```
管理端浏览 Vidu 上游音色（GET /admin/voices/vidu-sources，scope=vidu 302 条）
  → 选一个 Vidu voice_id → 后端下载其 sample_url 官方试听音频（5-15s 人声）作克隆样本
  → 克隆出平台 voice_id（跳过 TTS——MiMo 不认 Vidu voice_id，且样本音质最接近原声）
  → 写入 scope=platform；Language 默认"平台精选"
```

**默认音色机制**：`PUT /admin/voices/:id/default` 设平台默认（scope=platform 内仅一条
is_default=true）——生成未选音色时优先用它。

## 三、涉及的生成端点

| 端点 | sub_type / type | 用途 | 输入 | 输出 |
|------|-----------------|------|------|------|
| 语音合成 | `tts`（type='audio'） | 文本→音频 | text + voice_setting_* | 音频 URL |
| 声音克隆 | `voice_clone`（type='voice'） | 样本→专属音色 | audio_url + voice_id + 试听文本 | demo_audio |

> subject/reference2video/lip_sync/tts/voice_clone 五端点；管理后台可开。

## 四、服务端实现细节

### 4.1 Vidu TTS（endpoints_media.go:138-197）

- 参数：`text`（≤10000 必填，支持 `<#x#>` 停顿标记——`convertPauseMarkers` 标点自动转换）、
  `voice_setting_voice_id`（必填）、`voice_setting_speed(0.5-2)/volume(0-10)/pitch(-12~12)/
  emotion(happy/sad/angry/fearful/disgusted/surprised/calm)`
- **同步即终态**（vidu_provider.go:161-174）：创建响应 `state=success` 且携带 `file_url`
  → `SubmitResult.State=success` + Creations 直接落终态并触发转存；
  响应无 state/queueing → State 留空走轮询（兜底通道）
- 无 model 参数（registry 中 tts 能力为 `{Model:"default", MaxPromptLen:10000}`）

### 4.2 小米 MiMo 通道（ttsmimo/）

三模型（synthesizer.go:41-50），实际装配 `MiMoAsGenerationProvider`（包装为 GenerationProvider，name="xiaomi-mimo"）：
- TTS：`mimo-v2.5-tts`，chat 协议 `messages=[{role:assistant,content:text}]`，
  `audio{format:mp3, voice}`；同步返回 `choices[0].message.audio.data`（base64）→ 直接置 success
- 音色设计：`mimo-v2.5-tts-voicedesign`（`user.content` = 风格描述——port.AudioSynthesizer.SynthesizeDesign）
- 克隆：`mimo-v2.5-tts-voiceclone`，`audio.voice = 样本 DataURL`；**不返回 voice_id——
  每次合成需重传样本**（与 Vidu 的注册制 voice_id 模型不同）
- 音色映射 `mimoVoiceID`（tts_as_provider.go:144-153）：MiMo 9 音色直传；
  **Vidu 302 个音色 ID 一律降级 `mimo_default`**
- `QueryCredits=999999`（MiMo 免费额度，:136-138）
- Key 解析顺序：`MIMO_API_KEY` → resolver("tts") → resolver("voice-clone")（main.go:940-952）；
  同一 MiMoTTSProvider 实例兼作 `adminVoiceSynth`（管理后台官方音色创建，main.go:953-963）

### 4.3 端点选择与默认音色（endpoint_selector.go）

- 自动路由：`AudioCount>0 && Image==0 && Video==0` → tts（:261-266）；
  显式 `type='audio'`→tts、`type='voice'`→voice_clone（:304-311）
- `buildTTSParams`：text + 显式音色
- `applyDefaultVoice`（:595-612，白牌化 2026-09-01）**三级优先**：
  ① `voiceRepo.GetDefault()`——scope=platform 且 is_default=true 的平台默认音色
  ② system_settings `gen_default_voice_id`
  ③ 兜底 **`mimo_default`**（MiMo 预置——不再暴露 Vidu 音色 ID）
  tts 写 `voice_setting_voice_id`、lip_sync 写 `voice_id`；用户显式指定时不覆盖
- tts/voice_clone/text2audio 不注入 resolution/aspect_ratio（:562-577）
- `buildVoiceCloneParams`（:335-354）：`params.voice_id` 优先，否则自动 `vc-<UnixNano>`

### 4.4 Vidu 声音克隆（endpoints_media.go:199-250）

- 校验：`audio_url` 必填（mp3/m4a/wav，10s-5min）；`voice_id` 8-256 位字母开头
  `[a-zA-Z0-9_-]`；试听 `text` 必填 ≤1000
- 可选 `prompt_audio_url`/`prompt_text`（发音参考）
- **同步即终态**：创建响应携带 `demo_audio` → ViduProvider 解析为
  `Creations=[{ID:"demo_audio", URL:demo_audio}]` + State=success（vidu_provider.go:169-171）
  → `applySubmitResult`（generation.go:807+）的"SubmitResult.State 终态"分支直接置
  success + 触发 24h URL 转存

### 4.5 音色物化与产物转存（26 号 + 缺口A/B/C 修复）

```
voice_clone 任务 state=success
  → maybeMaterializeAsset（generation.go:432-449）
  → materializeVoiceClone（:558-595）：
      voiceID = params.voice_id（空则跳过）
      sampleURL = creations[0].stored_url || url || demo_audio
                  （缺口B防护：仅接受 http(s)——data: URI 内联会撑爆 VARCHAR(512)）
      → Upsert generation_voices{Scope:'clone', TenantID, SourceTaskID, Status:'active'}
```

失败/取消不物化（资产列表天然干净）。

**产物转存三通道（2026-09-01 修复）**：

| 通道 | 机制 |
|------|------|
| 即时转存 | applyStatus 内 DownloadAndStore（Vidu 24h URL → 本地/OSS stored_url） |
| data: URI 转存（缺口B） | MiMo 同步产物内联 base64 → ParseDataURI 解码直接落盘/上传（storage/datauri.go）——此前 http.Get 必然 "unsupported protocol scheme" |
| 定时补偿（缺口A） | TransferRetryTask 每小时扫描 success 且产物无 stored_url 的任务重试（24h 窗口内）；voice_clone 转存成功后回填空 sample_url |

### 4.7 样本合成通道（缺口C——厂商隔离）

```
tts 提交 + voice_setting_voice_id 命中 generation_voices（scope ∈ {clone, platform}）
  且 sample_url 为永久 http(s) 且文本 ≤1000 字
    → maybeRewriteSampleSynthesis（Submit 内钩子）
    → 改写为 voice_clone：{audio_url: 已存样本URL, voice_id, text}
    → 厂商重路由（tts→voice-clone 能力）
```

**价值**：
- **不依赖厂商 voice_id 生命周期**：Vidu 克隆音色 7 天不用即删——样本合成每次携带
  本地/OSS 已存样本，voice_id 被删也能继续用（Vidu 通道同 ID 复注册自动续期）
- **平台音色可用**：platform-* ID 各厂商均未注册，纯 voice_id TTS 必然失败——
  样本合成是唯一可用通道（MiMo 原生 audio.voice=样本；Vidu audio-clone demo_audio=产物）
- **lip_sync 不改写**：文本模式 voice_id 经 Vidu lip-sync 直用，每次使用即续期 7 天

### 4.6 计费

- 配额闸门：与视频共用 `generation` 场景（quotaGate.Check，generation.go:670）
- 积分：`resolveCredits` 优先 `generation_specs.cost_credits`（当前全 0——用服务商返回值）
- 套餐：free 10 次/月、中间档 200/月、team 不限（billing/seed.go:50/66/87）

## 五、数据库表结构

### generation_voices（音色资产表，082 + 083 迁移后）

```sql
CREATE TABLE generation_voices (
    voice_id VARCHAR(128) PRIMARY KEY,
    language VARCHAR(64),              -- 分组（平台精选/克隆音色/中文…）
    name VARCHAR(128),
    sample_url VARCHAR(512),           -- 试听音频
    recommend TINYINT(1) DEFAULT 0,     -- 精选标记（077 迁移）
    scope VARCHAR(16) DEFAULT 'vidu',   -- vidu(上游参考源)/platform(平台音色)/clone(用户克隆)
    tenant_id VARCHAR(64) DEFAULT '',   -- clone 行归属；官方行空
    source_task_id VARCHAR(64),
    status VARCHAR(16) DEFAULT 'active',
    is_default TINYINT(1) DEFAULT 0     -- 平台默认音色（083 迁移——scope=platform 内仅一条）
);
```

- seed：302 条 Vidu 上游音色（表空时写入，viduendpoint/voices.go），scope=vidu
- **用户端查询**：`GET /api/v1/generation/voices`（无参数）→
  `ListForUser(tenantID)`（voice_repo.go:47-52）：
  `status='active' AND (scope='platform' OR (scope='clone' AND tenant_id=?))`，
  排序 `is_default DESC, recommend DESC, language, voice_id`，tenantID 空防御返回空
- **管理端查询**：`ListForAdmin(scope)` 全量（含停用行；scope 过滤 vidu/platform/clone）
