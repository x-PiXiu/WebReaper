# 口播业务详细分析

> 最后更新：2026-08-31
> 定位：口播视频业务的服务端实现细节分析

---

## 一、业务概述

口播业务是 WebReaper 的核心业务之一，提供**数字人+对口型视频**的批量生产能力。

**核心价值**：
- 跨视频人物一致性（同一分身产出的系列视频形象统一）
- 批量生产（一个分身+多篇文案=多个视频）
- 傻瓜式操作（四步向导，用户无需专业技能）

---

## 二、用户旅程

```
┌─────────────────────────────────────────────────────────────────────────┐
│ 阶段0  数字分身准备（一次性）                                            │
│   上传形象照/视频 → 创建主体 → 自动生成10s形象视频 → 分身可用             │
└─────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────┐
│ 阶段1  台词来源（向导第①步，三选一）                                     │
│   ① 粘贴爆款链接提取文案（抖音/B站/长尾平台）                            │
│   ② 上传参考音/视频 → ASR 提取                                          │
│   ③ 手写/粘贴文案                                                       │
└─────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────┐
│ 阶段2  口播生成向导（傻瓜式分步）                                        │
│   选品牌人设 → 选出镜形态 → 选音频来源 → 对口型 → 成片                   │
└─────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────┐
│ 阶段3  B-Roll 插入（可选）                                              │
│   台词定位 → 指定句挂片段 → 合成 → 核对                                  │
└─────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────┐
│ 阶段4  发布分发                                                          │
│   选平台/账号 → 发布 → 作品库跟踪                                       │
└─────────────────────────────────────────────────────────────────────────┘
```

## 四、服务端实现细节

### 4.1 主体注册（subject）

**入口**：`POST /api/v1/generation/submit` (sub_type=subject)

**处理流程**：

```go
// generation.go - submitSubject()
func (uc *GenerationUseCase) submitSubject(ctx context.Context, in SubmitInput) (entity.GenerationTask, error) {
    // ① 创建任务记录 (state=created)
    task := entity.GenerationTask{
        ID:       "gen-" + nano,
        TenantID: in.TenantID,
        SubType:  "subject",
        State:    entity.TaskStateCreated,
    }

    // ② 提交到 Vidu API (同步接口)
    res, err := provider.Submit(ctx, endpoint, body)
    // Vidu 立即返回 server_id

    // ③ 处理结果
    if res.State == entity.TaskStateSuccess {
        task.State = entity.TaskStateSuccess
        task.ProviderTaskID = res.TaskID  // server_id
        task.CreationsJSON = marshal([]CreationItem{{ID: res.TaskID}})
    }

    // ④ 保存任务
    uc.repo.Save(ctx, task)

    // ⑤ 终态钩子
    uc.notifyTerminal(ctx, task)      // 站内通知
    uc.maybeMaterializeAsset(ctx, task) // 物化到 subject_assets
    uc.maybeChainAvatarVideo(ctx, task) // 链式形象视频
}
```

**数据库操作**：
- 写入 `generation_tasks` 表
- 成功后物化到 `subject_assets` 表

- `internal/usecase/generation/generation.go:997` - submitSubject

### 4.2 链式形象视频（avatar_chain）

```go
// avatar_chain.go - maybeChainAvatarVideo()
func (uc *GenerationUseCase) maybeChainAvatarVideo(ctx context.Context, subject entity.GenerationTask) {
    // ① 检查是否环境主体（环境主体不需要形象视频）
    if kind == "scene" { return }

    // ② 检查运营开关（gen_chain_avatar_video，默认开）
    if !uc.generationBoolDefault(ctx, "gen_chain_avatar_video", true) { return }

    // ③ 创建 reference2video 任务
    chain, err := uc.Submit(ctx, SubmitInput{
        SubType: "reference2video",
        Params: GenerationParams{
            "prompt":       "形象展示：正面特写，微笑看向镜头",
            "duration":     10,
            "aspect_ratio": "9:16",
            "subjects":     []SubjectRef{{Name: name, ServerID: serverID}},
            "avatar_video": true,  // 标记为链式形象视频
        },
    })

    // ④ 写回 avatar_task_id
    params["avatar_task_id"] = chain.ID
    uc.repo.Save(ctx, subject)
}
```

### 4.6 B-Roll 合成（compose）

**入口**：`POST /api/v1/generation/submit` (sub_type=compose)

**前置条件**：源成片必须已定位时间轴

**处理流程**：

```go
// videocompose/compose.go - SubmitCompose()
func (uc *UseCase) SubmitCompose(ctx context.Context, in port.ComposeInput) (port.ComposeResult, error) {
    // ① 校验：句号有效 + 窗口互不重叠
    for _, s := range in.Segments {
        if s.SentenceIndex < 0 || s.SentenceIndex >= len(meta.Lines) {
            return error("句号越界")
        }
    }

    // ② 创建 compose 任务
    task := entity.GenerationTask{
        SubType:  "compose",
        Model:    "local-ffmpeg",
        Provider: "local",
        State:    entity.TaskStateQueueing,
    }

    // ③ 后台执行
    go uc.execute(task.ID, tenantID, mainURL, resolvedSegs)

    return port.ComposeResult{TaskID: task.ID}, nil
}
```

**后台执行流程**：

```go
// videocompose/compose.go - execute()
func (uc *UseCase) execute(taskID, tenantID, mainURL string, segs []resolvedSeg) {
    // ① 并发闸门（2并发）
    composeSem <- struct{}{}

    // ② 安全下载全部媒体（SSRF校验）
    mainPath, cleanup, _ := safeDownloadMedia(ctx, mainURL)

    // ③ 片段预检（视频流校验+图片预转视频）
    for i, seg := range segs {
        hasVideo, _ := uc.av.ProbeHasVideoStream(ctx, segPath)
        if isImagePath(segPath) {
            uc.av.LoopImageToVideo(ctx, segPath, dur, loopPath)
        }
    }

    // ④ ffmpeg 合成
    uc.av.ComposeInsertSegments(ctx, mainPath, specs, outPath)

    // ⑤ 产物上传到存储
    outURL, _ := uc.uploadCreation(ctx, tenantID, outPath)

    // ⑥ 更新任务状态
    task.State = entity.TaskStateSuccess
    task.CreationsJSON = marshal([]map[string]any{{"url": outURL}})
    uc.tasks.Save(ctx, task)
}
```

### 4.7 台词时间轴定位（timeline）

**入口**：`POST /api/v1/generation/tasks/:id/timeline`

**处理流程**：

```go
// videocompose/timeline.go - LocateTimeline()
func (uc *UseCase) LocateTimeline(ctx context.Context, tenantID, taskID string, force bool, linesOverride []TimelineLineOverride) ([]TimelineLine, string, error) {
    // ① 文字修正模式（只改各行text，时间窗不动）
    if len(linesOverride) > 0 {
        meta.Lines[o.Index].Text = o.Text
        return meta.Lines, meta.ScriptSource, nil
    }

    // ② 缓存命中（非force）
    if meta, ok := parseTimeline(task.TimelineJSON); ok && !force {
        return meta.Lines, meta.ScriptSource, nil
    }

    // ③ 下载成片
    mediaPath, cleanup, _ := uc.safeDownloadTaskMedia(ctx, task)

    // ④ 静音检测
    segs, _ := uc.av.DetectSpeechSegments(ctx, mediaPath)

    // ⑤ 台词配对
    script := taskScript(task)
    if script != "" {
        // A/B路径：台词行与语音段配对
        lines := splitLines(script)
        meta = alignSegments(segs, lines)
    } else {
        // C路径：ASR全文→按段时长比例切行
        audioPath, _ := uc.av.ExtractAudio(ctx, mediaPath)
        text, _ := uc.transcriber.Transcribe(ctx, audioPath, "audio/mpeg", 0)
        meta = splitBySegments(segs, text)
    }

    // ⑥ 保存时间轴
    uc.saveTimeline(ctx, task, meta)
    return meta.Lines, meta.ScriptSource, nil
}
```

**三种配对模式**：
- **M==N**：语音段数=台词行数，直接配对（direct）
- **M>N**：语音段多于台词行，按字符比例合并相邻段（estimated）
- **M<N**：语音段少于台词行，按字符比例拆分段（estimated）

**关键代码位置**：
- `internal/usecase/videocompose/timeline.go:79` - LocateTimeline
- `internal/usecase/videocompose/timeline.go:201` - alignSegments

```sql
CREATE TABLE generation_tasks (
    id VARCHAR(64) PRIMARY KEY,
```
