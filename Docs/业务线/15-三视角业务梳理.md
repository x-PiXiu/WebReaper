# 三视角业务梳理（用户端 × 管理端）

> 最后更新：2026-09-01（第二次修订：对齐 31 号音色物化架构落地 + 前端发布预填闭环/作品库改版合并）
> 定位：跨业务线的横向梳理——每条业务按固定三视角展开：**① 业务做什么 ② 用户视角（获得什么、如何获取）③ 管理员视角（管什么内容、能提供什么便捷）**。
> 依据：01-05 号业务文档（已逐项核对代码）+ 06-14 号业务（尚未编写单独文档，本文基于路由与代码盘点梳理）+ 管理端 9 复合页能力清单 + 31 号设计实施后代码实态。

## 〇、方法说明（如何持续维护这套梳理）

每条业务用同一个模板回答四个问题，新业务上线或现有业务改动时按此补充：

```
【业务定位】一句话：这是什么能力，解决什么问题
【用户视角】
  - 获得什么：用户拿到手的产物/价值
  - 如何获取：入口页面 → 操作路径 → 关键端点 → 产物去向（异步等待方式）
【管理员视角】
  - 管什么：可增删改查/审核/配置的业务内容 + 所在管理页面
  - 给用户什么便捷：预置资产、代客操作、默认值兜底等机制
【缺口】管理员侧缺失的能力（用户受影响点）
```

## 一、内容创作域

### ① 口播业务（数字人+对口型，核心王牌）

**做什么**：数字分身对着镜头讲话的营销视频批量生产。核心价值是跨视频人物一致性（同一分身系列视频形象统一）+ 傻瓜式向导 + B-Roll 单阶段一次出片。目标态架构（31 号定案）：**画面=分身资产（阶段0 一次性预生成 10s 不说话形象视频），口播=对口型复用画面**——A 文本+音色两段 / B 文本直生单段 / C 上传音频单段。

**用户视角**：
- **获得什么**：一条"自己的数字分身讲完这篇文案"的口播成片（可带插入画面），进作品库可直接发布。
- **如何获取**：入口 `/m/compose/lipsync` 向导——
  1. 文案三选一：粘贴爆款链接提取 / 上传参考音视频 ASR 提取 / 手写粘贴；
  2. 出镜与配音：选分身（自己的或官方的）+ 音色（默认已选好，无需操作）；
  3. B-Roll（可选）：逐句挂图片/视频片段；
  4. 提交 `POST /generation/submit`（文本驱动 `lip_sync`/`reference2video`，Vidu 端内合成语音，**无需单独 TTS**；分身+上传音频走两步链）；
  5. 双通道异步等待（回调秒级 + 轮询 20s 兜底）→ 成片自动 B-Roll 合成 → 作品库 → **成片后一键跳发布（预填素材，前端已上线）**。
- 分身准备（一次性）：`/m/compose/avatar` 上传形象照 → 主体注册成功后自动链式生成 10s **不说话**形象视频（已显式静默 `audio=false`）。
- **可靠性（31 号落地后）**：向导里选**任何**音色（平台音色/默认音色/自己的克隆）文本驱动口播都能出片——服务端提交前自动完成 Vidu 注册/续期保障（6 天窗口内零开销，过期幂等重建）；音色 7 天过期对用户全程无感。`gen_lipsync_auto_chain` 开关（默认关）开启后升级为画面复用单段路径：分身形象视频直接作为对口型输入、B 路径默认用分身绑定音色，形象视频未就绪时显式提示回分身管理等待/重建。
- ⚠️ 已知约束：形象视频固定 10s → B/C 路径口播语音量约 ≤40-50 字；长文案方案待 Vidu 超长文本行为实测（31 号 §4.3）。

**管理员视角**：
- **管什么**：
  - 官方分身（平台资产页 Subjects Tab）：上传形象照→Vidu 注册→自动形象视频→上架后用户向导里"官方分身"即选即用（白牌，不暴露 Vidu）；
  - 生成默认参数（系统设置 Settings Tab）：`gen_default_resolution/aspect_ratio/watermark`、`gen_chain_avatar_video` 开关、`gen_default_avatar_prompt`；**口播新开关族**：`gen_lipsync_auto_chain`（画面复用路径，前端适配后开）、`gen_lipsync_two_step`（备胎道：注册失败自动降级 A 路径）、`gen_voice_materializer_enabled`（音色物化总开关，灰度用）；
  - 生成模板（引擎配置 Templates Tab）：口播默认参数模板 CRUD；
  - 生成规格/模式（系统集成页）：每个 sub_type 用哪个模型、商户端可见模式档位（default/advanced/closed）、一键收敛推荐档；
  - 任务监控（系统设置 Monitor Tab）：跨租户任务按状态筛选、取消卡住任务。
- **便捷供给**：官方分身 + 平台默认音色 = 新用户零资产冷启动即可出片；模式开关收敛让傻瓜用户只见到五端点主路径；音色注册自动保障（含创建后异步预热）让用户对厂商生命周期规则零感知。
- **缺口**：用户"作品"无 admin 管理端点（不能查看/删除/重发布）；`generation_specs.cost_credits` 全 0 待配置；前端向导未适配画面复用路径（适配后开 `gen_lipsync_auto_chain` 淘汰旧单步）。

### ② 图文业务（GEO 优化内容）

**做什么**：AI 生成面向 AI 搜索引擎优化的图文内容（小红书笔记/知乎文章等），带五维规则评分（权威性/专业性/结构/唯一性/时效性）。核心是 GEO 内容优化（`geo_optimized_contents`），文生图/文生视频是配图辅助。

**用户视角**：
- **获得什么**：高评分优化内容草稿 → 编辑定稿 → 发布 → 收录状态追踪，最终获得 AI 搜索里的品牌曝光。
- **如何获取**：入口 `/m/content` 或 `/m/brands`——选品牌人设 + 关键词 + 内容类型 → `POST /geo/content/generate`（LLM 初稿 + RAG 知识库素材注入 + 规则评分）→ 编辑/重新评分（`/:id/score`）→ `/:id/publish` 发布 → 收录通知。配图走 `text2image`（参考图+文本）。

**管理员视角**：
- **管什么**：
  - 系统提示词热更新（引擎配置 Prompts Tab）——直接决定所有用户的内容生成质量与风格；
  - LLM 配置 CRUD + 设默认模型（含 api_key）；生成模板；
  - 知识库采集配置（引擎配置 Knowledge Tab）：RAG 素材是内容质量的供给端；
  - 全平台内容一览（商户与品牌页 Contents Tab）：跨租户查看、发布/下架（状态切换）、删除；
  - 收录渠道与补提交（引擎配置 Indexing Tab）。
- **便捷供给**：知识库自动采集行业素材 → 用户生成时自动 RAG 增强（用户无感知拿到更专业的内容）；收录代运维。
- **缺口**：A/B 测试框架未接入内容生成（P2）；发布后自动收录通知待实现。

### ③ 混剪业务（B-Roll 画面插入）

**做什么**：在口播成片的指定句子处插入画面片段（产品图/场景视频），本地 ffmpeg 合成，不依赖外部 API。时间窗是"起始标记"：片段从该句开始自然播放，播完透出原片，不定格不截断。

**用户视角**：
- **获得什么**：视觉更丰富的成片（纯口播 → 口播+画面）。
- **如何获取**：两种模式——
  - **单阶段（推荐）**：口播向导第③步（step=broll）生成前逐句挂片段，提交时带 `broll_segments`，服务端成片后自动定位时间轴并链式合成，一次等待拿最终片；
  - **两阶段（后期调整）**：作品库 `BrollDrawer`——`POST /generation/tasks/:id/timeline` 看每句起止时间 → 选句挂片段 → `sub_type=compose` 提交。
- 时间轴三来源：手写文案/链接提取文案（配对），上传音频（ASR 全文按段切分）。

**管理员视角**：
- **管什么**：无专门管理页。compose 任务在任务监控里可见可取消；合成并发闸门（2 进程）为代码级控制。
- **缺口**：无混剪素材库管理（用户片段全靠自传）；合成进度无实时反馈（P3）；时间轴手动编辑 UI 缺失（P2）。

### ④ 音频业务（TTS + 声音克隆）

**做什么**：文本转语音与音色克隆，是口播/图文/工具台的配音底层。双厂商：Vidu（同步即终态）+ 小米 MiMo（同步返回，免费额度），CapabilityResolver 按能力路由。白牌化：上游 302 条 Vidu 音色仅管理端可见。核心架构（31 号定案）：**样本为源、注册为缓存**——音色的唯一事实源是平台库的永久样本 URL，厂商 voice_id 只是可随时重建的加速缓存。

**用户视角**：
- **获得什么**：配音音频（自动转存素材库，24h URL → 永久 stored_url）+ 专属克隆音色（音色库"我的"Tab 常驻，后续生成可复用）。
- **如何获取**：
  - TTS：任一配音入口（生成弹窗/合成轨道/工具台）→ VoicePicker 选音色（分组：★精选 > 🎤平台音色 > 我的克隆）→ 调 speed/volume/pitch/emotion → 提交 `type='audio'` 同步即得；
  - 克隆：上传 10s-5min 人声（≤20MB）→ 填音色 ID（可留空自动）+ 试听文案 → `type='voice'` 同步即终态 → 自动物化进音色库（走 Vidu 时创建即注册；走 MiMo 时后台异步补注册，几秒就绪）；
  - **删除克隆**：音色库批量删除现在**真删**（任务行+音色行联动清理，不再残留列表）；
  - 可靠性（用户无感知）：① 转存三通道兜底（即时转存 / data:URI 解码 / 每小时定时补偿）；② 样本合成厂商隔离——TTS 命中克隆/平台音色自动改走"带样本"请求，**MiMo 通道一律 voiceclone 样本化且无字数限制**（实测 2049 字 OK）、Vidu ≤1000 字样本化（顺带续期注册）、>1000 字走 tts+ID（注册前置保障）；③ **宁失败不变声**——音色在当前通道不可用时显式报错（如"样本转存未完成，请稍后重试"），绝不静默换成别的声音；④ 备胎道开关（`gen_lipsync_two_step`，默认关）开启后，口播注册类失败自动降级为"tts 样本合成→音频驱动对口型"，零厂商 ID 依赖。
- 口播主路径已不经独立 TTS（lip_sync 文本驱动端内合成），独立 TTS 存于配音场景。

**管理员视角**：
- **管什么**（平台资产页 Voices Tab + 系统设置）：
  - 平台音色 CRUD：上传样本/URL 克隆创建（MiMo 合成试听）、改名/语言/上下架、软删；
  - **从 Vidu 克隆**（白牌化主路径）：浏览上游 302 条参考源 → 一键克隆为平台音色；
  - **设平台默认音色**：三级默认解析最高级（平台 is_default > settings > mimo_default）——用户不选音色时全局兜底；
  - 精选标记（recommend）控制 VoicePicker"★精选"分组排序；
  - 模式开关：`text2audio/sound_effect` 等默认关闭（傻瓜式收敛），需要时管理端开；
  - 注册缓存参数：`gen_vidu_voice_window`（默认 144h）与 `gen_voice_audition_text`（注册试听文案）。
- **便捷供给**：平台音色库 + 默认音色 = 用户零配置可用；克隆音色自动物化 + 异步预热免手动登记；注册缓存自动续期让用户对 Vidu 7 天规则零感知。
- **缺口**：声音滥用审核缺失（克隆他人声音无授权声明/审计，P1 合规项）；admin 平台音色创建的异步预热接线待补（3 行改动）；窗口失效错误码为子串匹配待真实错误码校准。

## 二、分发获客域

### ⑤ 多平台发布

**做什么**：把口播/图文/文章作品一键分发到 7 平台（知乎/小红书/抖音/快手/B站/视频号/YouTube）。两种模式：半自动（生成预填链接，用户手动发）与全自动（RPA 浏览器代发）。配账号池、健康巡检、配额限流、定时发布、互动数据回读。

**用户视角**：
- **获得什么**：一次提交多平台分发 + 发布后互动数据（播放/点赞/评论/分享时间序列）+ GEO 提及率前后对比。
- **如何获取**：入口 `/m/distribution` 三 Tab——
  1. 账号池：扫码绑定（QRLogin）/抖音 OAuth，10min 健康巡检，OAuth 双时钟自动续期；
  2. 发布向导五步：平台与形态（多选）→ 标题正文（各平台截断/清洗预览）→ 素材 → 平台参数（B站分区/全自动/定时）→ 预览确认（配额拦截+完备性检查）；**作品库/作品详情/口播完成页可一键跳入发布向导并自动预填成片素材与标题**（发布预填闭环，前端已上线）——从成片到发布不需要重新选素材；
  3. 执行：全自动 RPA 代发（账号池最久未用优先取号）；半自动打开预填链接手动发后"标记已发布"（此刻才记配额，**半自动结果已支持发布中心内联确认**）；定时 5min 扫描到期执行；
  4. 发布记录：进度面板 + 数据回读（24h 批量+手动刷新）+ re-monitor 复测。
- 音频内容以"音画合一 mp4"按 video 形态发布（音频直发仅小红书声明，UI 不可达）。

**管理员视角**：
- **管什么**（系统设置 Settings Tab）：
  - 发布通道矩阵：查看各平台通道（官方 API 通道已删，仅 rpa/link），平台级 override 强制走指定通道或恢复自动降级；
  - `browser-headed` 开关：RPA 发布/扫码是否显示浏览器窗口（真机校准/排查用）；
  - 定时/自动闭环任务的全局开关。
- **缺口**：无发布账号池管理（账号由商户自绑）；无发布计划干预端点；🔴 P1：小红书全自动 video 通过门禁但执行层"暂未实现"必失败（§8.2 of 05 号）；半自动无作品链接无法回读数据。

### ⑥ GEO 优化（AI 搜索获客）

**做什么**：让本地生活商户的品牌在 AI 搜索引擎（豆包/元宝/Kimi 等）的回答中被推荐。链路：品牌建档 → 关键词监测 → 诊断 → 优化内容生产（见②）→ 发布（见⑤）→ 复测闭环。数据量最大的业务域（1690 条监测）。

**用户视角**：
- **获得什么**：品牌在 AI 搜索中的能见度/美誉度量化报告 + 一条"监测→优化→发布→复测"的自动闭环。
- **如何获取**：入口 `/m/brands`（品牌/关键词/监测/内容四 Tab）+ `/m/monitor`——
  1. 建品牌（人设/卖点/门店定位，`store-locations` 支持地理编码）；AI 辅助：`competitor-suggestions` 竞品建议、`nearby-competitors` 附近竞品、`diagnose` 诊断、`advice` 建议；
  2. 关键词管理（`keywords/distill` AI 蒸馏拓展）；
  3. 监测：`monitor-results` 多引擎提及/排名/引用（`ai-rank`/`citations`），自动监测任务周期跑；
  4. 优化内容生成与发布后 `re-monitor` 复测效果。

**管理员视角**：
- **管什么**：全平台品牌一览/删除（商户与品牌页）；全平台内容审核（发布/下架/删除）；行业全景看板（行业能见度/品牌美誉度/信源域名榜）；`auto-monitor` 自动监测总开关；诊断/建议/蒸馏所用 LLM 配置与提示词。
- **便捷供给**：行业级洞察（跨商户聚合）帮商户理解自己在行业中的位置；自动监测免手动盯梢。
- **缺口**：GEO 域无代客运营端点（不能替某商户跑监测/生成）。

### ⑦ 收录优化

**做什么**：让发布内容尽快被搜索引擎/AI 收录——IndexNow 与百度提交渠道，收录状态回写内容表（`index_status`/`indexed_at`）。

**用户视角**：
- **获得什么**：每篇发布内容的收录状态可见，未收录可手动重提交（`resubmit-index`）。
- **如何获取**：品牌内容列表自动显示收录状态；发布后自动提交；失败/未收录手动触发重提交。

**管理员视角**：
- **管什么**（引擎配置 Indexing Tab）：渠道配置（IndexNow/百度）、IndexNow key 自动生成+托管+可达性验证、提交日志审计、手动补提交。
- **便捷供给**：平台代生成并托管 key 文件（`/public/indexnow-key.txt`），用户零配置享有收录加速。

## 三、资源管理域

### ⑧ 分身管理（数字分身资产）

**做什么**：数字分身资产库（`subject_assets`，scope=personal/official，kind=person/scene）。分身是口播业务的"演员"，环境主体（scene）可与分身组合出镜。

**用户视角**：
- **获得什么**：形象跨视频一致的"我的分身"列表（含形象视频预览），向导中直接选用；环境主体可与分身乘法组合出镜。
- **如何获取**：`/m/compose/avatar` 上传形象照 → `subject` 注册（同步返回 server_id）→ 自动物化 + 自动链式 10s **不说话**形象视频（prompt 可自定义，@name 引用，已显式静默）→ `/api/v1/subjects/mine` 查看。数字资产页"我的分身"Tab 管理。**分身资产 = 画面 + 绑定音色**（31 号定案：口播复用路径开启后，形象视频直接作为对口型输入、绑定音色为 B 路径默认——用户选分身即同时选定画面与默认声音）。
- 删除分身：任务删除即本地移除（Vidu 侧无注销 API，7 天自然过期）。

**管理员视角**：
- **管什么**：官方主体（scope=official）与用户分身同链路创建；上下架控制用户端可见性（复用路径提交时校验，下架分身显式报错）；`gen_chain_avatar_video`/`gen_default_avatar_prompt` 全局配置；分身删除（连带 Vidu 侧资源）。
- **便捷供给**：官方分身让新用户跳过"上传自己照片"这一步直接出片。
- **缺口**：无法查看/管理具体某个用户的分身资产（跨租户资产视图缺）；环境主体组合出镜调用点的 audio=false 静默审计待补。

### ⑨ 音色管理（音色资产）

并入 **④ 音频业务**（同一资产表 `generation_voices`，scope=vidu/platform/clone 三类）。用户侧=音色库+VoicePicker；管理侧=平台音色 CRUD+from-vidu 克隆+设默认。

### ⑩ 素材管理

**做什么**：图片/视频/音频素材库（`media_assets`），是生成输入（参考图/B-Roll 片段/克隆样本/上传音频）与发布素材的统一池。

**用户视角**：
- **获得什么**：统一素材库，上传一次处处可用（向导引用、B-Roll、发布、克隆）。
- **如何获取**：`/m/assets` 上传（`POST /media/assets`，图/视频/音频 ≤20MB 白名单校验）；生成产物（TTS 音频/文生图等）自动入库；素材在各入口 AssetPicker 复用。

**管理员视角**：
- **管什么**：无专门管理页（素材属租户私有）。间接管控：上传大小/扩展名白名单为代码级配置。
- **缺口**：无全局素材审计（违规内容排查需查库）；配额/存储用量无管理视图。

### ⑪ 灵感采集（灵感广场）

**做什么**：爬虫采集各平台热门视频入灵感广场，供商户参考爆款/做同款（"看别人怎么火"）。

**用户视角**：
- **获得什么**：按平台/品牌分类的热门视频流，可做同款（跳转创作）。
- **如何获取**：`/inspirations` 浏览（platforms/brands 维度），管理端置顶/推荐的优质内容优先曝光。

**管理员视角**：
- **管什么**（爬虫管理页 4 Tab）：平台爬虫账号 CRUD（cookie 加密托管、脱敏展示、按账号健康检查）；爬虫配置（平台/关键词/频率）+ 测试连接 + 手动触发 + 代刷视频指标；采集任务监控；灵感运营（置顶/推荐/备注/批量删除——直接控制商户端曝光）。
- **便捷供给**：平台代持爬虫账号（商户零成本获得行业爆款流）。

## 四、智能服务域

### ⑫ 智能体对话（获客管家）

**做什么**：品牌上下文注入的 AI 获客管家，商户用自然语言完成咨询与部分操作（含发布计划两步确认 `publish-plans/:planID/confirm|cancel`）。

**用户视角**：
- **获得什么**：懂自己品牌情况的 AI 顾问（品牌/监测/知识库上下文注入），可对话式驱动业务（如让 AI 排发布计划）。
- **如何获取**：`/chat` 提问（`POST /chat`），会话与消息历史（`/conversations`）保存。

**管理员视角**：
- **管什么**：获客智能体参数（引擎配置 Agents Tab CRUD）；对话系统提示词热更新；Admin Chat（`/admin/chat`）同一端点按角色分流，admin 会话实时注入系统健康摘要。
- **缺口**：`admin_tools.go` 定义了 7 个 admin 专属 LLM 工具（健康查询/失败任务/取消任务/音色主体列表/积分/租户用量）但**未注册接线**，属 dead code——接线后管理员可自然语言运维。

### ⑬ 知识库（RAG 增强）

**做什么**：品牌级行业知识库，为图文生成（②）与智能体对话（⑫）提供 RAG 检索增强；自动采集 + 手动补充。

**用户视角**：
- **获得什么**：更专业、有行业依据的生成内容（用户无感知，检索自动注入 prompt）。
- **如何获取**：基本零操作——知识库按品牌自动采集（默认 360min 周期）；`brands/:id/knowledge/materials` 可手动补充/删除自己的素材。

**管理员视角**：
- **管什么**（引擎配置 Knowledge Tab）：向量嵌入模型/向量库配置；采集配置与间隔（30-1440min）；素材统计/管理；重建存量向量索引；手动触发采集；检索调试（带来源验证召回质量）。
- **便捷供给**：平台统一调优 embedding 与采集策略，各商户共享行业知识红利。

### ⑭ 数据分析（效果追踪）

**做什么**：发布互动数据 + GEO 监测数据 + 平台经营数据的汇总看板。

**用户视角**：
- **获得什么**：作品互动趋势（14 天）、GEO 提及率变化、品牌健康报告、平台配额用量的一站式视图。
- **如何获取**：`/m/analytics`（互动趋势/作品列表）；`/m/monitor`（GEO 数据）；`merchant/health-report`（健康报告）；`brands/:id/publish-stats`（配额）。数据源：发布后自动回读（24h 批量）+ 手动刷新。作品库已改版（卡片+详情抽屉），作品详情可直接跳发布预填。

**管理员视角**：
- **管什么**：Admin Dashboard——SaaS 核心指标（MRR/活跃商户/有效订阅）、系统健康卡、GEO 健康看板（行业分布/内容状态/沉睡商户/草稿积压告警）、行业全景榜；计费页收入概览/成本分析（收入 vs 厂商成本双报表）；R3 运营指标（LLM 成功率/缓存命中率/配额拒绝/锁竞争，`/admin/debug/metrics`）。
- **便捷供给**：沉睡商户/草稿积压告警是主动触达商户的运营线索。
