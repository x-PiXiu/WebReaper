# 适配器层（Adapter Layer）分析

> 整洁架构的外层：实现 Port 接口，连接外部世界

## 1. 适配器层概述

适配器层是**系统与外部世界的桥梁**，负责：
- 实现 Domain 层定义的 Port 接口
- 连接外部系统（数据库、第三方 API、消息队列等）
- 处理技术细节（HTTP 请求、数据库查询、文件 I/O）

**设计原则**：
- 依赖 Domain 层的 Port 接口
- 实现具体的技术细节
- 可替换（换数据库/第三方服务 = 换适配器）

## 2. 适配器分类

### 2.1 Repository 适配器（数据持久化）

**位置**：`internal/adapter/repository/`

**职责**：实现 Domain 层的 Repository 接口，负责数据持久化

#### 2.1.1 GORM 实现示例

**BrandRepository 实现**：
```go
type GormBrandRepository struct {
    db *gorm.DB
}

var _ port.BrandRepository = (*GormBrandRepository)(nil)

func NewGormBrandRepository(db *gorm.DB) *GormBrandRepository {
    return &GormBrandRepository{db: db}
}

func (r *GormBrandRepository) Save(ctx context.Context, b entity.Brand) error {
    po := brandToPO(b)  // 领域实体 → 持久化对象
    return r.db.WithContext(ctx).Save(&po).Error
}

func (r *GormBrandRepository) FindByID(ctx context.Context, tenantID, id string) (entity.Brand, error) {
    var po BrandPO
    q := applyTenantScope(r.db.WithContext(ctx), tenantID)  // 多租户隔离
    err := q.Where("id = ?", id).First(&po).Error
    if errors.Is(err, gorm.ErrRecordNotFound) {
        return entity.Brand{}, pkg.ErrNotFound
    }
    if err != nil {
        return entity.Brand{}, err
    }
    return brandFromPO(po), nil  // 持久化对象 → 领域实体
}
```

**关键设计**：
- **多租户隔离**：`applyTenantScope` 强制带 tenant_id 过滤
- **实体映射**：`brandToPO` / `brandFromPO` 转换领域实体和持久化对象
- **错误处理**：GORM 错误转换为领域错误（`pkg.ErrNotFound`）

```go
func NewViduProvider(apiKey string) *ViduProvider {
```

**核心方法**：

```go
// Submit 提交生成任务
func (p *ViduProvider) Submit(ctx context.Context, endpoint string, body map[string]any) (port.SubmitResult, error) {
    // 1. 序列化请求体
    payload, _ := json.Marshal(body)
    
    // 2. 构建 HTTP 请求
    req, err := http.NewRequestWithContext(ctx, http.MethodPost, baseURL+endpoint, bytes.NewReader(payload))
    if err != nil {
        return port.SubmitResult{}, err
    }
    req.Header.Set("Content-Type", "application/json")
    req.Header.Set("Authorization", "Token "+p.apiKeyNow())
    
    // 3. 发送请求
    resp, err := p.client.Do(req)
    if err != nil {
        return port.SubmitResult{}, fmt.Errorf("Vidu 创建任务请求失败: %w", err)
    }
    defer resp.Body.Close()
    
    // 4. 解析响应
    raw, _ := io.ReadAll(io.LimitReader(resp.Body, 8192))
    if resp.StatusCode != http.StatusOK {
        // 错误处理：错误码翻译
        var eb struct {
            Reason  string `json:"reason"`
            Message string `json:"message"`
        }
        _ = json.Unmarshal(raw, &eb)
        return port.SubmitResult{}, fmt.Errorf("Vidu 创建任务失败: %s", p.TranslateError(eb.Reason))
    }
    
    // 5. 返回结果
    var parsed struct {
        TaskID  string `json:"task_id"`
        State   string `json:"state"`
        Credits int    `json:"credits"`
    }
    if err := json.Unmarshal(raw, &parsed); err != nil {
        return port.SubmitResult{}, err
    }
    
    return port.SubmitResult{
        TaskID:  parsed.TaskID,
        State:   parsed.State,
        Credits: parsed.Credits,
    }, nil
}
```

**Key 热更新机制**：

```go
// apiKeyNow 并发安全的 Key 读取
func (p *ViduProvider) apiKeyNow() string {
    // 快路径：keySource 存在且缓存未过期
    if p.keySource != nil && time.Since(p.keyCacheAt) < p.keyCacheTTL {
        p.mu.RLock()
        k := p.keyCache
        p.mu.RUnlock()
        if k != "" {
            return k
        }
    }
    
    // 慢路径：走 keySource 从 DB 读
    if p.keySource != nil {
        k, err := p.keySource(context.Background())
        if err == nil && k != "" {
            p.mu.Lock()
            p.keyCache = k
            p.keyCacheAt = time.Now()
            p.mu.Unlock()
            return k
        }
    }
    
    return p.apiKey
}

// UpdateAPIKey 运行时更新 API Key（同实例即时生效）
func (p *ViduProvider) UpdateAPIKey(key string) {
    p.mu.Lock()
    defer p.mu.Unlock()
    p.apiKey = key
    p.keyCache = key
    p.keyCacheAt = time.Now()
}
```

**RateLimitCrawler（限流装饰器）**：
```go
type RateLimitCrawler struct {
    inner  port.CrawlerTool
    policy CrawlPolicy
    lastRequest time.Time
    mu     sync.Mutex
}

func NewRateLimitCrawler(inner port.CrawlerTool, policy CrawlPolicy) *RateLimitCrawler {
    return &RateLimitCrawler{
        inner:  inner,
        policy: policy,
    }
}

func (c *RateLimitCrawler) Name() string {
    return c.inner.Name()
}

func (c *RateLimitCrawler) Crawl(ctx context.Context, url string) (CrawlResult, error) {
    // 限流逻辑
    c.mu.Lock()
    elapsed := time.Since(c.lastRequest)
    if elapsed < time.Duration(c.policy.RequestIntervalMs)*time.Millisecond {
        time.Sleep(time.Duration(c.policy.RequestIntervalMs)*time.Millisecond - elapsed)
    }
    c.lastRequest = time.Now()
    c.mu.Unlock()
    
    // 调用被装饰的爬虫
    return c.inner.Crawl(ctx, url)
}
```

```go
type LocalMediaStore struct {

}

func NewLocalMediaStore(baseDir, publicBaseURL string) (*LocalMediaStore, error) {
    if err := os.MkdirAll(baseDir, 0755); err != nil {
        return nil, err
    }
    return &LocalMediaStore{
        baseDir:       baseDir,
        publicBaseURL: publicBaseURL,
    }, nil
}

func (s *LocalMediaStore) Store(ctx context.Context, tenantID, brandID, ownerType string, data []byte, mime string) (string, error) {
    // 1. 生成文件路径
    filename := fmt.Sprintf("%s/%s/%s/%s%s", tenantID, brandID, ownerType, generateID(), extFromMime(mime))
    filePath := filepath.Join(s.baseDir, filename)
    
    // 2. 写入文件
    if err := os.MkdirAll(filepath.Dir(filePath), 0755); err != nil {
        return "", err
    }
    if err := os.WriteFile(filePath, data, 0644); err != nil {
        return "", err
    }
    
    // 3. 返回公开 URL
    return s.publicBaseURL + "/media/" + filename, nil
}
```

```go
    return &RedisCache{client: client}

func (c *RedisCache) Get(ctx context.Context, key string) (string, error) {
    val, err := c.client.Get(ctx, key).Result()
    if err == redis.Nil {
        return "", nil  // 缓存未命中
    }
    if err != nil {
        return "", err
    }

    return val, nil
}

    return c.client.Set(ctx, key, value, ttl).Err()
}

    return c.client.Del(ctx, keys...).Err()
}
```

## 5. 适配器层与用例层的边界

### 5.1 适配器层职责

- 实现 Port 接口
- 处理技术细节（HTTP/DB/文件 I/O）
- 错误转换（技术错误 → 领域错误）
- 数据转换（持久化对象 ↔ 领域实体）

### 5.2 用例层职责

- 编排业务流程
- 调用 Port 接口
- 不关心技术实现细节

## 6. 总结

适配器层的设计体现了整洁架构的核心思想：

1. **依赖倒置**：实现 Domain 层定义的 Port 接口
2. **技术隔离**：技术细节集中在适配器层，用例层不关心
3. **可替换性**：换数据库/第三方服务 = 换适配器
4. **可测试性**：通过 Mock Port 接口，适配器层可以独立测试
5. **错误转换**：技术错误转换为领域错误，保持领域层纯净
