## 🏗️ 架构概览

### 整洁架构四层结构

```
┌─────────────────────────────────────────────────────────────┐
│                    外部世界（HTTP/DB/LLM/第三方API）           │
├─────────────────────────────────────────────────────────────┤
│                      Adapter 层（适配器层）                    │
│  ┌─────────────┐ ┌─────────────┐ ┌─────────────┐            │
│  │   Handler    │ │ Repository  │ │   Provider   │           │
│  │  (HTTP API)  │ │  (数据库)   │ │  (Vidu/LLM)  │           │
│  └─────────────┘ └─────────────┘ └─────────────┘            │
├─────────────────────────────────────────────────────────────┤
│                      Usecase 层（用例层）                     │
│  ┌─────────────┐ ┌─────────────┐ ┌─────────────┐            │
│  │  Generation  │ │     GEO     │ │   Account    │           │
│  │  (内容生成)   │ │ (本地生活)   │ │  (账号发布)   │           │
│  └─────────────┘ └─────────────┘ └─────────────┘            │
├─────────────────────────────────────────────────────────────┤
│                      Domain 层（领域层）                      │
│  ┌─────────────────────────────────────────────────────┐    │
│  │  Entity（实体）  +  ValueObject（值对象）  +  Port（接口）  │
│  └─────────────────────────────────────────────────────┘    │
├─────────────────────────────────────────────────────────────┤
│                      Config 层（配置层）                      │
│  ┌─────────────────────────────────────────────────────┐    │
│  │              环境变量 + 运行时配置                      │    │
│  └─────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────┘
```

### 核心业务模块

| 模块 | 业务目标 | 核心实体 |
|------|----------|----------|
| **GEO** | 帮助商户在 AI 搜索引擎中被提及和引用 | Brand、Keyword、MonitoringResult |
| **内容生成** | 统一任务协议支持多种媒体类型生成 | GenerationTask、ModelCapability |
| **发布系统** | 支持内容一键发布到多个平台 | Account、PublishJob |
| **经济系统** | SaaS 级的套餐/订阅/计费管理 | Plan、Subscription、Order |

## 🔧 技术栈

### 后端
- **语言**：Go 1.21+
- **Web 框架**：Gin
- **ORM**：GORM
- **数据库**：MySQL 8.0
- **缓存**：Redis 7.0

### 前端
- **框架**：React 18 + TypeScript
- **UI 库**：Ant Design
- **状态管理**：React Query

### AI/LLM
- **LLM 服务商**：OpenAI / 豆包 / Kimi / 小米 MiMo
- **向量嵌入**：OpenAI Embedding / 本地模型

### 第三方服务
- **视频生成**：Vidu API
- **地图服务**：高德地图 API
- **支付网关**：ZPay
