# 面试题生成

> 优先级：🔴 P0 | 阶段：0（已完成）| 模式：策略 + Prompt 工程隔离

## 一、需求来源

> "根据招聘需求整理出相关的面试题之类的" — 用户原话

## 二、现状

已完成。真实实现（trpc-agent-go + MiniMax）+ mock 实现均就位。

## 三、实体设计

```go
// domain/entity/interview_question.go
type InterviewQuestion struct {
    ID         string
    JobPostID  string   // 关联招聘需求
    Title      string
    Answer     string
    Difficulty Difficulty // easy/medium/hard
    Tags       []string
    CreatedAt  time.Time
}

func (q InterviewQuestion) IsValid() bool { return q.Title != "" && q.Answer != "" }
// 实现 Publishable 接口（可推送）
func (q InterviewQuestion) PublishIdentity() (string, ContentType) { return q.ID, ContentTypeQuestion }
```

## 四、设计：策略 + Prompt 隔离

```go
// usecase/port/ai_generator.go —— 隔离 trpc-agent-go
type AIGenerator interface {
    GenerateQuestions(ctx context.Context, post entity.JobPost) ([]entity.InterviewQuestion, error)
}
```

**关键设计：Prompt 工程在适配器层**
- 用例只传 `JobPost`，不知道 Prompt 长什么样
- Prompt 构造 + LLM 输出解析全部在 `adapter/ai/`
- Prompt 迭代不影响用例

```go
// adapter/ai/prompt.go —— 系统提示词
const GenerateQuestionsSystemPrompt = `你是一名资深技术面试官...必须只输出 JSON 数组...`

// adapter/ai/parser.go —— LLM 输出容错
// 处理三种情况：纯JSON / ```json代码块包裹 / 前后噪声文本
func parseQuestions(raw string, jobPostID string) ([]entity.InterviewQuestion, error)
```

## 五、用例编排流程

```
POST /api/v1/questions/generate {job_post_id}
    │
    ▼
GenerateQuestionsUseCase.Execute
    │
    ├─ 1. 校验 JobPostID
    ├─ 2. JobPostRepository.FindByID() 取招聘需求
    ├─ 3. AIGenerator.GenerateQuestions() 调 AI（trpc-agent-go→MiniMax）
    ├─ 4. 逐题 IsValid() 过滤（剔除 AI 空输出）
    └─ 5. QuestionRepository.SaveBatch() 入库
    │
    ▼
返回 []InterviewQuestion
```

## 六、LLM 输出容错（关键设计）

LLM 输出不稳定，parser.go 做三层容错：

```
LLM 原始输出                    parser 处理
───────────────────────────────────────────
"好的，以下是题目：            ┐
[{...}]"                       ┘ → 剥离噪声 → 提取 JSON 数组 → Unmarshal

"```json                       ┐
[{...}]                        ┘ → 去代码块标记 → 提取 JSON
```"

"[{title:'',answer:''}]"        → 领域规则过滤空标题/答案
```
