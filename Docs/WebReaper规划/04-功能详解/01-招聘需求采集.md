## 三、实体设计

```go
// domain/entity/job_post.go
type JobPost struct {
    ID           string
    Source       string    // 来源平台
    Company      string
    Position     string
    Requirements []string  // 任职要求
    Salary       string
    RawHTML      string
    URL          string
    CollectedAt  time.Time
}

// 领域规则
func (j JobPost) IsValid() bool { return j.Position != "" && len(j.Requirements) > 0 }
func (j JobPost) Fingerprint() ContentFingerprint { ... } // 公司+职位+要求 → SHA-256
```

## 四、设计：策略+注册表

```go
// usecase/port/spider.go —— 接口归用例所有
type Spider interface {
    Crawl(ctx context.Context, source entity.Source) ([]entity.JobPost, error)
    Supports() string
}

// usecase/port/registry.go —— 注册表（开闭原则）
type SpiderRegistry struct { ... }
func (r *SpiderRegistry) Lookup(sourceType string) (Spider, bool)
```

**真实实现**：`adapter/spider/GenericWebSpider`（colly，CSS 选择器配置化，通用任意网站）
**降级实现**：`adapter/mock/MockSpider`（硬编码示例数据）

## 五、用例编排流程

```
POST /api/v1/collect
    │
    ▼
CollectJobPostsUseCase.Execute
    │
    ├─ 1. 校验 Source.IsValid()
    ├─ 2. SpiderRegistry.Lookup(sourceType) 分派爬虫
    ├─ 3. spider.Crawl() 爬取
    ├─ 4. 逐条：IsValid() 校验 → ExistsByFingerprint() 去重
    └─ 5. SaveBatch() 批量入库
    │
    ▼
返回 {Collected, Skipped, Failed}
```
