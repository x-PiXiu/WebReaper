| 品牌数 / 关键词数 | Brand/Keyword 仓储 Count | 数字卡片 |

## 三、关键词工作台（增强：结构化输出 + 多来源）

### 3.1 LLM 结构化输出约束（防随机化）

**问题**：LLM 直接生成关键词列表会随机化（格式漂移、数量漂移、重复）。

**方案**：结构化输出三层保障：
1. **JSON Schema 硬约束**：LLM 必须输出 `{"keywords":[{"term":"...","intent":"informational|transactional|local"}]}`
2. **解析校验 + 重试**：解析失败 → 带错误信息重试一次（上限 2 次）；仍失败 → 报错不降级为乱数据
3. **去重 + 过滤**：去重、过滤空串/过短（<2 字）/与种子重复项

**落点**：
- `port.KeywordSource` 策略接口：`Extract(ctx, input) ([]entity.Keyword, error)`
- `adapter/ai/keyword_generator.go`：JSON Schema 约束 prompt + 校验循环
- `usecase/geo/keyword_distill.go`：改为编排多来源（内部保持现有 Distill）

### 3.2 多来源获取

| 来源 | 说明 | 实现 |
|---|---|---|
| 文本蒸馏种子拓展 | ✅ 已有（Distill） | 保留 |
| 文件读取 | 上传 txt/csv 关键词清单，批量导入 | `adapter/keyword/file_source.go`（解析+去重+入库） |
| 网络获取 | 从竞品页面/搜索热词抓取候选词 | `adapter/keyword/web_source.go`（复用爬虫） |
| LLM 生成 | 按品牌定位/卖点生成拓展词 | 结构化输出（3.1） |

### 3.3 API
```
POST /api/v1/geo/brands/:id/keywords/generate   # LLM 结构化生成（已有，改约束）
POST /api/v1/geo/brands/:id/keywords/import     # 文件导入（新增）
POST /api/v1/geo/keywords/distill               # 文本蒸馏（已有）
```

## 四、内容工作台（增强：组合生成 + 平台维度 + 优化模式）

### 4.1 生成模式

```
输入：品牌 + 关键词（多选可组合） + 目标平台（豆包/文心/DeepSeek/通用）
模式 A 生成：按 品牌定位+卖点+关键词组合+平台调性 → 生成全新内容
模式 B 优化：用户输入草稿 → 按关键词+平台调性 → 优化改写（保留原意，增强关键词覆盖）
```

### 4.2 平台维度设计（策略模式）

```go
// port.ContentPlatform 内容平台调性模板（策略）
type ContentPlatform interface {
    Name() string              // 豆包 / 文心 / DeepSeek / 通用
    BuildPrompt(input) string  // 平台调性 prompt
    Tone() string              // 语气（口语化/专业/营销）
}
```
- `adapter/platform/` 下每平台一个实现，注册表 `PlatformRegistry`（新增平台 = 注册新适配器，开闭原则）
- 输出统一过 `StripThinkTags`（已有，**保证零思考内容**——GEO 硬约束）

### 4.3 API
```
POST /api/v1/geo/brands/:id/contents/generate      # 生成（改：接受 keywords[] + platform）
POST /api/v1/geo/brands/:id/contents/optimize      # 优化（新增：草稿 + keywords + platform）
POST /api/v1/geo/brands/:id/contents/generate-stream # SSE 流式（已有）
```
