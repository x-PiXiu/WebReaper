# 02-视频生成与登录地址域设计（全新域）

> 两个全新能力域：
> ① **视频生成**：Vidu 文本/素材生成 → 配音 → 合成 → 发布抖音等视频平台
> ② **登录地址**：记录用户登录 IP 归属地，发布内容时附带（实体经济场景：门店/到店引流）

---

## 一、视频生成域（Video）

### 1.1 业务流水线

```
素材输入 ──┐
          ├─→ ① 视频生成（Vidu 文生视频 / 图生视频）──→ ② 配音（TTS）──→ ③ 合成（音视频合并）──→ ④ 发布（抖音/快手）
随机文本 ──┘
```

| 阶段 | 能力 | 说明 |
|---|---|---|
| ① 生成 | `VideoProvider.Generate` | 文本/素材 → 视频文件（异步任务，轮询状态） |
| ② 配音 | `VoiceSynthesizer.Synthesize` | 文本 → 语音（TTS，可选手音/语速） |
| ③ 合成 | `VideoComposer.Compose` | 视频 + 配音 → 成片（ffmpeg 合并） |
| ④ 发布 | 复用 `PublishChannel` | 抖音/快手适配器（视频上传） |

### 1.2 领域模型

```go
// domain/entity/video.go

// VideoTask 视频生成任务（状态机：pending → generating → dubbing → composing → ready / failed）
type VideoTask struct {
    ID        string
    TenantID  string
    BrandID   string          // 可选：与品牌关联
    Mode      string          // text / material（随机文本 / 上传素材）
    Prompt    string          // 生成提示词（文本模式）
    Material  string          // 素材 URL（素材模式）
    Status    string
    VideoURL  string          // 生成后视频地址
    VoiceText string          // 配音文本
    VoiceURL  string          // 配音文件地址
    FinalURL  string          // 合成成片地址
    DurationSec int
    Error     string
    CreatedAt, UpdatedAt time.Time
}

// VideoJob 视频发布任务（复用 PublishJob 结构，扩展 media_type=video）
type VideoJob struct {
    ID, TenantID, AccountID string
    VideoTaskID string
    Platform   string        // douyin / kuaishou
    Status     string        // pending / publishing / published / failed
    ExternalURL string
}
```

### 1.3 分层落点

```
domain/entity/video.go            VideoTask / VideoJob 实体 + 状态机方法（CanDubb/CanCompose...）
usecase/port/video_port.go        VideoProvider / VoiceSynthesizer / VideoComposer 接口
usecase/video/video.go            VideoUseCase：编排流水线（模板方法骨架：生成→配音→合成→就绪）
usecase/video/video_test.go       mock 提供者验证状态机与降级
adapter/video/vidu.go             ViduProvider（Vidu API 适配器，异步轮询）
adapter/video/voice.go            VoiceSynthesizer（如火山 TTS / 阿里云 TTS）
adapter/video/compose.go          ffmpeg 合成（exec 封装，隔离在适配器）
adapter/video/publish.go          视频发布适配器（对接 PublishChannelRegistry）
```

### 1.4 状态机（VideoTask）

```
pending ──提交──> generating ──完成──> dubbing ──完成──> composing ──完成──> ready
   │                 │                                      │
   └── 失败任一阶段 ──┴───────────────> failed（保留 Error 供重试）
```

- 状态机逻辑放实体层（`CanTransitionTo(next)`），用例层只编排——行为内聚、测试友好
- 异步任务：提交后立即返回，前端轮询 `GET /api/v1/video/tasks/:id`

### 1.5 API

```
POST   /api/v1/video/tasks                    # 提交生成任务 {mode, prompt|material, brand_id?}
GET    /api/v1/video/tasks/:id                # 轮询任务状态
POST   /api/v1/video/tasks/:id/dub            # 配音 {voice_text, voice?}
POST   /api/v1/video/tasks/:id/compose        # 合成（触发 ffmpeg）
POST   /api/v1/video/tasks/:id/publish        # 发布 {platform, account_id?}
GET    /api/v1/video/tasks                    # 任务列表（租户）
```

### 1.6 配置（.env.example 追加）

```
VIDU_API_KEY=            # Vidu 视频生成密钥
VIDU_BASE_URL=https://api.vidu.cn/v1
TTS_API_KEY=             # 配音 TTS 密钥
TTS_VOICE_ID=            # 默认音色
FFMPEG_PATH=ffmpeg       # 合成器路径
```

## 二、登录地址域（GeoLocation）

### 2.1 需求
用户登录时记录 IP 归属地（省/市/经纬度），发布内容时可选附带地址——对实体经济（门店引流、同城营销）有用。

### 2.2 设计

```go
// domain/entity/login_trace.go
type LoginTrace struct {
    ID, UserID string
    IP         string
    Country, Province, City string
    Lat, Lng   float64
    LoginAt    time.Time
}

// usecase/port/geo_resolver.go —— 策略接口（IP 库可替换）
type GeoResolver interface {
    Resolve(ctx context.Context, ip string) (GeoLocation, error)
}
type GeoLocation struct {
    Country, Province, City string
    Lat, Lng float64
}
```

### 2.3 适配器（策略模式）

| 适配器 | 说明 | 适用 |
|---|---|---|
| `adapter/geotrace/ipapi.go` | 免费 ipapi.co 查询（HTTP） | 开发/低流量 |
| `adapter/geotrace/mmdb.go` | 本地 MaxMind MMDB 离线库 | 生产（无外部依赖） |

- 登录成功时异步记录（不阻塞登录）：`LoginUseCase` 完成后经 `LoginTraceUseCase` 落库
- IP 从请求上下文取（`c.ClientIP()`），代理部署时取 `X-Forwarded-For`

### 2.4 API

```
GET /api/v1/login-trace            # 我的登录记录（商户端可见）
PUT /api/v1/publish-jobs/:id/location  # 发布时附带地址 {city, address, lat, lng}
```

### 2.5 发布附带地址

- `PublishJob` 扩展可选 `Location` 字段（城市/门店地址/经纬度）
- 半自动：预填 URL 附带地址文案；全自动：正文尾部追加门店定位信息
- 前端发布表单：开关"附带登录地址" + 可选门店地址文本

## 三、风险与降级

| 场景 | 降级策略 |
|---|---|
| Vidu API 未配置/失败 | 任务标记 failed 带 Error；前端展示；不阻断其他功能 |
| TTS 未配置 | 跳过配音阶段（任务直接 composing，用原视频音轨） |
| ffmpeg 不存在 | 合成阶段 failed 并提示安装 |
| IP 解析失败 | 记录 IP 原文，地址字段留空（不影响登录） |
| 视频发布失败 | 任务保持 ready，可重新发布 |
